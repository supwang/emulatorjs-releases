**Which file?**
- **Windows** (recommended): `EmulatorJS-Setup-<version>.exe` — installer; updates itself when a new version comes out
- **Windows** (no install): `EmulatorJS-<version>-win.zip` — unzip, then double-click `EmulatorJS.exe`
- **Mac with Apple chip** (M1 / M2 / M3 / M4): `…-mac-apple-silicon.dmg` · **Mac with Intel chip**: `…-mac-intel.dmg`
- **Android** phone / tablet / TV: `…-android.apk` (Android 7.0+) · **Android emulator on a PC** (MuMu etc.): `…-android-x86_64.apk`
- **Any computer, in the browser**: `…-folder.zip` — unzip, then double-click `EmulatorJS-Windows.bat` (Windows) or `EmulatorJS.command` (Mac)
- **Your own internet play server**: `ejs-cloud-setup.sh` (Ubuntu 22.04 / 24.04: `sudo bash ejs-cloud-setup.sh`)

**First start:** Windows — "More info → Run anyway"; Mac — System Settings → Privacy & Security → Open Anyway.
No game ROMs or BIOS files are included. Full guide: `README_US.txt` in the download.

### 中文

**下载哪个？**
- **Windows**（推荐）：`EmulatorJS-Setup-版本号.exe`，安装版，以后有新版本能自动更新
- **Windows**（不想安装）：`EmulatorJS-版本号-win.zip`，解压后双击 `EmulatorJS.exe`
- **Mac（M1 / M2 / M3 / M4 芯片）**：`…-mac-apple-silicon.dmg` · **Mac（Intel 芯片）**：`…-mac-intel.dmg`
- **安卓手机 / 平板 / 电视**：`…-android.apk`（需要 Android 7.0 以上）· **电脑上的安卓模拟器**（MuMu 等）：`…-android-x86_64.apk`
- **任何电脑，用浏览器玩**：`…-folder.zip`，解压后双击 `EmulatorJS-Windows.bat`（Windows）或 `EmulatorJS.command`（Mac）
- **自己搭外网联机服务器**：`ejs-cloud-setup.sh`（Ubuntu 22.04 / 24.04 上运行 `sudo bash ejs-cloud-setup.sh`）

国内下载慢的话，用百度网盘：https://pan.baidu.com/s/13atBCqmTib1rGp_30279mQ?pwd=6akk （提取码 `6akk`），文件完全一样。

**第一次打开**：Windows 点「更多信息 → 仍要运行」；Mac 到「系统设置 → 隐私与安全性」点「仍要打开」。
本工具不包含任何游戏 ROM 和 BIOS。详细说明在下载包里的 `README_CN.txt`。
