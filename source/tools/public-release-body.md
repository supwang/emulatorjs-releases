- 文件夹版（Windows、Mac 都能用，用浏览器玩）：`…-folder.zip`
- 自己搭外网联机服务器：`ejs-cloud-setup.sh`

**Which file?** Windows: the Setup .exe (installer, updates itself) or the -win.zip (no install). Mac: -mac-apple-silicon.dmg (M1–M4) or -mac-intel.dmg (Intel). Any computer, in the browser: -folder.zip. Your own internet play server: ejs-cloud-setup.sh.
First start: Windows "More info → Run anyway"; Mac: System Settings → Privacy & Security → Open Anyway. No game ROMs or BIOS files are included.
