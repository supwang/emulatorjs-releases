点左上角「选择 ROM 文件夹」，选你放 ROM 的那个总文件夹（里面按平台分子文件夹最好，比如 RetroArch 常用的 Nintendo - Game Boy Advance 这种命名）。

再点「选择预览图文件夹」，选 RetroArch 的 thumbnails 文件夹，就能看到封面和游戏截图。

在左边点一个平台，右边会显示这个平台所有游戏的封面，点封面就开始玩。存档会自动保存在浏览器里。
