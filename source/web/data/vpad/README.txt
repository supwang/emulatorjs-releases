On-screen controller buttons (phones / tablets) for NES, SNES, Mega Drive / Genesis, PlayStation, arcade, GBA and Game Boy.

Pictures from libretro "common-overlays" (https://github.com/libretro/common-overlays, folders gamepads/nes, snes,
genesis, psx, arcade, gba, gameboy), licensed under Creative Commons Attribution 4.0 International (CC BY 4.0, see
LICENSE-CC-BY-4.0.txt). Changes: the arcade pictures were scaled down; only the button pictures are used.

The controller bodies behind the buttons (body.webp, left.webp, right.webp in nes, snes, genesis, psx, n64, gba, gameboy and arcade) are original artwork made for this project, not from common-overlays.
