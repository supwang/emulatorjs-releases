EmulatorJS 使用說明
================================

EmulatorJS 是一個在瀏覽器裡玩老遊戲的工具，不需要安裝 RetroArch，也不需要聯網。
支援 FC/NES、超任 SNES、Game Boy / GBA、N64、NDS、世嘉 MD / Mega-CD / 32X / Saturn、PS1、PSP、
PC Engine、街機 (FBNeo / MAME 2003) 等二十多個平臺。


一、資料夾裡有什麼
------------------
  index.html              遊戲頁面（不要直接雙擊開啟它）
  data/                   模擬器和模擬核心，不要改動
  EmulatorJS.command      Mac 啟動檔案
  EmulatorJS-Windows.bat  Windows 啟動檔案
  start-windows.ps1       Windows 啟動檔案要用到的指令碼，和 .bat 放在一起
  Enable-LAN-Windows.bat  Windows 聯機許可（第一次執行會自動彈出，選了「否」時再手動雙擊它）
  cloud-server/           搭建外網聯機伺服器用的安裝指令碼（只在雲伺服器上用，見第八節）
  server.py               Mac 啟動檔案要用到的本地伺服器程式
  config.json             第一次儲存資料夾設定後自動生成，記錄你選的資料夾
  EmulatorJS.lnk          Windows 第一次執行後自動生成的快捷方式（帶遊戲手柄圖示）
  LICENSE                 EmulatorJS 的開源許可證（GPL-3.0）
  README_HK.txt 等        這份說明，每種語言一份：CN 简体中文、HK 繁體中文、US English、JP 日本語、
                          KR 한국어、ES Español、FR Français、DE Deutsch、BR Português、RU Русский


二、怎麼開啟
------------
【桌面版程式（推薦）】
  不想用瀏覽器、也不想一直開著終端視窗，可以用桌面版：雙擊圖示就開啟遊戲視窗，關掉視窗就退出。
  · Windows：EmulatorJS-Setup-版本號.exe 是安裝版（可以自己選安裝位置，會建開始選單和桌面圖示）；
    EmulatorJS-版本號-win.zip 是免安裝版：解壓到任意資料夾，雙擊裡面的 EmulatorJS.exe 就能玩。
    第一次開啟如果出現「Windows 已保護你的電腦」：點「更多資訊」→「仍要執行」。
    Windows 問是否允許網路訪問時，勾選「專用網路」再點「允許」（區域網聯機要用）。
  · Mac：M1 / M2 / M3 / M4 晶片用 …-mac-apple-silicon.dmg，Intel 晶片用 …-mac-intel.dmg。
    開啟 dmg，把 EmulatorJS 拖進「應用程式」資料夾。
    第一次開啟會提示無法驗證開發者：到「系統設定 → 隱私與安全性」，點「仍要開啟」。
    之後問能否查詢本地網路上的裝置、能否使用麥克風時，都選「允許」（區域網聯機、語音聊天要用）。
  · 遊戲資料夾：自動找「文稿 / EmulatorJS」裡的 roms、thumbnails、system，以及 RetroArch 的預設位置；
    也可以在「⚙ 資料夾設定」裡選。第一次開啟時會自動沿用原來 EmulatorJS 資料夾的設定。
  · 設定儲存在程式自己的資料資料夾裡。原來的 EmulatorJS.command / EmulatorJS-Windows.bat 也照樣能用，
    兩種方式可以一起聯機。
  · 設定檔 config.json（資料夾設定、外網聯機伺服器地址和房間密碼）在：
    Windows：%APPDATA%\EmulatorJS\config.json（在檔案總管的位址列輸入 %APPDATA%\EmulatorJS 回車就能開啟）
    Mac：~/Library/Application Support/EmulatorJS/config.json（訪達裡按 Shift+Command+G，貼上這個路徑）

【Android 手機 / 平板 / Android 電視（APK）】
  · 手機、平板、電視、電視盒子用 EmulatorJS-版本號-android.apk；
    電腦上的 Android 模擬器（MuMu 等）用 EmulatorJS-版本號-android-x86_64.apk。
    需要 Android 7.0 以上。電視上的「Android System WebView」太舊時會提示更新。
  · 安裝：把 apk 傳到手機 / 電視上（傳輸線、USB 手指、WhatsApp / 微信傳檔案都可以），用檔案管理員點開它。
    提示「不允許安裝不明來源的應用程式」時，按提示允許這個檔案管理員安裝應用程式，再點一次 apk。
    電視：把 apk 複製到 USB 手指，插到電視上，用電視內建的「檔案管理」開啟 USB 手指裡的 apk。
  · 第一次開啟會問能否存取相片和檔案（儲存空間權限），選「允許」，不然讀不到遊戲。
    之後會自動建好「手機儲存 / EmulatorJS」資料夾，裡面有 roms、thumbnails、system 三個資料夾。
  · 放遊戲：手機用傳輸線連電腦（手機上選「傳輸檔案」），把遊戲複製到 EmulatorJS / roms，
    放法和電腦上一樣（見第三節），封面圖放 thumbnails，BIOS 放 system。放好後按「↻ 重新讀取」。
    也可以放在別的地方，在「⚙ 資料夾設定」裡選；選資料夾時上面有「手機儲存」「下載」等捷徑按鈕。
  · 電視讀 USB 手指：USB 手指根目錄下有 EmulatorJS 或 RetroArch 資料夾（裡面是 roms 等）時會自動找到；
    也可以在「⚙ 資料夾設定」裡按「U 盤 / 儲存卡」選資料夾。USB 手指換了內容，按「↻ 重新讀取」。
    Android 不允許應用程式寫入 USB 手指：連線時從別人電腦下載的遊戲會存到「EmulatorJS / downloads」，
    和 USB 手指裡的遊戲顯示在一起。
  · 操作：
    手機：螢幕上有虛擬按鍵，也可以連藍牙 / USB 手柄。
    電視：用遙控器選遊戲（方向鍵移動，確認鍵 / OK 開啟，返回鍵返回），連上手柄玩。
    遊戲中按遙控器或手機的返回鍵（或手柄同時按住 Select + Start）開啟遊戲選單：
    繼續、即時存檔、讀取存檔、重設、全螢幕、離開遊戲。在遊戲列表裡連按兩次返回鍵離開程式。
  · 連線、大廳、帳號和電腦版一樣，可以和電腦一起連線（區域網路要連同一個 Wi-Fi）。
    語音聊天第一次用時會問能否使用麥克風，選「允許」。
  · 便宜的電視盒子效能有限：FC、超任、GBA、MD 這些都很流暢，N64、PSP、NDS、Saturn 可能會卡。

【Mac】
  1. 雙擊 EmulatorJS.command。
     第一次開啟如果提示「無法開啟，因為來自身份不明的開發者」：
     右鍵點它 → 選「開啟」→ 再點「開啟」。以後直接雙擊就行。
  2. 會彈出一個終端視窗，瀏覽器會自動開啟遊戲頁面。
     如果系統提示安裝「命令列開發者工具」，點「安裝」，裝好後再雙擊一次。
  3. 玩的時候不要關終端視窗，玩完再關。
  啟動檔案會自動換成遊戲手柄圖示。如果圖示在傳輸中丟了，雙擊執行一次就會恢復。

【Windows】
  1. 雙擊 EmulatorJS-Windows.bat。
     如果出現藍色的「Windows 已保護你的電腦」：點「更多資訊」→「仍要執行」。
  2. 會彈出一個黑色命令列視窗，瀏覽器會自動開啟遊戲頁面。
  3. 玩的時候不要關這個視窗，玩完再關。
  Windows 不能給 .bat 檔案設圖示，所以第一次執行後，資料夾裡會自動生成一個帶圖示的
  「EmulatorJS」快捷方式，以後雙擊它就行。快捷方式可以拖到桌面。
  如果把資料夾挪了位置，快捷方式會失效，再雙擊一次 .bat 就會重新生成。

為什麼要開著這個視窗？
  視窗裡執行的是一個只有本機能訪問的小網頁伺服器。瀏覽器出於安全限制，
  不允許直接雙擊開啟的網頁讀取模擬器檔案，所以要透過它來開啟。
  關掉視窗，伺服器就停了。

【更新到新版本】
  · 程式開啟後會自己檢查有沒有新版本（之後每 6 小時看一次），有的話會彈出提示，列出這次更新了什麼；
    左邊欄的版本號旁邊也會顯示「🆕 有新版本」。點版本號隨時可以手動檢查。正在玩遊戲時不會彈出來打擾。
  · Windows 安裝版（用 EmulatorJS-Setup-版本號.exe 裝的）：點「自動更新」，程式自己下載新的安裝包並檢查是否完整，
    下載好後點「立即安裝」：程式會關閉，裝好新版本後自己重新開啟（大約半分鐘），遊戲、設定、存檔都會保留。
    下載太慢（預計要 5 分鐘以上）或者下載失敗時，會提示改用百度網盤下載。
  · Mac、Windows 免安裝版、資料夾版、安卓：點「下載新版本」開啟下載地址，或者點「去百度網盤下載」（國內推薦），
    下載後按提示替換舊版本（Mac：把新的 EmulatorJS 拖進「應用程式」選「替換」；資料夾版：把新檔案複製到原來的資料夾裡覆蓋）。
  · 下載地址：https://github.com/supwang/emulatorjs-releases/releases
    百度網盤：https://pan.baidu.com/s/13atBCqmTib1rGp_30279mQ?pwd=6akk （提取碼 6akk）
  · 不想裝某個版本，點「跳過這個版本，不再提醒」。檢查更新只是讀取下載網站上的版本資訊，不會上傳任何東西。


三、遊戲資料夾（只需設定一次）
------------------------------
開啟頁面後會自動讀取三個資料夾，不用每次選擇：

  ROM 資料夾       放遊戲的總資料夾（必需）
  預覽圖資料夾     RetroArch 的 thumbnails 資料夾（可選，用來顯示遊戲封面）
  BIOS 資料夾      放 BIOS 的資料夾（可選，只有部分平臺需要，見第九節）

【自動查詢】沒設定過的資料夾會按下面的順序自動查詢，找到就直接用：
  1. EmulatorJS 資料夾裡（和 EmulatorJS.command、EmulatorJS-Windows.bat 放在一起）的
     roms、thumbnails、system 資料夾（BIOS 資料夾叫 bios 也可以）
  2. RetroArch 的預設位置
     Mac：~/Library/Application Support/RetroArch/ 下的 roms、thumbnails、system
     Windows：%APPDATA%\RetroArch，或 C:/D:/E:/F: 盤的 RetroArch-Win64、RetroArch、
              Games\RetroArch-Win64 等資料夾下的 roms、thumbnails、system
  所以如果你的 RetroArch 用的是預設位置，第一次開啟就能直接玩。
  分享給別人時，也可以把 roms、thumbnails、system 三個資料夾直接放進 EmulatorJS 資料夾裡，
  對方解壓後開啟就能玩。

【手動設定】點左上角「⚙ 資料夾設定」：
  1. 點每一項後面的「瀏覽…」，一層層點進資料夾，再點「選這個資料夾」。
     上方有「個人資料夾」「桌面」「RetroArch」等快捷按鈕。也可以直接貼上資料夾路徑。
  2. 點「儲存並讀取遊戲」。設定會儲存在 config.json 裡，以後開啟會自動使用。
  - 「清除」後儲存，就會改回自動查詢。
  - 之前設定的資料夾找不到了（比如換了電腦），會自動改回自動查詢，設定頁裡會提示。

【自動下載預覽圖】
  沒有封面的遊戲，可以從 libretro 社群的封面庫（libretro-thumbnails，RetroArch 用的也是它）自動下載
  封面、標題畫面和遊戲截圖，存進你的預覽圖資料夾（沒設定的話，會在 ROM 資料夾旁邊建一個 thumbnails 資料夾）。
  · 第一次讀取到沒有封面的遊戲時會問你要不要自動下載；同意後，以後加了新遊戲也會自動下載。
  · 也可以在「⚙ 資料夾設定」→「自動下載預覽圖」裡開啟 / 關閉，或者點「⬇ 現在下載缺少的預覽圖」。
  · 按遊戲名找對應的圖（街機按 FBNeo 的遊戲全名），檔名最好保持 No-Intro 這類標準名字，中文名或自己改過的名字可能找不到。
  · 需要能連上 GitHub。下載時左上角會顯示進度，可以隨時「停止」。這個封面庫是社群整理的，圖片版權歸各遊戲公司。

【加了新遊戲後】點左上角「↻ 重新讀取」，不用重新開啟頁面。

【新遊戲怎麼自動歸類到平臺】
  每個遊戲按下面的順序判斷平臺，前面的認出來了就不再往下看：
  1. RetroArch 播放列表裡記錄的平臺（本工具自帶了一份遊戲清單）
  2. 以前手動選過的平臺（在「需要手動選平臺」裡選過一次，以後自動記住）
  3. 副檔名：.nes .sfc .smc .md .gen .gba .gb .n64 .nds 等
  4. 讀檔案內容：
     - 壓縮包（.zip）：看裡面裝的是什麼檔案，比如裡面是 .sfc 就是超任，是 .md 就是世嘉 MD
     - 光碟 / 卡帶映象（.bin .iso .cue）：讀檔案開頭的標記，能認出世嘉 MD、世嘉 CD、
       世嘉土星、PS1 等
  5. 所在資料夾的名字：snes、md、fbneo、「Nintendo - Super Nintendo Entertainment System」等
  6. 壓縮包裡都不是已知的卡帶格式 → 當作街機遊戲
  7. 還是認不出來的（比如 .7z、.chd），放進「需要手動選平臺」，選一次就會記住
  街機遊戲還會對照 FBNeo 官方的遊戲清單（8000 多個）：檔名不在清單裡的（比如 NAOMI 的 cvs2.zip），
  FBNeo 跑不了，放進「網頁版不支援」。
  所以別人就算把各種遊戲都放在同一個資料夾裡，大部分也能自動歸到正確的平臺。
  只讀取檔案開頭和目錄的一小部分，不會把整個檔案讀一遍，速度很快；識別結果會記住，
  下次開啟不用重新識別。

小提示：
  - ROM 資料夾裡最好按平臺分子資料夾，比如 snes、md、nes、fbneo，
    或者 RetroArch 常用的「Nintendo - Super Nintendo Entertainment System」這類名字，
    這樣能自動識別平臺。
  - 如果左上角顯示的是「選擇 ROM 資料夾」等三個按鈕，而不是「⚙ 資料夾設定」，
    說明開啟方式不對或用的是舊的啟動視窗：關掉所有終端/命令列視窗，
    再雙擊啟動檔案重新開啟。


四、開始玩
----------
  1. 左邊是平臺列表，每個平臺都有主機圖片。Neo Geo 遊戲單獨列為「Neo Geo」，
     其他街機遊戲在「街機 (FBNeo)」裡。
     點一個平臺，右邊會顯示這個平臺所有遊戲的封面。
     最上面的「🕘 最近玩過」列出這台電腦上最近玩的 10 個遊戲，點封面就能直接再玩。
     不想保留某個記錄：滑鼠移到封面上，點右上角的 ✕（手柄選中後按 X，鍵盤按 Delete）；「清空記錄」一次全部刪掉。
     滑鼠停在某個遊戲上，會自動輪播它的預覽圖：封面 → 標題畫面 → 遊戲截圖，
     封面下方的小圓點表示一共幾張、現在是第幾張；滑鼠移開就停在當前這張。
     （沒有的圖會跳過，只有一張圖的遊戲不輪播。）
     封面大小：封面牆右上角可以選「小 / 中 / 大 / 特大」，每個平臺分別記住自己的大小。
  2. 點封面就開始遊戲。
  3. 點右上角「退出遊戲」回到封面牆。
  4. 搜尋框可以按名字找遊戲。
  5. 左側欄最下面有「⌨ 快捷鍵提醒」，列出投幣、開始、重置遊戲、暫停、連發、存檔讀檔、
     街機後臺等功能鍵的鍵盤和手柄按法。點標題可以收起 / 展開，會記住你的選擇。
  6. 頁面配色：點左上角「EmulatorJS」旁邊的 🎨，可以在 7 套配色裡選
     （童年〔預設：黃昏的遊戲廳，帶背景圖〕、夜色街機〔深色〕、世嘉藍〔鮮豔藍〕、Game Boy 綠、超任灰紫〔淺色〕、
       奶油卡帶〔淺色〕、糖果粉〔淺色〕），
     背景、文字、按鈕會一起換，選好後會記住。
     同一個面板裡還能設定「背景圖片」：從電腦裡選一張圖片，顯示在右邊遊戲列表的後面（滾動時不動）。
     可以設一張通用的，也可以給每個機種單獨設一張（沒單獨設定的機種用通用的那張）；
     「調暗」滑塊可以讓圖片暗一點，文字看得更清楚。圖片只儲存在這臺裝置的這個瀏覽器裡。
     玩遊戲時，畫面兩邊的空白也會顯示這張背景圖（調暗、模糊），豎版遊戲兩邊就不是一片黑；不喜歡可以在同一個面板裡關掉。
  7. 介面語言：點左上角的國旗按鈕（見第八節【介面語言】）。

  - 「需要手動選平臺」：網頁認不出平臺的遊戲，選一下平臺就會歸到對應分組。
  - 「網頁版不支援」：瀏覽器版跑不了的遊戲（比如世嘉 NAOMI），請用 RetroArch 玩。
    不想看到這個列表：打開它點右上角的「不顯示這個列表」，或在「⚙ 資料夾設定」裡取消勾選；想看時再勾上。

遊戲裡的按鍵、存檔、即時存檔、全屏等，都在遊戲畫面下方的選單欄裡。
「控制設定」可以檢視和修改鍵盤按鍵，也支援手柄。
存檔儲存在瀏覽器裡，換瀏覽器或清除瀏覽器資料後會丟失。
需要備份的話，可以用選單裡的「匯出存檔檔案」。

金手指：選單欄裡的「秘籍」（英文介面叫 Cheats）→「添加作弊」（Add Cheat），填上代碼（Code）和說明（Description），
提交後勾選就生效，再點一次取消。代碼格式看平台：FC 用 Game Genie，GBA 用 Action Replay / GameShark 等，
網上搜「遊戲名 + 金手指」能找到。有些金手指關掉後要重新開始遊戲才會完全恢復。
連線時（有別的玩家一起玩）金手指會自動關閉，秘籍按鈕也會藏起來；只剩你一個人時自動恢復。

金手指庫：在「秘籍」（Cheats）選單最上面點「📚 從金手指庫選（libretro）」，會按遊戲名找到這個遊戲的金手指
（來自 libretro 社群的資料庫 libretro-database，FC、超任、MD、GBA 等家用機比較全，街機基本沒有），勾選後點「新增選中的金手指」，
再回到「秘籍」裡勾選才會開啟。聯機時同樣不能用。需要能連上 GitHub。


五、鍵盤和手柄
--------------
【鍵盤預設鍵位】（玩家 1）

  方向                W 上   S 下   A 左   D 右
  開始 (Start)        回車
  選擇 (Select)/投幣  V

  FC / NES            J = A    K = B
  超任 SNES           J = A    K = B    I = X    L = Y    U = L 肩鍵    O = R 肩鍵
  世嘉 MD / Mega-CD   下排 J K L = A B C        上排 U I O = X Y Z
  街機 Neo Geo（拳皇、合金彈頭、侍魂等）
                      J = A    K = B    I = C    L = D
                      U = A+B 組合   O = C+D 組合   （A+B+C、B+C+D 組合預設沒有分配按鍵）
  街機（其他遊戲）    J K I L = 按鍵 1 2 3 4    U O = 按鍵 5 6
  街機（街霸類 6 鍵格鬥：街霸系列、惡魔戰士、漫畫英雄等）
                      輕拳 J   中拳 K   重拳 L
                      輕腳 U   中腳 I   重腳 O
                      （三拳、三腳組合預設沒有分配按鍵）

  暫停 / 繼續   右 Shift
  連發 開/關    T
  重置遊戲      V + 回車 + U + O 同時按（多合一卡帶會回到選遊戲畫面）
  即時存檔 1    讀取即時存檔 2    切換存檔位 3
  （快進、慢放、倒帶預設沒有分配按鍵，可以在「控制設定」裡自己設）

  - 街機遊戲會按 ROM 檔名自動選擇佈局。目前用「街霸類 6 鍵」佈局的遊戲有：
      街霸 1 (sf)、街霸 2 冠軍版 (sf2ce)、街霸 Zero 3 (sfa3)、街霸 3 三度衝擊 (sfiii3)、
      街霸 EX2 Plus (sfex2p)、惡魔戰士 (dstlk)、惡魔戰士 2 (nwarr)、吸血鬼救世主 2 (vsav2)
    其餘街機遊戲（包括拳皇、合金彈頭等 Neo Geo 遊戲）都用 J K I L 佈局。
    以後新加的街霸、惡魔戰士、漫畫英雄 (X-Men、Marvel) 系列遊戲也會自動識別成 6 鍵佈局。
  - 鍵位可以在遊戲畫面下方選單欄的「控制設定」裡修改。

【「控制設定」裡顯示的按鍵】
  按鍵名稱按各平臺原始手柄顯示，順序統一為：
    投幣 / 選擇 → 開始 → 上下左右 → 按鍵 → 組合鍵 → 即時存檔、快進等功能鍵

  FC / NES            選擇、開始、方向、A、B
  超任 SNES           選擇、開始、方向、A、B、X、Y、L、R
  世嘉 MD / Mega-CD   MODE、開始、方向、A、B、C、X、Y、Z
  街機 Neo Geo        投幣、開始、方向、A、B、C、D
                      組合鍵：A+B、C+D、A+B+C、B+C+D
  街機 街霸類格鬥     投幣、開始、方向、輕拳、中拳、重拳、輕腳、中腳、重腳
                      組合鍵：三拳（三個拳同時按）、三腳（三個腳同時按）
  街機 其他遊戲       投幣、開始、方向、按鍵 1～6

  - 組合鍵：按一個鍵，等於同時按下幾個鍵。Neo Geo 原機只有 A B C D 四個鍵，
    組合鍵是模擬器額外提供的，方便放必殺技、閃避（比如拳皇的 A+B 閃避、C+D 吹飛）。
  - 街機遊戲是不是 Neo Geo / 街霸類，是按 ROM 檔名和遊戲全名自動判斷的。
  - 設定是按遊戲分別儲存的：在某個遊戲裡改過的鍵位、濾鏡等，只對這個遊戲生效，
    下次開啟這個遊戲會自動沿用；其他遊戲仍然使用上面的預設鍵位。
  - 遊戲存檔（包括即時存檔）和這些設定是分開儲存的，互不影響。
  - 手柄的鍵位不受上面鍵盤設定影響，見下面的【手柄】。

【手柄】
支援常見手柄：Xbox、PS4 / PS5、Switch Pro，以及大部分 USB / 藍芽通用手柄。

  1. 先用 USB 或藍芽把手柄連上電腦。
  2. 進入遊戲後，先按一下手柄上的任意鍵，瀏覽器才會識別手柄（瀏覽器的隱私規定）。
  3. 預設按 RetroArch 的習慣對應手柄按鍵（以 Xbox 手柄為例，左邊是遊戲裡的鍵）：
       FC / 超任   B → 手柄 A（下）   A → 手柄 B（右）   Y → 手柄 X（左）   X → 手柄 Y（上）
       世嘉 MD     A → 手柄 X（左）   B → 手柄 A（下）   C → 手柄 B（右）
       Neo Geo     A → 手柄 A（下）   B → 手柄 B（右）   C → 手柄 X（左）   D → 手柄 Y（上）
       街霸類      輕拳 → 手柄 X（左）  中拳 → 手柄 Y（上）  輕腳 → 手柄 A（下）  中腳 → 手柄 B（右）
                   重拳 → LB   重腳 → RB
     （EmulatorJS 原本的預設設定把手柄的 A、B 對調了，本工具已改成和 RetroArch 一致。）
     鍵位不對的話，點遊戲畫面下方選單欄的「控制設定」，可以給每個按鍵重新指定。
     最多支援 4 個玩家，可以分別設定不同的手柄。設定會儲存在瀏覽器裡。

  - 推薦用 Chrome 或 Edge，對手柄支援最好。
  - 街機遊戲的投幣和開始，一般是手柄上的 Select / 檢視鍵 和 Start / 選單鍵。
  - 重置遊戲：手柄同時按 Select + Start + LB + RB（PS 手柄是 Share + Options + L1 + R1）。
    玩 FC 多合一卡帶時，用它回到選遊戲的畫面。所有平臺都可以用。
  - 左搖桿和十字鍵作用一樣，可以控制方向（推過一半就算按下，斜推就是斜方向），
    兩個可以混著用。
  - 連發開關：按一下右搖桿（R3，就是把右搖桿按下去）。
  - 不用滑鼠也能選遊戲（手柄、鍵盤、電視遙控器都可以）：
      十字鍵 / 左搖桿 / 方向鍵：在遊戲封面和按鈕之間移動；A / 回車：確認（開始遊戲、點按鈕）；
      B / Esc / 遙控器返回鍵：返回、關掉開啟的面板；LB / RB：換上一個 / 下一個機種；Start：開啟或關上大廳。
  - 遊戲選單：玩的時候同時按住 Select + Start 半秒（電視遙控器按返回鍵），可以繼續、即時存檔、讀檔、
    重置、全屏、退出遊戲。單人玩時開啟選單會暫停；聯機時遊戲不會暫停，亂入的人看不到存檔、讀檔和重置。

【連發】
  1. 進遊戲後，點畫面上方的「連發設定」，勾選這個遊戲裡哪些鍵要連發。
     比如射擊遊戲：勾選射擊鍵，不勾蓄力鍵。這樣按住射擊鍵會連發，按住蓄力鍵就是正常蓄力。
  2. 開啟連發：在「連發設定」裡點「開啟連發」，或者遊戲中按 鍵盤 T / 手柄右搖桿（R3）。
     開啟後畫面左上角顯示「連發 ON」，「連發設定」按鈕也會變成「連發設定 · 開」。
  3. 勾選「進入這個遊戲時自動開啟連發」，以後進這個遊戲就自動開著，不用再按 T / R3。

  - 設定按遊戲分別儲存，每個遊戲設一次就行。預設是全部按鍵都勾選、進遊戲時不自動開啟。
  - 連發速度大約每秒 15 次。方向鍵、開始、投幣不受影響。
  - 所有平臺都可以用，鍵盤和手柄都可以。
  - 關掉「連發設定」視窗後，如果按鍵沒反應，用滑鼠點一下游戲畫面就好。


六、街機設定：後臺、難度、命數、Neo Geo 模式
--------------------------------------------
以下設定都在遊戲畫面下方選單欄的「設定」（齒輪圖示）→「Backend Core Options（核心選項）」裡。
改完後點選單欄的「重新開始」才會生效。設定按遊戲分別儲存。

【進入街機後臺（服務選單 / Test Mode）】
  遊戲裡按住「開始」鍵（回車）約 2 秒，就會進入街機原本的後臺選單，
  可以調難度、命數、時間、是否允許接關等（具體有哪些選項由遊戲決定）。
  進入方式可以在核心選項的「diagnostic input」裡改，比如改成按住選擇鍵。

【難度、命數（撥碼開關）】
  很多街機遊戲的難度、命數是用機板上的撥碼開關（DIP 開關）設定的。
  在核心選項裡找名字帶「Dipswitch」的項，比如：
    Difficulty（難度）  Lives（命數）  Bonus Life（獎命）
  每個遊戲的開關不一樣，有的遊戲沒有。

【多人模式（3 人、4 人）】
  - 名將（Captain Commando）：機臺出廠是 2 人模式，本工具預設改成 4 人模式
    （核心選項裡的「Dipswitch Play Mode」，想改回去可以在那裡改）。
  - 圓桌騎士、龍王戰士、戰場之狼 2：出廠就是 3 人模式，不用改。
  - 吞食天地 2、恐龍快打這類 Q-Sound 的 CPS1 遊戲：人數不是撥碼開關，而是遊戲後臺裡的設定，
    第 3 個人加入不了的話，進街機後臺（按住開始鍵約 2 秒）的 CONFIGURATION 裡看看。
  - 聯機時，大家同一個遊戲的這些設定要一樣，否則會提示“畫面對不上”，所以最好都用最新版本。

【Neo Geo 街機 / 家用機模式】
  本工具預設讓 Neo Geo 遊戲（拳皇、合金彈頭、侍魂等）以「街機模式」執行（MVS 歐亞版）：
    - 和街機廳一樣：按 V 投幣，再按回車開始；
    - 一個人在玩時，另一個人隨時投幣按開始就能加入（聯機亂入也一樣）；
    - 難度、命數等在街機後臺設定裡調（見上面的「進入後臺」）。
  想換成家用機模式：核心選項裡找「mode」（即 Neo-Geo mode），可選：
    MVS_EUR / MVS_USA / MVS_JAP  街機版（歐亞 / 美國 / 日本），需要投幣   ← 預設 MVS_EUR
    AES_EUR / AES_JAP            家用機版（歐亞英文 / 日文），不用投幣，標題畫面 Option 裡可調難度和命數
    DIPSWITCH                    按遊戲自帶的預設（一般是街機版）
    UNIBIOS                      玩家自制增強 BIOS（可開作弊、切地區等）
  按遊戲分別記住：某個遊戲改成家用機模式後，下次進這個遊戲還是家用機模式。
  聯機時，雙方同一個遊戲的模式要一樣，否則會提示“畫面對不上”。
  注意：需要 neogeo.zip 裡有對應的 BIOS 檔案（完整的 FBNeo 版 neogeo.zip 一般都有），
  缺少的話會自動退回遊戲預設模式。


七、濾鏡（畫面效果）
--------------------
進遊戲後，點畫面下方選單欄的「設定」→「圖形設定（Graphics Settings）」→「Shaders」，
選一個就能馬上看到效果：

  CRT easymode       模擬老式映象管電視，有掃描線，效果柔和，推薦先試這個
  CRT geom           映象管效果，帶螢幕弧度和暗角，最像當年的大屁股電視
  CRT aperture       模擬蔭罩網格，畫面清晰
  CRT mattias        模擬電視訊號的輕微模糊和色彩溢位
  2xScaleHQ          把畫素邊緣磨圓、變平滑
  4xScaleHQ          同上，平滑效果更強
  Disabled           關閉濾鏡，保持原始畫素

  - 濾鏡是按遊戲分別儲存的：給某個遊戲選好後，下次開啟這個遊戲還是這個濾鏡，
    其他遊戲需要分別設定。
  - CRT 類濾鏡在全屏下效果最好，視窗太小時掃描線會顯得太密。
  - 電腦配置比較老時，CRT geom 可能會卡，換成 CRT easymode 會流暢一些。


八、聯機
--------
【區域網聯機（同一個 Wi-Fi / 路由器下的電腦）】
不用互相發地址：大家各自雙擊 EmulatorJS.command（Mac）或 EmulatorJS-Windows.bat（Windows），
只要在同一個區域網裡，左側「🕹 正在遊戲」就會自動列出別的電腦上誰在玩什麼，點「亂入」就加入。

  · 區域網聯機預設是開啟的。不想被別人看到，點左下角「⚙ 資料夾設定」，去掉「區域網聯機」的勾。
  · Mac：第一次可能彈出“是否允許 Python 接受傳入網路連線”，選「允許」。
  · Windows：第一次開啟時會彈出“是否允許此應用對你的裝置進行更改”，選「是」（只問一次）。
    如果當時選了「否」，以後雙擊資料夾裡的「Enable-LAN-Windows.bat」補一次，再重新開啟 EmulatorJS。
  · 點「亂入」後，還是在自己的頁面上玩，用的是自己電腦裡的同一個遊戲檔案；
    自己這裡沒有這個遊戲（或檔案不一樣）時，自動改成看對方的畫面玩。
  · 列表裡寫著「另一臺電腦」的，是別的電腦上開的局；沒寫的，是在你這臺電腦的遊戲庫裡開的局。
  · 家用機遊戲也一樣：看到同一個遊戲在列表裡，點「亂入」就能一起玩。
  · 點「我是：…」可以改自己的名字，別人在列表裡看到的就是這個名字。
    名字不能含有辱罵、侮辱等不文明的詞，也不能和正在玩的人重名（不分大小寫、空格和符號）。
    含不文明詞的名字會被自動改成「玩家」加編號。
    遮蔽詞在 data/badwords.json 裡，可以用文字編輯器增刪（一個詞一項）；
    外網聯機伺服器上的在 /opt/emulatorjs-cloud/data/badwords.json，改完馬上生效，不用重啟。

沒裝 EmulatorJS 的裝置（平板、別人的電腦）：
  在瀏覽器位址列輸入開著 EmulatorJS 的那臺電腦的地址（左側欄會顯示，例如 http://192.168.1.23:8765 ），
  就能看到那臺電腦的全部遊戲並亂入，不需要 ROM。這些裝置看不到、也改不了那臺電腦的資料夾設定。
  注意：這種方式開啟的頁面，瀏覽器不允許用麥克風，所以不能語音（只能聽別人說話）。

怎麼聯機的（自動選擇，不用設定）：
  · 按鍵同步（實驗功能，預設優先用）：亂入的人自己的電腦上也執行同一個遊戲，
    網上只傳每一幀按了哪些鍵，和 RetroArch 的聯機原理一樣。畫面是自己電腦算出來的，清楚不模糊，
    幾乎不佔網速。從「另一臺電腦」亂入時用自己電腦裡的同一個遊戲檔案；
    用瀏覽器輸入區域網地址開啟的，遊戲檔案會自動從開局的電腦讀取，不用自己有 ROM。
    為了等按鍵在網上傳過來，所有人的按鍵會延後幾幀生效（區域網裡大約 2～3 幀，感覺不太出來）。
    每隔 2 秒會自動核對一次遊戲狀態；萬一對不上，主機會自動把即時存檔發給大家重新對齊，
    這時畫面會閃一下或跳一下，屬於正常現象。
  · 畫面串流：開局的電腦把畫面和聲音實時傳給亂入的人，亂入的人按鍵再傳回去。
    亂入的人找不到同一個遊戲檔案時，自動改用這種方式。
  開局的人是 1P，亂入的依次是 2P、3P、4P，最多 4 人（要遊戲本身支援多人）。
  能一起玩的人數看平臺：FC、PS1、Neo Geo 等 2 人，超任、MD、N64、其他街機、PC Engine 4 人，
  掌機（GB / GBA / NDS / PSP 等）1 人；人滿了還可以觀戰。「正在遊戲」裡的「2/2 人 · 👀 1」
  意思是：現在 2 個玩家 / 最多 2 人，另外 1 人在觀戰。
  亂入的人用自己的鍵盤或手柄，鍵位和單人玩時一樣。
  區域網裡延遲很低，但 Wi-Fi 訊號差時會卡，開局的電腦最好用網線。

按鍵同步時要注意：
  · 主機按右 Shift 暫停，所有人一起暫停；亂入的人不能暫停。
  · 只有主機能重置遊戲（Select+Start+L1+R1）和讀檔；主機讀檔或重置後，會自動同步給大家。
  · 每個玩家名字旁邊顯示他到主機的延遲（綠色快、黃色一般、紅色慢；經過伺服器中轉的標「中轉」），
    房主和亂入的人都看得到。有人一直是紅色、拖慢了大家，房主可以在「👥 房間」裡把他請出去。
  · 頂部的 📶 顯示連線情況：直連還是中轉、網絡來回一次多少毫秒、按鍵延後幾幀（會根據網絡自動調整）。
    數字一直很大時，可以改用網線，或暫停佔網速的下載。聯機的各方最好都用最新版本。
  · 所有人的電腦都要停在遊戲頁面上，有一個人切到別的視窗或最小化，大家都會一起卡住。
  · 某個人網路卡頓時，大家會一起慢下來，畫面上方會提示“等待 某某 的網路…”。
  · 如果一直提示“畫面對不上”，通常是雙方這個遊戲的設定（核心選項，比如 Neo Geo 的家用機/街機模式、
    難度）不一樣，改成一樣即可。
  · 已測試過 FC 和世嘉 MD，其他機種理論上也可以，但沒有逐個驗證；有問題時會自動重新對齊。

兩種聯機方式：延遲 / 回滾（按鍵同步時才有；由開局的人決定）
  在「⚙ 資料夾設定」→「聯機方式」裡選，玩的時候也可以在「👥 房間」裡切換。
  · 延遲模式（預設，穩）：上面說的方式。所有人的按鍵延後幾幀生效，畫面永遠一致，網路差時也不會回跳。
  · 回滾模式（跟手，實驗功能）：自己的按鍵幾乎馬上生效（只延後 2 幀）。對方的按鍵還沒傳到時，
    先當作他還按著上一次的鍵接著跑；真正的按鍵到了、發現猜錯了，就讀回幾幀前的即時存檔，
    用正確的按鍵一瞬間重跑一遍，所以偶爾會看到對方的角色“閃”一下到正確的位置。
    格鬥遊戲的線上對戰大多用這種方式。
    · 適合網路來回 100 毫秒以內；更慢時對方的動作會經常跳一下，可以改回延遲模式。
    · 每一幀都要多存一次即時存檔，電腦要夠快：哪臺電腦跑不動，這局會自動改回延遲模式並提示。
    · 聯機的所有人都要是新版本；有人是舊版本時，這局自動用延遲模式。
    · 某個遊戲在回滾模式下老是對不上（1 分鐘裡 3 次），這局也會自動改回延遲模式。
    · 回滾模式下不能暫停；頂部的 📶 顯示「回滾」。重跑那幾幀時偶爾可能聽到一點雜音。

手機和電腦一起玩（速度慢的裝置）：
  按鍵同步時大家必須一幀一幀一起跑，速度跟著最慢的那臺走。手機跑街機（Neo Geo 等）比電腦慢，所以會自動這樣處理：
  · 手機亂入電腦的遊戲：手機自動改成「看畫面玩」，遊戲在電腦上跑，速度和電腦一樣。螢幕上會出現十字鍵和按鍵。
  · 電腦亂入手機的遊戲：先對齊畫面，然後遊戲自動交給電腦執行，手機改成看畫面接著玩，
    中間會停一兩秒。兩人的玩家號不變（手機還是 1P，電腦還是 2P）。
  · 手機、平板上的街機、PS、N64 等遊戲一律按「慢」處理；其他遊戲按實際測到的速度判斷，電腦很老很慢時也一樣。
  · 手機單獨玩街機遊戲時，預設開啟自動跳幀、降低聲音取樣率，跑得更快（偶爾少畫一幀，遊戲速度不變）。

不想讓別人亂入：
  玩遊戲時，畫面上方有「允許亂入：開」按鈕，點一下變成「關」，別人就進不來了，
  列表裡會顯示“不允許亂入”（已經進來的人不受影響）。
  預設開還是關，以你最後一次的選擇為準。
  別人點進你正在玩的遊戲時，會提示“不允許亂入”，可以選擇自己單獨玩。

房間管理（👥 房間）：
  玩遊戲時點上方的「👥 房間」，可以看到房間裡的玩家和觀戰的人：
  · 允許觀戰：開 / 關。每局最多 8 人觀戰，其中看畫面觀戰的最多 2 人
    （看畫面觀戰要你的電腦給每個人單獨壓縮影片，人多了會拖慢你的遊戲）。
  · 只允許註冊玩家：開啟後，沒有登入賬號的人不能亂入或觀戰（區域網裡也一樣，需要設定好外網聯機伺服器）。
  · 請出去：點兩下（第二下是確認）。被請出去的人 30 分鐘內不能再進你的房間，
    按賬號、裝置編號和網路地址認人（同一個網路裡的其他人這 30 分鐘內也可能進不來）。
  · ♡：給其他玩家點贊（對方要有賬號）。

注意：
  · 開局的電腦要一直停在遊戲頁面上，切到別的視窗或最小化，畫面可能會停住。
  · 開局的人退出遊戲，這一局就結束了，亂入的人會收到提示。
  · 存檔儲存在開局那臺電腦上。連發：按鍵同步時用自己電腦上的設定，畫面串流時用開局那臺電腦的設定。
  · 只在同一個區域網內有效；外地朋友請看下面的方法。

【語音聊天】
  聯機時畫面上方有「🎤 語音：關」按鈕，點一下變成「開」，就能和一起玩的人說話（所有人都能互相聽到）。
  · 第一次開啟時，瀏覽器會問能否使用麥克風，選「允許」。以後會記住：開過語音的話，下次聯機自動開啟。
  · 關掉語音只是不讓別人聽到你，你仍然能聽到別人。
  · 有人說話時，上方他的名字會亮一圈。
  · 強烈建議戴耳機：不戴的話，麥克風會把遊戲聲音和別人的聲音又傳回去，產生回聲。
  · 必須是在自己電腦上開啟 EmulatorJS（地址是 127.0.0.1）才能用麥克風；
    平板等用區域網地址直接開啟的頁面，瀏覽器不允許用麥克風。

【和外地朋友聯機（外網聯機伺服器）】
和不在同一個網路的朋友聯機，需要一臺大家都能訪問的「聯機伺服器」（比如一臺雲伺服器）。
用法和區域網一樣：「正在遊戲」裡會出現外地朋友開的局（標著「外網」），點「亂入」即可，語音也能用。

每臺電腦的設定（只需一次）：
  「⚙ 資料夾設定」→「外網聯機伺服器」，填伺服器地址（例如 http://1.2.3.4:8765 ）和房間密碼，
  點「儲存並測試」，顯示“已連線”就好了。
  這個設定儲存在 EmulatorJS 資料夾的 config.json 裡：設定好以後再把整個資料夾打包發給朋友，
  朋友那邊就不用再填了。
  注意：config.json 裡有房間密碼，拿到這個資料夾的人都能進你的伺服器，只發給信任的人。
  不想讓對方直接連上，就先刪掉 config.json 再打包，讓對方自己填伺服器地址和房間密碼。

可以儲存多個伺服器：再填一個地址和房間密碼，點「添加並切換到這裡」。一個伺服器就是一個大廳，
在左邊「正在遊戲」下面點「🌐 大廳：…」就能切換；每個大廳旁邊有伺服器所在國家 / 地區的國旗、
房間數和線上人數。每台伺服器的帳號、好友、戰績是分開的，換到另一個大廳要在那邊另外註冊或登入。

注意：
  · 外網的局旁邊有房主網絡所在國家 / 地區的國旗（按 IP 大致判斷），可以用來估計延遲。
  · 沒有這個遊戲的人點「亂入」時，可以向開局的人請求下載：對方會彈窗選「允許 / 不允許 / 以後都允許他」，
    同意後遊戲檔案、3 張預覽圖和缺少的 BIOS 直接從對方電腦傳過來（不經過伺服器），存進自己 ROM 資料夾裡同名的平台資料夾，然後自動亂入。
  · 連不上或斷線：亂入後 20 秒還連不上會自動退出並提示；玩到一半斷線 15 秒，亂入的人自動退出，
    開局的人不再等他、接著玩。有一方開著 VPN 時，經常會連不上或延遲很高。
  · 外網亂入用的是自己電腦裡的同一個遊戲檔案（按鍵同步），所以大家的 ROM 要一樣
    （用同一個 EmulatorJS 包就沒問題）。沒有這個遊戲的人會改成看畫面，比較佔伺服器流量。
  · 兩地越遠，按鍵延後的幀數越多（程式會自動測網速調整），格鬥類遊戲會感覺稍微黏手。
  · 有密碼的人都能看到伺服器上的所有遊戲局；不想被人加入，就關掉「允許亂入」。

搭建聯機伺服器（只需做一次，由有云伺服器的人來做）：
  需要一臺 Ubuntu 22.04 / 24.04 的雲伺服器（最便宜的輕量伺服器就夠）。
  1. 雲伺服器控制檯 →「防火牆」放行：TCP 8765、TCP 80、TCP 3478、UDP 3478、UDP 49160-49250。
     （TCP 80 用來申請免費的 https 證書，讓密碼等資訊加密傳輸；證書每 3 天自動續期）
  2. 用控制檯的「登入」開啟網頁終端，把資料夾裡「cloud-server/ejs-cloud-setup.sh」上傳到伺服器。
  3. 在終端裡執行：sudo bash ejs-cloud-setup.sh
     想自己定密碼：sudo bash ejs-cloud-setup.sh 你的密碼（只能用英文字母和數字）
     有域名的話（先在域名解析裡把它指向這臺伺服器的 IP）：sudo bash ejs-cloud-setup.sh 你的域名
     例如 sudo bash ejs-cloud-setup.sh example.site。之後地址就是 https://你的域名:8765，
     原來的 IP 地址照樣能用，各臺電腦連上後會自動換成域名地址（以後伺服器換了 IP，只要改域名解析）。
  4. 執行完會顯示伺服器地址（https://開頭）和房間密碼，填到上面的設定裡。
     以前填的 http 地址不用改，EmulatorJS 會自動換成 https，設定裡顯示「🔒 已加密連線」。
  伺服器重啟後會自動執行。
  更新伺服器：EmulatorJS 更新後，把新的「cloud-server/ejs-cloud-setup.sh」再上傳一次（覆蓋舊的），
  執行 sudo bash ejs-cloud-setup.sh 即可，密碼不變，正在玩的人會斷開一下，重新亂入就好。
  （注意：這樣會用新版的遮蔽詞檔案覆蓋伺服器上的，自己在伺服器上加過的詞要重新加。）
  管理賬號：在伺服器的終端裡執行 sudo ejs-admin，出現英文選單後按數字選擇：
    檢視 / 搜尋使用者、重置密碼、改名字、封禁 / 解封、刪除賬號、檢視 / 刪除勝負記錄。
    選單 10「Server limits」可以設定伺服器上限：最多同時線上人數、最多房間數、網路中轉的速度上限。
    選單 11「Developer (admin) account」建管理員專用賬號「开发者」或「Developer」：名字裡帶這兩個詞的，
    玩家不能註冊、也不能冒用；用這個賬號登入後，你的名字在大廳、房間、排行榜裡都會彩色 + 🛠 高亮顯示。
  （封禁後不能登入，已登入的會馬上退出；刪除賬號會連同好友和勝負記錄一起刪除，不能恢復。）

【大廳】
  左側「正在遊戲」旁邊點「⤢ 大廳」（手機上點右上角的 🕹），開啟全屏的大廳：
  · 「正在遊戲」：所有區域網、外網正在玩的局，可以搜尋遊戲名或玩家名，按「可以亂入 / 擂臺 / 格鬥 /
    好友 / 區域網 / 外網」篩選。每一局都可以「亂入」或「👀 觀戰」（觀戰的人只能看，不能操作）。
  · 「🌐 線上玩家」：外網聯機伺服器上現在所有線上的人（開啟了程式、連著這個伺服器的都算），顯示國旗、名字、
    是不是註冊玩家，以及在玩什麼還是在大廳裡；正在玩的可以直接「亂入」或「👀 觀戰」。左邊的「🌐 大廳」按鈕上
    會顯示「線上 37/200 人」（現在人數 / 伺服器的上限）。伺服器是舊版本時看不到，請伺服器管理員重新執行一次安裝指令碼更新。
  · 「好友」「排行榜」「我的戰績」：要先登入賬號（見下面）。

【賬號、好友、戰績】（需要外網聯機伺服器）
  不註冊也能玩、能聯機；註冊賬號後才有戰績和好友。
  · 註冊：大廳右上角點「註冊」，填名字（2～16 個字，不能有不文明的詞）、密碼（至少 6 位），選地區。
    賬號儲存在外網聯機伺服器上，換電腦登入也能用。登入後聯機時就用賬號的名字和地區（顯示國旗）。
  · 好友：在「好友」裡輸入對方的賬號名字發請求，對方同意後就是好友。
    能看到好友在不線上、在玩什麼，好友正在玩的局可以一點就亂入或觀戰。
  · 戰績：自動記錄玩了哪些遊戲、玩了多久、聯機了幾次、和誰一起玩過。
  · 勝負：聯機打完一局，畫面上方點「🏆 記錄勝負」選贏家，其他人會收到確認提示，
    所有人都點「對，確認」才算數；有人點「不對」，這條記錄就作廢。
  · 擂主：一個遊戲贏 10 場以上、勝率 60% 以上，就是這個遊戲的擂主，大廳里名字是金色的 👑。
  · 點贊：在大廳、好友列表、玩家資料或遊戲裡的「👥 房間」裡點 ♡ 給別人點贊，再點一下取消。
    排行榜裡的「♥ 最受歡迎」按收到的贊排名。
  · 擂臺：玩格鬥遊戲時，開局的人可以點畫面上方的「🥊 擂臺」，大廳裡會把這一局排在最前面，
    寫著“歡迎挑戰”，誰都可以來挑戰。
  · 手機、平板用區域網地址開啟的頁面，也能登入、看外網的局：請求會經過開局的那臺電腦轉發
    （那臺電腦要設定好外網聯機伺服器）。

【介面語言】
  左上角國旗按鈕可以切換介面語言：简体中文、繁體中文、English、日本語、한국어、Español、Français、
  Deutsch、Português、Русский。預設和電腦系統的語言一樣。
  遊戲名會同時顯示英文名和所選語言的譯名（有譯名時；街機遊戲大多有中文名）。
  翻譯在 data/i18n 資料夾裡（data/names.json 是遊戲譯名），可以自己修改。

其他辦法：
  · Parsec（https://parsec.app）遠端同屏：朋友連進你的電腦，看到你的畫面，他的手柄變成你電腦上的
    第二個手柄。朋友那邊不需要 ROM，也不用裝 EmulatorJS。
  · 如果雙方都裝了 RetroArch，也可以用 RetroArch 自帶的聯機功能。


九、BIOS
--------
  FC / NES、超任 SNES、世嘉 MD     不需要
  世嘉 Mega-CD                     必須要：bios_CD_U.bin（美版）、
                                   bios_CD_J.bin（日版）、bios_CD_E.bin（歐版）
  街機 (FBNeo)                     大部分不需要；Neo Geo 遊戲（拳皇、合金彈頭等）
                                   需要 neogeo.zip，PGM 遊戲需要 pgm.zip

  缺少 BIOS 時，點世嘉 CD 遊戲會提示「缺少 BIOS」。
  選好 BIOS 資料夾後，左上角會顯示「已找到 BIOS：世嘉 Mega-CD（U/J）」這類提示，
  字母表示有哪些地區的 BIOS。


十、常見問題
------------
  點了遊戲一直黑屏
    → 確認是雙擊啟動檔案開啟的（位址列顯示 http://127.0.0.1 或 http://localhost），
      而不是直接雙擊 index.html（位址列顯示 file://）。

  雙擊 EmulatorJS.command 沒反應（Mac）
    → 檔案的「可執行」許可權可能在傳輸時丟了。開啟「終端」，輸入
         chmod +x 
      （注意末尾有個空格），把 EmulatorJS.command 拖進終端視窗，按回車，再雙擊試試。

  Mac 上 EmulatorJS.command 沒有顯示遊戲手柄圖示
    → 雙擊執行一次就會自動設定。如果還是沒變，關掉訪達視窗再開啟（訪達有時不會馬上重新整理）。
      圖示檔案在 data/icon.png，不要刪掉。

  Windows 上沒有生成「EmulatorJS」快捷方式
    → 先雙擊 EmulatorJS-Windows.bat 執行一次，快捷方式會在同一個資料夾裡生成。
      確認 data 資料夾裡有 icon.ico，並且 start-windows.ps1 和 .bat 放在一起。

  個別遊戲啟動不了
    → 有些遊戲需要 BIOS（見第九節）；有些街機遊戲原本是給其他模擬器用的，
      網頁版的 FBNeo 跑不了，這類請用 RetroArch 玩。

  我的設定、賬號、存檔儲存在哪裡？
    → 賬號（名字、好友、戰績）：儲存在外網聯機伺服器上，換電腦、換手機都能登入；密碼只存加密後的結果。
      設定（資料夾、外網聯機伺服器地址和房間密碼）：儲存在每臺裝置自己的 config.json 裡——
        資料夾版（.command / .bat）：EmulatorJS 資料夾裡的 config.json
        Windows 桌面版：%APPDATA%\EmulatorJS\config.json
        Mac 桌面版：~/Library/Application Support/EmulatorJS/config.json
        安卓 App：App 自己的資料裡（解除安裝 App 或清除 App 資料會一起刪掉）
      登入狀態、玩家名字、介面語言、配色、背景圖片、最近玩過、遊戲存檔和即時存檔：儲存在瀏覽器裡
      （桌面版、安卓 App 儲存在程式自己的資料裡），每臺裝置各存各的，不會上傳到伺服器。
      換瀏覽器、清除瀏覽器資料或解除安裝程式後會丟失；存檔請用遊戲下方選單欄裡的「匯出存檔檔案」備份。
