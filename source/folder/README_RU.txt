EmulatorJS — руководство
================================

EmulatorJS запускает ретро-игры прямо в браузере. Устанавливать RetroArch не нужно, интернет тоже не нужен.
Поддерживается более двадцати платформ, среди них NES, Super Nintendo, Game Boy / GBA, N64, NDS,
Sega Mega Drive / Mega-CD / 32X / Saturn, PS1, PSP, PC Engine и аркадные автоматы (FBNeo / MAME 2003).


1. Что лежит в папке
--------------------
  index.html              Страница с играми (не открывайте её двойным щелчком)
  data/                   Эмуляторы и ядра — здесь ничего не трогайте
  EmulatorJS.command      Запуск на Mac
  EmulatorJS-Windows.bat  Запуск на Windows
  start-windows.ps1       Скрипт для запуска на Windows; держите рядом с .bat
  Enable-LAN-Windows.bat  Разрешение Windows для игры по локальной сети (появляется само при первом запуске;
                          запускайте вручную, только если тогда выбрали «Нет»)
  cloud-server/           Скрипт установки сервера для игры через интернет (только на облачном сервере, см. раздел 8)
  server.py               Небольшой локальный сервер, который использует запуск на Mac
  config.json             Создаётся при первом сохранении папок; запоминает ваши папки
  EmulatorJS.lnk          Ярлык со значком геймпада, который Windows создаёт при первом запуске
  LICENSE                 Лицензия EmulatorJS (GPL-3.0)
  README_RU.txt и др.     Это руководство, по файлу на язык: CN 简体中文, HK 繁體中文, US English, JP 日本語,
                          KR 한국어, ES Español, FR Français, DE Deutsch, BR Português, RU Русский


2. Как открыть
--------------
[Приложение для компьютера (рекомендуется)]
  Если не хотите пользоваться браузером и держать открытым окно терминала, используйте приложение: двойной щелчок
  открывает окно игры, закрытие окна — выход.
  · Windows: EmulatorJS-Setup-версия.exe устанавливает приложение (папку можно выбрать; ярлыки в меню «Пуск» и на рабочем столе);
    EmulatorJS-версия-win.zip работает без установки: распакуйте в любую папку и дважды щёлкните EmulatorJS.exe.
    Если в первый раз появится «Система Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае».
    Когда Windows спросит о доступе к сети, отметьте «Частные сети» и нажмите «Разрешить» (нужно для игры по сети).
  · Mac: …-mac-apple-silicon.dmg для чипов M1 / M2 / M3 / M4, …-mac-intel.dmg для Intel.
    Откройте dmg и перетащите EmulatorJS в «Программы».
    В первый раз macOS скажет, что не может проверить разработчика: «Системные настройки → Конфиденциальность и
    безопасность» → «Всё равно открыть».
    Когда приложение спросит про поиск устройств в локальной сети или микрофон, выберите «Разрешить»
    (нужно для игры по сети и голосового чата).
  · Папки с играми: roms, thumbnails и system в «Документы/EmulatorJS» и в обычных местах RetroArch находятся
    сами, или выберите их в «⚙ Папки». При первом запуске приложение перенимает настройки старой папки EmulatorJS.
  · Настройки хранятся в собственной папке данных приложения. Старые EmulatorJS.command / EmulatorJS-Windows.bat
    продолжают работать, и оба варианта могут играть вместе.
  · Файл настроек config.json (папки, адрес интернет-сервера и пароль комнаты) лежит здесь:
    Windows: %APPDATA%\EmulatorJS\config.json (введите %APPDATA%\EmulatorJS в адресную строку Проводника и нажмите Enter)
    Mac: ~/Library/Application Support/EmulatorJS/config.json (в Finder нажмите Shift+Cmd+G и вставьте путь)

[Телефоны / планшеты / Android TV (APK)]
  · Телефоны, планшеты, телевизоры и ТВ-приставки: EmulatorJS-версия-android.apk.
    Эмуляторы Android на компьютере (MuMu и др.): EmulatorJS-версия-android-x86_64.apk.
    Нужен Android 7.0 или новее. Если «Android System WebView» на телевизоре слишком старый, приложение предложит обновить его.
  · Установка: перенесите apk на телефон / телевизор (кабель USB, флешка или мессенджер) и откройте его в файловом менеджере.
    Если Android пишет, что установка неизвестных приложений запрещена, разрешите её этому файловому менеджеру и откройте apk снова.
    Телевизор: скопируйте apk на флешку, вставьте её в телевизор и откройте apk файловым менеджером телевизора.
  · При первом запуске разрешите доступ к фото и файлам (память), иначе приложение не сможет читать игры.
    Потом приложение создаст «Память устройства / EmulatorJS» с папками roms, thumbnails и system.
  · Как добавить игры: подключите телефон к компьютеру кабелем (на телефоне выберите «Передача файлов») и скопируйте игры
    в EmulatorJS / roms так же, как на компьютере (раздел 3); обложки — в thumbnails, BIOS — в system.
    Затем нажмите «↻ Перечитать». Игры можно хранить и в другом месте: выберите папки в «⚙ Папки», там есть
    кнопки-ярлыки «Память устройства», «Загрузки» и другие.
  · Флешка в телевизоре: папка EmulatorJS или RetroArch (с roms и т. д.) в корне флешки находится сама,
    или нажмите «Флешка / карта памяти» в «⚙ Папки». После смены содержимого нажмите «↻ Перечитать».
    Android не разрешает приложениям записывать на флешку: игры, скачанные у других игроков при игре по сети,
    сохраняются в «EmulatorJS / downloads» и показываются вместе с играми с флешки.
  · Управление:
    Телефон: кнопки на экране или Bluetooth / USB-геймпад.
    Телевизор: выбирайте игру пультом (стрелки — перемещение, OK — открыть, «Назад» — назад), играйте геймпадом.
    В игре кнопка «Назад» на пульте или телефоне (или удержание Select + Start на геймпаде) открывает меню игры:
    продолжить, быстрое сохранение, быстрая загрузка, сброс, полный экран, выйти из игры.
    В списке игр нажмите «Назад» два раза, чтобы закрыть приложение.
  · Игра по сети, лобби и аккаунты работают так же, как на компьютере, можно играть вместе с компьютерами
    (в локальной сети — через один Wi-Fi). Голосовой чат в первый раз попросит микрофон: выберите «Разрешить».
  · Дешёвые ТВ-приставки медленные: NES, SNES, GBA и Mega Drive идут плавно; N64, PSP, NDS и Saturn могут тормозить.

[Mac]
  1. Дважды щёлкните по EmulatorJS.command.
     Если в первый раз появится сообщение, что его «нельзя открыть, так как разработчик не подтверждён»:
     правый щелчок → «Открыть» → ещё раз «Открыть». Дальше хватит двойного щелчка.
  2. Откроется окно «Терминала», а браузер сам покажет страницу с играми.
     Если macOS предложит установить «инструменты разработчика командной строки», нажмите «Установить», а потом
     снова дважды щёлкните по файлу запуска.
  3. Не закрывайте окно «Терминала», пока играете; закройте его, когда закончите.
  Файл запуска сам получает значок геймпада. Если значок пропал при копировании, запустите файл один раз —
  и он вернётся.

[Windows]
  1. Дважды щёлкните по EmulatorJS-Windows.bat.
     Если появится синее окно «Система Windows защитила ваш компьютер»: «Подробнее» → «Выполнить в любом случае».
  2. Откроется чёрное окно командной строки, а браузер сам покажет страницу с играми.
  3. Не закрывайте это окно, пока играете; закройте его, когда закончите.
  Windows не позволяет задать значок для .bat-файла. Поэтому после первого запуска в папке появится ярлык
  «EmulatorJS» со значком. Дальше пользуйтесь им — его можно перетащить на рабочий стол.
  Если переместить папку, ярлык перестанет работать; двойной щелчок по .bat создаст его заново.

Почему окно должно оставаться открытым?
  В нём работает маленький веб-сервер, доступный только с этого компьютера. Из соображений безопасности браузеры
  не дают странице, открытой двойным щелчком, читать файлы эмулятора, — поэтому страница открывается через этот
  сервер. Закроете окно — сервер остановится.

[Обновление до новой версии]
  · При запуске (и затем каждые 6 часов) EmulatorJS проверяет, есть ли новая версия; если есть, появляется окно со списком
    изменений, а рядом с номером версии на левой панели — «🆕 Новая версия». Нажмите номер версии, чтобы проверить вручную
    в любой момент. Во время игры окно не появляется.
  · Установленная версия для Windows (через EmulatorJS-Setup-<версия>.exe): нажмите «Обновить автоматически». Новый установщик
    скачивается и проверяется на целостность; затем «Установить сейчас»: EmulatorJS закроется, установит новую версию и сам
    откроется снова (около полуминуты). Игры, настройки и сохранения останутся.
    Если загрузка очень медленная (дольше примерно 5 минут) или не удалась, будет предложен Baidu Netdisk.
  · Mac, zip-версия для Windows, версия-папка, Android: нажмите «Скачать новую версию» (или Baidu Netdisk — лучше в Китае)
    и замените старую версию, как подсказывает окно (Mac: перетащите новый EmulatorJS в «Программы» и выберите «Заменить»;
    версия-папка: скопируйте новые файлы поверх старой папки).
  · Загрузки: https://github.com/supwang/emulatorjs-releases/releases
    Baidu Netdisk: https://pan.baidu.com/s/13atBCqmTib1rGp_30279mQ?pwd=6akk (код 6akk)
  · Не нужна какая-то версия? Нажмите «Пропустить эту версию». При проверке читается только информация о версии на сайте
    загрузок; ничего не отправляется.


3. Папки с играми (настраиваются один раз)
------------------------------------------
При открытии страница сама читает три папки, так что выбирать их каждый раз не нужно:

  Папка ROM       Основная папка с вашими играми (обязательно)
  Папка обложек   Папка thumbnails из RetroArch (необязательно, показывает обложки)
  Папка BIOS      Папка с файлами BIOS (необязательно, нужна лишь некоторым платформам, см. раздел 9)

[Автопоиск] Ненастроенные папки ищутся в таком порядке и сразу используются:
  1. Внутри папки EmulatorJS (рядом с EmulatorJS.command и EmulatorJS-Windows.bat):
     папки roms, thumbnails и system (папку BIOS можно назвать и bios)
  2. Стандартные папки RetroArch
     Mac: roms, thumbnails, system в ~/Library/Application Support/RetroArch/
     Windows: %APPDATA%\RetroArch, или roms, thumbnails, system в RetroArch-Win64, RetroArch,
              Games\RetroArch-Win64 и т. п. на дисках C:/D:/E:/F:
  То есть если RetroArch стоит в стандартном месте, играть можно с первого же запуска.
  Чтобы поделиться сборкой, можно положить папки roms, thumbnails и system прямо в папку EmulatorJS —
  тогда останется распаковать, открыть и играть.

[Ручная настройка] Нажмите «⚙ Папки» в левом верхнем углу:
  1. У каждого пункта нажмите «Обзор…», перейдите к нужной папке и нажмите «Выбрать эту папку».
     Наверху есть быстрые переходы: «Домашняя папка», «Рабочий стол», «RetroArch».
     Можно также вставить путь к папке.
  2. Нажмите «Сохранить и загрузить игры». Настройки сохранятся в config.json и будут действовать всегда.
  - «Очистить» и сохранить — вернуться к автопоиску.
  - Если настроенная папка больше не находится (например, на другом компьютере), снова включается автопоиск,
    а страница настроек сообщит об этом.

[Автоматическая загрузка картинок]
  Для игр без обложки EmulatorJS может скачать обложки, титульные экраны и скриншоты из коллекции сообщества libretro
  (libretro-thumbnails, та же, что у RetroArch) в вашу папку с картинками (если её нет, рядом с папкой ROM создаётся папка «thumbnails»).
  · Когда впервые находятся игры без обложек, программа спрашивает; если согласиться, картинки будут скачиваться и для новых игр.
  · Включается и выключается в «⚙ Папки» → «Скачивать картинки автоматически», есть и кнопка «⬇ Скачать недостающие картинки сейчас».
  · Картинки ищутся по названию игры (аркады — по полному названию FBNeo); лучше всего работают стандартные имена в стиле No-Intro,
    переименованные или переведённые имена могут не найтись.
  · Нужен доступ к GitHub. Ход загрузки виден слева вверху, её можно «Остановить». Коллекцию собрало сообщество;
    права на картинки принадлежат компаниям-разработчикам.

[После добавления новых игр] Нажмите «↻ Перечитать» в левом верхнем углу — открывать страницу заново не нужно.

[Как новые игры распределяются по платформам]
  Платформа каждой игры определяется в таком порядке; засчитывается первый сработавший шаг:
  1. Платформа, указанная в плейлисте RetroArch (в комплекте уже есть список игр)
  2. Платформа, выбранная раньше (выбрав её один раз в «Нужно выбрать платформу вручную», вы её закрепите)
  3. Расширение файла: .nes .sfc .smc .md .gen .gba .gb .n64 .nds и т. п.
  4. Содержимое файла:
     - Архивы (.zip): что внутри — например, .sfc означает Super Nintendo, .md — Mega Drive
     - Образы дисков / картриджей (.bin .iso .cue): метка в начале файла, по которой узнаются
       Mega Drive, Mega-CD, Saturn, PS1 и другие
  5. Имя папки: snes, md, fbneo, «Nintendo - Super Nintendo Entertainment System» и т. п.
  6. Архив без известного формата картриджа → считается аркадной игрой
  7. То, что так и не опознано (например, .7z, .chd), попадает в «Нужно выбрать платформу вручную»;
     выбрать достаточно один раз
  Аркадные игры ещё сверяются с официальным списком FBNeo (более 8000): если имени файла в нём нет (например,
  cvs2.zip от NAOMI), FBNeo его не запустит, и игра попадёт в «Не поддерживается в веб-версии».
  Так что даже если все игры свалены в одну папку, большинство окажется на нужной платформе.
  Читаются только начало файлов и оглавление архивов, поэтому это быстро; результаты запоминаются, и в следующий
  раз ничего определять заново не нужно.

Советы:
  - Лучше всего сделать в папке ROM по подпапке на платформу, например snes, md, nes, fbneo, или назвать их
    как в RetroArch: «Nintendo - Super Nintendo Entertainment System», — тогда платформы определятся сами.
  - Если в левом верхнем углу вместо «⚙ Папки» видны три кнопки вроде «Выбрать папку ROM», страница открыта
    неправильно или через старое окно запуска: закройте все окна «Терминала» / командной строки и откройте
    заново через файл запуска.


4. Игра
-------
  1. Слева — список платформ, у каждой картинка приставки. У игр Neo Geo свой пункт «Neo Geo»; остальные
     аркадные игры — в «Аркада (FBNeo)».
     Нажмите на платформу, чтобы справа увидеть обложки всех её игр.
     «🕘 Недавние игры» в самом верху — последние 10 игр на этом компьютере; нажмите, чтобы сыграть снова.
     Чтобы убрать игру из списка: наведите мышь на обложку и нажмите ✕ в углу (геймпад: выберите и нажмите X; клавиатура: Delete).
     «Очистить список» убирает все.
     Если навести мышь на игру, картинки сменяются: обложка → титульный экран → скриншот. Точки под обложкой
     показывают, сколько их и какая сейчас видна; уберёте мышь — останется текущая.
     (Отсутствующие картинки пропускаются; у игр с одной картинкой ничего не меняется.)
     Размер обложек: выберите «S / M / L / XL» в правом верхнем углу стены обложек. Каждая платформа запоминает свой размер.
  2. Нажмите на обложку, чтобы запустить игру.
  3. «Выйти из игры» в правом верхнем углу возвращает к стене обложек.
  4. Через поле поиска можно найти игру по названию.
  5. Внизу левой панели «⌨ Горячие клавиши» перечисляет клавиши клавиатуры и кнопки геймпада для монеты, «Старт»,
     сброса, паузы, турбо, сохранения / загрузки состояния и сервисного меню аркады. Нажатие на заголовок
     сворачивает / разворачивает список; выбор запоминается.
  6. Цветовая тема: нажмите 🎨 рядом с «EmulatorJS» в левом верхнем углу и выберите одну из 7 тем
     (Детство [по умолчанию: игровой зал на закате, с фоновой картинкой], Ночной зал [тёмная], Синий Sega [яркая синяя], Зелёный Game Boy, Серо-фиолетовый SNES [светлая],
      Кремовый картридж [светлая], Конфетно-розовая [светлая]).
     Фон, текст и кнопки меняются вместе; выбор запоминается.
     В той же панели есть «Фоновое изображение»: выберите картинку на компьютере, и она появится за списком игр
     справа (при прокрутке не двигается). Можно задать общую картинку и/или свою для любой платформы (платформы без
     своей используют общую). Ползунок «Затемнение» делает картинку темнее, чтобы текст хорошо читался. Картинки
     хранятся только в этом браузере на этом устройстве.
     Во время игры пустое место по бокам показывает ту же картинку (затемнённую и размытую), так что у вертикальных игр
     нет чёрных полос; отключается в той же панели.
  7. Язык: нажмите на флаг в левом верхнем углу (см. «Язык интерфейса» в разделе 8).

  - «Нужно выбрать платформу вручную»: игры, платформу которых определить не удалось. Выберите платформу,
    и игра перейдёт в эту группу.
  - «Не поддерживается в веб-версии»: игры, которые браузерная версия запустить не может (например, Sega NAOMI).
    Не хотите видеть этот список? Откройте его и нажмите «Скрыть этот список» справа вверху или снимите галочку в «⚙ Папки».
    В них играйте в RetroArch.

Кнопки, сохранения, состояния, полный экран и т. п. — в строке меню под игрой.
«Control Settings» показывает и меняет назначение клавиш, поддерживает и геймпады.
Сохранения хранятся в браузере; они пропадут, если сменить браузер или очистить его данные.
Для резервной копии используйте «Export Save File» в меню.

Читы: в строке меню «Читы» (Cheats) → «Добавить чит» (Add Cheat), введите код и описание, отправьте и поставьте галочку,
чтобы включить (ещё раз — выключить). Формат кода зависит от платформы: Game Genie для NES, Action Replay / GameShark для GBA и т. д.;
ищите в интернете «<название игры> читы». Некоторые читы до конца отменяются только перезапуском игры.
При игре по сети с другими игроками читы выключаются автоматически, а кнопка скрывается; когда вы снова играете один, они возвращаются.

Библиотека читов: вверху меню «Читы» (Cheats) нажмите «📚 Выбрать из библиотеки читов (libretro)». Программа найдёт читы для этой игры
(из базы данных сообщества libretro, libretro-database: много для NES, SNES, Mega Drive, GBA и других консолей, для аркад почти нет);
отметьте нужные, нажмите «Добавить выбранные читы» и отметьте их в «Читы», чтобы включить.
Во время сетевой игры тоже недоступно. Нужен доступ к GitHub.


5. Клавиатура и геймпад
-----------------------
[Клавиши по умолчанию] (игрок 1)

  Направления         W вверх   S вниз   A влево   D вправо
  Старт               Enter
  Select / монета     V

  NES                 J = A    K = B
  Super Nintendo      J = A    K = B    I = X    L = Y    U = плечевая L    O = плечевая R
  Mega Drive / CD     нижний ряд J K L = A B C        верхний ряд U I O = X Y Z
  Аркада Neo Geo (The King of Fighters, Metal Slug, Samurai Shodown и др.)
                      J = A    K = B    I = C    L = D
                      U = A+B вместе    O = C+D вместе    (у A+B+C и B+C+D по умолчанию нет клавиши)
  Аркада (прочие)     J K I L = кнопки 1 2 3 4    U O = кнопки 5 6
  Аркада (файтинги с 6 кнопками: Street Fighter, Darkstalkers, Marvel)
                      Слабый удар рукой J    Средний удар рукой K    Сильный удар рукой L
                      Слабый удар ногой U    Средний удар ногой I    Сильный удар ногой O
                      (3 удара рукой / 3 удара ногой вместе по умолчанию без клавиши)

  Пауза / продолжить  правый Shift
  Турбо вкл/выкл      T
  Сброс игры          V + Enter + U + O одновременно (многоигровые картриджи вернутся в меню выбора игры)
  Сохранить состояние 1    Загрузить состояние 2    Сменить слот 3
  (Ускорение, замедление и перемотка назад по умолчанию без клавиш; назначьте их в «Control Settings»)

  - Аркадные игры выбирают раскладку по имени файла ROM. Сейчас 6-кнопочную раскладку используют:
      Street Fighter (sf), Street Fighter II' Champion Edition (sf2ce), Street Fighter Alpha 3 (sfa3),
      Street Fighter III 3rd Strike (sfiii3), Street Fighter EX2 Plus (sfex2p),
      Darkstalkers (dstlk), Night Warriors (nwarr), Vampire Savior 2 (vsav2)
    Остальные аркадные игры (включая Neo Geo — KOF, Metal Slug) используют раскладку J K I L.
    Новые игры серий Street Fighter, Darkstalkers и Marvel (X-Men, Marvel) тоже распознаются как 6-кнопочные.
  - Клавиши меняются в «Control Settings» в строке меню под игрой.

[Кнопки в «Control Settings»]
  Кнопки названы как на оригинальном контроллере платформы и всегда идут в таком порядке:
    Монета / Select → Старт → направления → кнопки → комбинации → сохранение состояния, ускорение и прочее

  NES                 Select, Start, направления, A, B
  Super Nintendo      Select, Start, направления, A, B, X, Y, L, R
  Mega Drive / CD     MODE, Start, направления, A, B, C, X, Y, Z
  Аркада Neo Geo      Монета, Старт, направления, A, B, C, D
                      Комбинации: A+B, C+D, A+B+C, B+C+D
  Аркадные файтинги   Монета, Старт, направления, слабый / средний / сильный удар рукой,
                      слабый / средний / сильный удар ногой
                      Комбинации: 3 удара рукой вместе, 3 удара ногой вместе
  Аркада (прочие)     Монета, Старт, направления, кнопки 1–6

  - Комбинация — это одна кнопка, которая нажимает несколько кнопок сразу. У настоящего Neo Geo есть только
    A B C D; комбинации — добавка эмулятора, чтобы проще делать спецприёмы и уклонения
    (например, A+B — уклонение, C+D — отброс в KOF).
  - Считается ли аркадная игра Neo Geo или 6-кнопочным файтингом, решается по имени файла ROM и полному названию.
  - Настройки сохраняются для каждой игры отдельно: клавиши, фильтры и т. п., изменённые в одной игре, действуют
    только в ней и применятся в следующий раз; у остальных игр остаётся раскладка выше.
  - Сохранения (и состояния) хранятся отдельно от этих настроек и друг на друга не влияют.
  - Кнопки геймпада не зависят от раскладки клавиатуры выше — см. [Геймпад] ниже.

[Геймпад]
Подходят обычные контроллеры: Xbox, PS4 / PS5, Switch Pro и большинство USB- / Bluetooth-геймпадов.

  1. Подключите геймпад к компьютеру по USB или Bluetooth.
  2. В игре сначала нажмите любую кнопку на геймпаде — только после этого браузер его увидит
     (правило конфиденциальности браузеров).
  3. По умолчанию кнопки как в RetroArch (контроллер Xbox; слева — кнопка в игре):
       NES / SNES   B → A (низ)      A → B (право)    Y → X (лево)    X → Y (верх)
       Mega Drive   A → X (лево)     B → A (низ)      C → B (право)
       Neo Geo      A → A (низ)      B → B (право)    C → X (лево)    D → Y (верх)
       Файтинги     Слабый рукой → X (лево)   Средний рукой → Y (верх)   Слабый ногой → A (низ)   Средний ногой → B (право)
                    Сильный рукой → LB   Сильный ногой → RB
     (Сам EmulatorJS по умолчанию меняет местами A и B на геймпаде; здесь сделано как в RetroArch.)
     Если какая-то кнопка не та, откройте «Control Settings» в строке меню под игрой и переназначьте её.
     До 4 игроков, у каждого свой геймпад. Настройки сохраняются в браузере.

  - Рекомендуются Chrome или Edge — геймпады в них работают лучше всего.
  - В аркадных играх монета и «Старт» обычно — Select / View и Start / Menu на геймпаде.
  - Сброс игры: Select + Start + LB + RB одновременно (на PlayStation — Share + Options + L1 + R1).
    Так можно вернуться в меню многоигровых картриджей NES. Работает на всех платформах.
  - Левый стик работает как крестовина (наклон больше половины считается нажатием; диагонали тоже работают),
    и их можно смешивать.
  - Турбо вкл / выкл: нажмите правый стик (R3).
  - Выбор игр без мыши (геймпад, клавиатура или пульт телевизора):
      крестовина / левый стик / стрелки: перемещение между обложками и кнопками; A / Enter: подтвердить (начать игру,
      нажать кнопку); B / Esc / «Назад» на пульте: вернуться или закрыть открытую панель; LB / RB: предыдущая / следующая
      платформа; Start: открыть или закрыть лобби.
  - Меню игры: во время игры удерживайте Select + Start полсекунды («Назад» на пульте телевизора) — продолжить,
    сохранить состояние, загрузить состояние, сбросить, полный экран или выйти. В одиночной игре на время меню ставится
    пауза; в сетевой игре пауза не ставится, а подключившиеся игроки не видят сохранение, загрузку и сброс.

[Турбо]
  1. В игре нажмите наверху «Настройки турбо» и отметьте кнопки, которые в этой игре должны стрелять очередью.
     Пример для шутера: отметьте выстрел, а кнопку заряда не отмечайте — удерживаемый выстрел будет частить,
     а удерживаемая кнопка заряда будет заряжать как обычно.
  2. Включить турбо: в «Настройки турбо» нажмите «Включить турбо» или в игре нажмите T на клавиатуре / R3 на
     геймпаде. Пока турбо включено, в левом верхнем углу игры горит «ТУРБО ВКЛ», а кнопка показывает «Турбо · вкл».
  3. Отметьте «Включать турбо при запуске этой игры», и в следующий раз оно уже будет включено — без T / R3.

  - Настройки сохраняются для каждой игры; достаточно один раз настроить каждую. По умолчанию отмечены все
    кнопки, а само турбо не включается.
  - Турбо срабатывает примерно 15 раз в секунду. Направления, «Старт» и монета не затрагиваются.
  - Работает на всех платформах, с клавиатурой и с геймпадом.
  - Если после закрытия «Настройки турбо» кнопки не реагируют, щёлкните один раз по экрану игры.


6. Настройки аркады: сервисное меню, сложность, жизни, режим Neo Geo
-------------------------------------------------------------------
Эти настройки — в строке меню под игрой: «Settings» (шестерёнка) → «Backend Core Options».
После изменения нажмите в строке меню «Restart», чтобы оно вступило в силу. Сохраняются для каждой игры.

[Сервисное меню аркады (Test Mode)]
  В игре удерживайте «Старт» (Enter) около 2 секунд, чтобы открыть сервисное меню платы.
  Там настраиваются сложность, жизни, время, продолжения и т. п. (набор зависит от игры).
  Способ вызова меняется в пункте «diagnostic input» параметров ядра, например на удержание Select.

[Сложность, жизни (DIP-переключатели)]
  Во многих аркадных играх сложность и жизни задаются DIP-переключателями на плате.
  Ищите в параметрах ядра пункты со словом «Dipswitch», например:
    Difficulty (сложность)   Lives (жизни)   Bonus Life (дополнительная жизнь)
  У каждой игры свои переключатели, у некоторых их нет вовсе.

[Режим на 3–4 игроков]
  - Captain Commando: автомат с завода стоит в режиме 2 игроков; эта программа по умолчанию включает режим 4 игроков
    («Dipswitch Play Mode» в настройках ядра — там же можно вернуть как было).
  - Knights of the Round, The King of Dragons, Mercs: уже с завода режим 3 игроков, менять ничего не нужно.
  - Warriors of Fate, Cadillacs & Dinosaurs и другие игры CPS1 с Q-Sound: число игроков задаётся не DIP-переключателем,
    а в сервисном меню игры. Если третий игрок не может войти, загляните в CONFIGURATION сервисного меню
    (удерживайте Start около 2 секунд).
  - При игре по сети у всех должны быть одинаковые настройки этой игры (иначе будут сообщения о рассинхронизации),
    поэтому лучше всем пользоваться последней версией.

[Neo Geo: аркадный / домашний режим]
  Здесь игры Neo Geo (KOF, Metal Slug, Samurai Shodown и др.) по умолчанию запускаются в аркадном режиме
  (MVS, Европа/Азия):
    - Как в игровом зале: бросьте монету клавишей V и начните клавишей Enter;
    - Пока один играет, другой может в любой момент бросить монету и нажать «Старт», чтобы вступить
      (по сети так же);
    - Сложность, жизни и т. п. задаются в сервисном меню аркады (см. выше).
  Для домашнего режима найдите в параметрах ядра «mode» (Neo-Geo mode):
    MVS_EUR / MVS_USA / MVS_JAP  Аркадная версия (Европа-Азия / США / Япония), с монетами   ← по умолчанию MVS_EUR
    AES_EUR / AES_JAP            Домашняя версия (английская / японская), без монет; сложность и жизни —
                                 в Option на титульном экране
    DIPSWITCH                    Значение по умолчанию самой игры (обычно аркадная версия)
    UNIBIOS                      Расширенный BIOS от энтузиастов (читы, смена региона и т. п.)
  Выбор запоминается для каждой игры: игра в домашнем режиме и в следующий раз будет в домашнем режиме.
  По сети у всех должен быть одинаковый режим этой игры, иначе картинка разойдётся.
  Примечание: в neogeo.zip должен быть нужный BIOS (в полном neogeo.zip для FBNeo он обычно есть);
  если его нет, игра вернётся к режиму по умолчанию.


7. Фильтры (эффекты изображения)
--------------------------------
В игре нажмите в строке меню внизу «Settings» → «Graphics Settings» → «Shaders» и выберите фильтр —
эффект виден сразу:

  CRT easymode       Старый кинескопный телевизор со строками развёртки, мягкая картинка — хорош для начала
  CRT geom           Кинескоп с выпуклым экраном и тёмными углами — ближе всего к старому телевизору
  CRT aperture       Имитирует апертурную решётку, чёткая картинка
  CRT mattias        Имитирует лёгкую размытость и растекание цвета телевизионного сигнала
  2xScaleHQ          Скругляет и сглаживает края пикселей
  4xScaleHQ          То же, сглаживание сильнее
  Disabled           Без фильтра, исходные пиксели

  - Фильтры сохраняются для каждой игры: выбрав один раз, вы получите его и в следующий раз;
    другие игры настраиваются отдельно.
  - CRT-фильтры лучше всего смотрятся в полноэкранном режиме; в маленьком окне строки слишком частые.
  - На старых компьютерах CRT geom может подтормаживать; CRT easymode работает легче.


8. Игра вместе
--------------
[Игра по локальной сети (компьютеры в одной сети Wi-Fi / за одним роутером)]
Адреса пересылать не нужно: каждый дважды щёлкает по EmulatorJS.command (Mac) или EmulatorJS-Windows.bat
(Windows). В одной локальной сети список «🕹 Сейчас играют» слева показывает, кто во что играет на других
компьютерах, — нажмите «Подключиться», чтобы присоединиться.

  · Игра по локальной сети включена по умолчанию. Кто не хочет, чтобы его видели, нажимает «⚙ Папки» и снимает
    галочку «Игра по локальной сети».
  · Mac: в первый раз macOS может спросить, разрешить ли Python принимать входящие сетевые подключения, —
    выберите «Разрешить».
  · Windows: в первый раз появится «Разрешить этому приложению вносить изменения на вашем устройстве?» — выберите
    «Да» (спрашивается только один раз). Если вы выбрали «Нет», потом дважды щёлкните в папке по
    «Enable-LAN-Windows.bat» и снова откройте EmulatorJS.
  · После «Подключиться» вы продолжаете играть на своей странице, тем же файлом игры со своего компьютера.
    Если игры у вас нет (или ваш файл отличается), вы автоматически играете по картинке с чужого компьютера.
  · Игры с пометкой «другой компьютер» запущены на другом компьютере; остальные — из библиотеки этого.
  · Игры для приставок работают так же: если игра есть в списке, нажмите «Подключиться».
  · В «Я: …» можно сменить имя; его видят другие в списке.
    Имя не может содержать мат и другие оскорбительные слова и не может совпадать с именем того, кто сейчас
    играет (регистр, пробелы и символы не учитываются).
    Имя с оскорбительными словами автоматически заменяется на «Игрок» с номером.
    Запрещённые слова лежат в data/badwords.json — редактируйте текстовым редактором (одно слово на элемент).
    На сервере для игры через интернет это /opt/emulatorjs-cloud/data/badwords.json; изменения действуют сразу,
    без перезапуска.

Устройства без EmulatorJS (планшеты, чужие компьютеры):
  Введите в браузере адрес компьютера, на котором работает EmulatorJS (он указан на левой панели, например
  http://192.168.1.23:8765), — увидите все игры этого компьютера и сможете присоединяться без ROM.
  Такие устройства не видят и не меняют настройки папок компьютера.
  Примечание: на страницах, открытых так, браузеры не дают доступ к микрофону, поэтому голосового чата нет
  (других вы при этом слышите).

Как устанавливается связь (выбирается само, настраивать ничего не нужно):
  · Синхронизация нажатий (экспериментально, приоритетно): кто присоединяется, запускает ту же игру у себя;
    по сети передаются только кнопки, нажатые в каждом кадре, — тот же принцип, что у Netplay в RetroArch.
    Каждый компьютер сам считает картинку, поэтому она чёткая, а трафика почти нет.
    При подключении к игре «другого компьютера» используется тот же файл игры с вашего компьютера; страница,
    открытая по адресу в локальной сети, сама читает файл игры с компьютера хоста, так что ROM вам не нужен.
    Чтобы нажатия успевали дойти, кнопки у всех срабатывают на несколько кадров позже
    (в локальной сети около 2–3 кадров — почти незаметно).
    Каждые 2 секунды состояние игры сверяется; если оно разошлось, хост рассылает всем сохранённое состояние для
    выравнивания. Картинка может на мгновение мигнуть или прыгнуть — это нормально.
  · Видеотрансляция: компьютер хоста передаёт изображение и звук в реальном времени, а нажатия гостя идут обратно.
    Включается сама, если у присоединившегося нет того же файла игры.
  Хост — это P1; присоединившиеся становятся P2, P3, P4 — до 4 игроков (если игра это поддерживает).
  Сколько человек может играть, зависит от платформы: 2 — NES, PS1, Neo Geo и т. п.; 4 — SNES, Mega Drive, N64, другие
  аркады и PC Engine; 1 — портативные (GB / GBA / NDS / PSP и т. п.). Если мест нет, можно смотреть.
  «2/2 игроков · 👀 1» в «Сейчас играют» значит: сейчас 2 игрока / максимум 2, и ещё 1 зритель.
  Гости играют своей клавиатурой или геймпадом с той же раскладкой, что и в одиночной игре.
  В локальной сети задержка очень мала, но слабый Wi-Fi вызывает рывки; хосту лучше подключиться кабелем.

При синхронизации нажатий учтите:
  · Хост ставит паузу для всех правым Shift; гости поставить паузу не могут.
  · Только хост может сбросить игру (Select+Start+L1+R1) или загрузить состояние; после этого все
    синхронизируются сами.
  · Рядом с именем каждого игрока видна его задержка до хоста (зелёный — быстро, жёлтый — нормально, красный — медленно;
    «Через ретранслятор», если связь идёт через ретранслятор). Её видят все. Если кто-то долго красный и тормозит всех,
    хост может выгнать его в «👥 Комната».
  · Значок 📶 вверху показывает соединение: напрямую или через ретранслятор, время туда-обратно в мс и на
    сколько кадров задерживаются кнопки (подстраивается само). Если цифры долго большие, подключитесь кабелем
    или приостановите большие загрузки. Всем лучше использовать последнюю версию.
  · Все должны оставаться на странице игры. Если кто-то переключит окно или свернёт его, встанут все.
  · Если у кого-то подвисает связь, все замедляются, а наверху появляется «Ждём соединения X…».
  · Если картинка то и дело расходится, обычно у этой игры разные настройки (параметры ядра, например
    домашний/аркадный режим Neo Geo, сложность) — сделайте их одинаковыми.
  · Проверено на NES и Mega Drive. Другие системы тоже должны работать, но проверены не все;
    неполадки исправляются автоматически.

Два способа играть вместе: задержка / откат (только при синхронизации кнопок; решает хост)
  Выбирается в «⚙ Папки» → «Режим сетевой игры»; во время игры его можно переключить и в «👥 Комната».
  · Режим задержки (по умолчанию, стабильный): способ, описанный выше. Кнопки у всех срабатывают на несколько
    кадров позже; картинка у всех всегда одинаковая, без скачков даже при плохой сети.
  · Режим отката (отзывчивый, экспериментальный): ваши кнопки срабатывают почти сразу (всего на 2 кадра позже).
    Пока кнопки другого игрока не дошли, игра считает, что он держит то же, что и раньше; когда настоящие
    кнопки приходят и догадка оказалась неверной, она загружает сохранение нескольких кадров назад и мгновенно
    переигрывает эти кадры с правильными кнопками. Поэтому иногда персонаж другого игрока «перескакивает» на
    нужное место. Так работает большинство сетевых файтингов.
    · Лучше всего при задержке сети туда-обратно до 100 мс; при большей движения другого игрока будут часто
      скакать, и лучше режим задержки.
    · Каждый кадр делается лишнее сохранение, поэтому компьютеры должны быть достаточно быстрыми: если какой-то
      не справляется, игра сама возвращается к режиму задержки и сообщает об этом.
    · У всех должна быть новая версия; если у кого-то старая, в этой игре используется режим задержки.
    · Если игра в режиме отката постоянно рассинхронизируется (3 раза за минуту), она тоже возвращается к режиму задержки.
    · В режиме отката нельзя поставить паузу; 📶 наверху показывает «Откат». При переигрывании кадров иногда
      возможен короткий щелчок в звуке.

Телефоны и компьютеры вместе (медленные устройства):
  При синхронизации нажатий все идут кадр за кадром вместе, поэтому темп задаёт самое медленное устройство.
  Телефоны тянут аркадные игры (Neo Geo и др.) медленнее компьютеров, поэтому автоматически происходит следующее:
  · Телефон присоединяется к игре компьютера: телефон играет по транслируемой картинке. Игра идёт на компьютере,
    в его темпе. На телефоне появляются крестовина и кнопки.
  · Компьютер присоединяется к игре телефона: сначала картинки выравниваются, затем игра передаётся компьютеру,
    а телефон продолжает играть по картинке. При этом бывает пауза на секунду-две.
    Номера игроков сохраняются (телефон остаётся P1, компьютер — P2).
  · Аркада, PS1, N64 и похожие игры на телефонах и планшетах всегда считаются «медленными»; остальные игры
    оцениваются по измеренной скорости — это касается и очень старых медленных компьютеров.
  · Когда телефон играет в аркаду один, по умолчанию включены автоматический пропуск кадров и пониженная
    частота дискретизации звука, чтобы работало быстрее (иногда кадр не рисуется; скорость игры не меняется).

Если не хотите, чтобы кто-то присоединялся:
  В игре нажмите наверху кнопку «Вход: открыт», чтобы переключить на «закрыт». Тогда больше никто не войдёт,
  а в списке будет «Вход закрыт» (кто уже внутри, остаётся).
  По умолчанию используется ваш последний выбор.
  Если кто-то нажмёт на вашу игру, ему сообщат, что вход закрыт, и он сможет играть один.

Управление комнатой (👥 Комната):
  Во время игры нажмите наверху «👥 Комната», чтобы увидеть игроков и зрителей своей комнаты:
  · Разрешить зрителей: вкл / выкл. До 8 зрителей на игру, из них не больше 2 по видео
    (для каждого зрителя по видео ваш компьютер сжимает отдельное видео; если их много, игра тормозит).
  · Только зарегистрированные: если включить, без входа в аккаунт нельзя ни играть, ни смотреть
    (и в локальной сети тоже; нужен сервер для игры через интернет).
  · Выгнать: нажмите дважды (второе нажатие — подтверждение). Этот человек не сможет войти в ваши комнаты
    30 минут; его узнают по аккаунту, номеру устройства и сетевому адресу (другие из той же сети тоже
    могут не попасть к вам эти 30 минут).
  · ♡: поставить лайк другому игроку (у него должен быть аккаунт).

Примечания:
  · Хост должен оставаться на странице игры; переключение окна или сворачивание может заморозить картинку.
  · Когда хост выходит из игры, партия заканчивается, а гостей об этом уведомляют.
  · Сохранения хранятся на компьютере хоста. Турбо: при синхронизации нажатий действуют ваши настройки,
    при видеотрансляции — настройки хоста.
  · Игра по локальной сети работает только в одной сети; для друзей в других местах — см. ниже.

[Голосовой чат]
  Во время совместной игры нажмите наверху «🎤 Голос: выкл», чтобы включить и говорить с остальными
  (все слышат всех).
  · В первый раз браузер спросит про микрофон — выберите «Разрешить». Это запоминается: если вы однажды
    включали голос, в следующий раз он включится сам.
  · Выключение только не даёт другим слышать вас; вы по-прежнему их слышите.
  · Когда кто-то говорит, вокруг его имени наверху загорается кольцо.
  · Очень советуем наушники — иначе микрофон подхватит звук игры и голоса других и вернёт их эхом.
  · Микрофон работает, только если EmulatorJS открыт на вашем собственном компьютере (адрес 127.0.0.1);
    на страницах, открытых по адресу в локальной сети, например на планшете, браузеры его не разрешают.

[Игра с друзьями из других мест (сервер для игры через интернет)]
Чтобы играть с друзьями вне вашей сети, нужен «игровой сервер», доступный всем (например, облачный сервер).
Всё работает как в локальной сети: игры друзей появляются в «Сейчас играют» (с пометкой «Интернет»);
нажмите «Подключиться». Голосовой чат тоже работает.

Настройка каждого компьютера (один раз):
  «⚙ Папки» → «Сервер для игры через интернет»: введите адрес сервера (например, http://1.2.3.4:8765) и пароль
  комнаты, нажмите «Сохранить и проверить» — готово, когда появится сообщение о подключении.
  Это сохраняется в config.json в папке EmulatorJS: настройте сначала у себя, а потом отправьте друзьям всю
  папку — им ничего вводить не придётся.
  Внимание: в config.json записан пароль комнаты, поэтому любой, кто получит папку, сможет зайти на ваш сервер —
  отправляйте её только тем, кому доверяете. Если не хотите, чтобы они сразу подключались, удалите config.json перед
  упаковкой: пусть сами введут адрес сервера и пароль комнаты.

Можно сохранить несколько серверов: введите другой адрес и пароль комнаты и нажмите «Добавить и переключиться».
Каждый сервер — отдельное лобби; переключение — «🌐 Лобби: …» под «Сейчас играют» слева. У каждого лобби
виден флаг страны / региона сервера, число комнат и сколько людей онлайн. Аккаунты, друзья и статистика
у каждого сервера свои: в другом лобби зарегистрируйтесь или войдите заново.
Если адрес недоступен или пароль комнаты неверный, об этом сразу сообщается, и сервер не добавляется.
Чтобы изменить пароль комнаты у сервера, нажмите 🔑 рядом с ним, введите новый пароль и нажмите
«Сохранить пароль и переключиться сюда».

Примечания:
  · У игр через интернет показан флаг страны / региона, где находится сеть хоста (примерно по IP), —
    подсказка, какой будет задержка.
  · Если игры у вас нет, при «Войти» можно попросить её у хоста: хост выбирает «Разрешить», «Не разрешать»
    или «Всегда разрешать». Игра, 3 картинки превью и недостающий BIOS идут прямо с компьютера хоста (не через сервер), сохраняются в папку той же
    платформы в вашей папке ROM, после чего вы входите в игру автоматически.
  · Нет соединения или обрыв: если через 20 секунд после входа соединения нет, вы выйдете с сообщением; если
    связь пропала на 15 секунд во время игры, вошедший выходит, а хост играет дальше. VPN у любой из сторон
    часто мешает соединиться или сильно увеличивает задержку.
  · И через интернет используется тот же файл игры с вашего компьютера (синхронизация нажатий), поэтому у всех
    должны быть одинаковые ROM (с одной и той же сборкой EmulatorJS проблем нет).
    У кого игры нет, тот играет по видео — это сильнее нагружает канал сервера.
  · Чем дальше вы друг от друга, тем на больше кадров задерживаются нажатия (подстраивается само после замера
    связи); файтинги будут чуть «вязче».
  · Кто знает пароль, видит все игры на сервере; чтобы никого не пускать, закройте вход.

Установка игрового сервера (один раз, тот, у кого есть облачный сервер):
  Нужен облачный сервер с Ubuntu 22.04 / 24.04 (хватит самого маленького и дешёвого).
  1. В «брандмауэре» облачной консоли откройте: TCP 8765, TCP 80, TCP 3478, UDP 3478, UDP 49160-49250.
     (TCP 80 нужен для получения бесплатного сертификата https, чтобы пароли и прочее шли в зашифрованном виде;
      сертификат обновляется сам каждые 3 дня.)
  2. Через «Вход» в консоли откройте веб-терминал и загрузите на сервер «cloud-server/ejs-cloud-setup.sh» из папки.
  3. В терминале выполните: sudo bash ejs-cloud-setup.sh
     Задать свой пароль: sudo bash ejs-cloud-setup.sh вашпароль (только латинские буквы и цифры)
     Если есть домен (сначала направьте его A-записью на IP сервера): sudo bash ejs-cloud-setup.sh вашдомен
     например, sudo bash ejs-cloud-setup.sh example.site. Тогда адрес будет https://вашдомен:8765;
     старый IP-адрес продолжит работать, а каждый компьютер при подключении сам перейдёт на домен
     (если IP сервера когда-нибудь сменится, достаточно поменять A-запись домена).
  4. В конце будут показаны адрес сервера (начинается с https://) и пароль комнаты — введите их в настройках выше.
     Старый http-адрес менять не нужно: EmulatorJS сам перейдёт на https, а в настройках будет
     «🔒 Защищённое подключение».
  После перезагрузки сервер запускается сам.
  Обновление сервера: после обновления EmulatorJS снова загрузите новый «cloud-server/ejs-cloud-setup.sh»
  (заменив старый) и выполните sudo bash ejs-cloud-setup.sh. Пароль сохранится; кто сейчас играет, ненадолго
  отключится и просто присоединится снова.
  (Примечание: при этом файл запрещённых слов на сервере заменится новым; добавленные вами слова придётся
  внести заново.)
  Управление аккаунтами: в терминале сервера выполните sudo ejs-admin и выберите номер в меню (на английском):
    список / поиск пользователей, сброс пароля, переименование, блокировка / разблокировка, удаление аккаунта,
    список / удаление результатов матчей.
    Пункт 10 «Server limits» задаёт ограничения сервера: людей онлайн, комнат и скорость ретранслятора.
    Пункт 11 «Developer (admin) account» создаёт аккаунт администратора 开发者 или Developer: имена с этими словами
    игроки не могут ни зарегистрировать, ни присвоить; войдя в этот аккаунт, вы увидите своё имя выделенным
    цветом и 🛠 в лобби, комнатах и рейтингах.
  (Заблокированный пользователь не может войти и сразу выходит из аккаунта; при удалении аккаунта удаляются и его
   друзья, и результаты, восстановить их нельзя.)

[Лобби]
  Нажмите «⤢ Лобби» рядом с «Сейчас играют» слева (на телефоне — 🕹 в правом верхнем углу), чтобы открыть лобби
  на весь экран:
  · «Сейчас играют»: все идущие игры в локальной сети и в интернете. Ищите по названию игры или имени игрока и
    фильтруйте: «Открытые / Арена / Файтинг / Друзья / Локальная сеть / Интернет». У каждой игры можно
    «Подключиться» или «👀 Смотреть» (зрители только смотрят и не управляют).
    У каждой игры есть метка: зелёная «Локальная сеть» — в той же Wi-Fi / роутере, синяя «🌐 Интернет» — на
    интернет-сервере. Игра, видная обоими способами, показывается один раз — как локальная (быстрее).
  · «🌐 Игроки онлайн»: все, кто сейчас на интернет-сервере (у кого открыт EmulatorJS с этим сервером): флаг, имя,
    зарегистрирован ли игрок и во что играет или находится в лобби; можно сразу «Присоединиться» или «👀 Смотреть».
    Рядом с кнопкой «🌐 Лобби» видно, например, «Онлайн: 37/200» (людей сейчас / предел сервера). Старые серверы этого
    не показывают: владелец сервера должен ещё раз запустить установочный скрипт.
  · «Друзья», «Рейтинг», «Моя статистика»: для них сначала нужно войти в аккаунт (см. ниже).

[Аккаунты, друзья, статистика] (нужен сервер для игры через интернет)
  Играть — в том числе по сети — можно без аккаунта; аккаунт добавляет статистику и друзей.
  · Регистрация: нажмите «Регистрация» в правом верхнем углу лобби, введите имя (2–16 символов, без
    оскорбительных слов) и пароль (не меньше 6 символов) и выберите свой регион.
    Аккаунты хранятся на сервере для игры через интернет, поэтому войти можно и с других компьютеров.
    Когда вы вошли, в сетевых играх используются имя аккаунта и ваш регион (в виде флага).
  · Друзья: в «Друзья» введите имя аккаунта другого человека, чтобы отправить заявку; когда он её примет, вы
    станете друзьями. Видно, кто из друзей в сети и во что играет, присоединиться или посмотреть можно одним
    нажатием.
  · Статистика: во что вы играете, сколько времени, сколько раз по сети и с кем — записывается автоматически.
  · Результаты: после сетевого матча нажмите наверху «🏆 Записать результат» и выберите победителя.
    Остальным придёт запрос на подтверждение; результат засчитывается, только когда все нажмут «Да, подтверждаю».
    Если кто-то нажмёт «Неверно», запись отменяется.
  · Чемпион: при 10+ победах и не менее 60 % побед в игре вы становитесь её чемпионом; ваше имя в лобби
    горит золотом с 👑.
  · Лайки: нажмите ♡ в лобби, в списке друзей, в статистике игрока или в «👥 Комната» во время игры;
    повторное нажатие убирает лайк. «♥ Самые популярные» в рейтинге — по числу полученных лайков.
  · Арена: в файтингах хост может нажать наверху «🥊 Арена». Тогда игра окажется первой в лобби с пометкой
    «вызовы принимаются», и бросить вам вызов сможет любой.
  · Телефоны и планшеты, открывшие страницу по адресу в локальной сети, тоже могут входить в аккаунт и видеть
    интернет-игры: их запросы передаёт компьютер хоста (на нём должен быть настроен сервер для игры через интернет).

[Язык интерфейса]
  Нажмите на флаг в левом верхнем углу, чтобы сменить язык: 简体中文, 繁體中文, English, 日本語, 한국어,
  Español, Français, Deutsch, Português, Русский. По умолчанию используется язык системы.
  Названия игр показываются по-английски, а если есть перевод — ещё и на выбранном языке.
  Переводы лежат в папке data/i18n (в data/names.json — названия игр); их можно править.

Другие варианты:
  · Parsec (https://parsec.app) для удалённой игры: друг подключается к вашему компьютеру, видит ваш экран, а его
    геймпад становится вторым геймпадом на вашем компьютере. Ему не нужны ни ROM, ни EmulatorJS.
  · Если у обоих есть RetroArch, можно пользоваться и его собственным Netplay.


9. BIOS
-------
  NES, Super Nintendo, Mega Drive   Не нужен
  Sega Mega-CD                      Обязателен: bios_CD_U.bin (США), bios_CD_J.bin (Япония), bios_CD_E.bin (Европа)
  Аркада (FBNeo)                    Обычно не нужен; играм Neo Geo (KOF, Metal Slug и др.) нужен neogeo.zip,
                                    играм PGM — pgm.zip

  Без BIOS при нажатии на игру Mega-CD появится «Нет BIOS — запуск невозможен».
  Если папка BIOS настроена, в левом верхнем углу будет, например, «Найден BIOS: Sega Mega-CD (U/J)»;
  буквы показывают, для каких регионов у вас есть BIOS.


10. Частые проблемы
-------------------
  После нажатия на игру чёрный экран
    → Проверьте, что страница открыта через файл запуска (в адресной строке http://127.0.0.1 или
      http://localhost), а не двойным щелчком по index.html (в адресной строке file://).

  Двойной щелчок по EmulatorJS.command ничего не делает (Mac)
    → При копировании могло пропасть право на «выполнение». Откройте «Терминал», введите
         chmod +x
      (с пробелом в конце), перетащите EmulatorJS.command в окно «Терминала», нажмите Enter и снова дважды
      щёлкните по файлу.

  На Mac у EmulatorJS.command нет значка геймпада
    → Один двойной щелчок ставит значок. Если ничего не изменилось, закройте окно Finder и откройте снова
      (Finder не всегда обновляется сразу). Файл значка — data/icon.png, не удаляйте его.

  В Windows не появляется ярлык «EmulatorJS»
    → Один раз дважды щёлкните по EmulatorJS-Windows.bat; ярлык появится в той же папке.
      Проверьте, что в data есть icon.ico, а start-windows.ps1 лежит рядом с .bat.

  Некоторые игры не запускаются
    → Некоторым играм нужен BIOS (см. раздел 9); некоторые аркадные наборы сделаны под другие эмуляторы и не идут
      в веб-версии FBNeo — в них играйте в RetroArch.

  Где хранятся мои настройки, аккаунт и сохранения?
    → Аккаунт (имя, друзья, статистика): на интернет-сервере, поэтому войти можно с любого компьютера или телефона;
      пароль хранится только в зашифрованном виде.
      Настройки (папки, адрес интернет-сервера и пароль комнаты): в config.json на каждом устройстве —
        Версия-папка (.command / .bat): config.json в папке EmulatorJS
        Приложение для Windows: %APPDATA%\EmulatorJS\config.json
        Приложение для Mac: ~/Library/Application Support/EmulatorJS/config.json
        Приложение для Android: в данных самого приложения (удаляются вместе с приложением или при очистке его данных)
      Вход, имя игрока, язык, цветовая тема, фоновая картинка, недавние игры, сохранения и состояния: в браузере
      (приложения для компьютера и Android — в своих данных). Каждое устройство хранит своё, на сервер ничего не
      отправляется. Всё пропадёт при смене браузера, очистке его данных или удалении приложения; сохранения можно
      скопировать кнопкой «Export Save File» в строке меню под игрой.
