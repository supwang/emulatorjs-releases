EmulatorJS 사용 설명서
================================

EmulatorJS는 웹 브라우저에서 고전 게임을 즐기는 도구입니다. RetroArch를 설치할 필요도,
인터넷에 연결할 필요도 없습니다.
패미컴(NES), 슈퍼 패미컴(SNES), 게임보이 / GBA, N64, NDS, 세가 메가드라이브 / 메가 CD / 32X / 새턴,
PS1, PSP, PC 엔진, 아케이드(FBNeo / MAME 2003) 등 20개가 넘는 플랫폼을 지원합니다.


1. 폴더에 들어 있는 것
----------------------
  index.html              게임 페이지 (직접 더블클릭해서 열지 마세요)
  data/                   에뮬레이터와 코어. 건드리지 마세요
  EmulatorJS.command      Mac 실행 파일
  EmulatorJS-Windows.bat  Windows 실행 파일
  start-windows.ps1       Windows 실행 파일이 쓰는 스크립트. .bat과 같은 곳에 두세요
  Enable-LAN-Windows.bat  Windows LAN 플레이 허가 (처음 실행할 때 자동으로 뜹니다. 그때 ‘아니요’를
                          눌렀을 때만 직접 더블클릭하세요)
  cloud-server/           인터넷 플레이 서버 설치 스크립트 (클라우드 서버에서만 사용, 8장 참고)
  server.py               Mac 실행 파일이 쓰는 작은 로컬 서버
  config.json             폴더 설정을 처음 저장할 때 자동으로 생기며, 고른 폴더를 기억합니다
  EmulatorJS.lnk          Windows에서 처음 실행한 뒤 자동으로 생기는 바로가기 (게임패드 아이콘)
  LICENSE                 EmulatorJS 오픈 소스 라이선스 (GPL-3.0)
  README_KR.txt 등        이 설명서. 언어마다 하나씩: CN 简体中文, HK 繁體中文, US English, JP 日本語,
                          KR 한국어, ES Español, FR Français, DE Deutsch, BR Português, RU Русский


2. 여는 방법
------------
[데스크톱 앱 (추천)]
  브라우저나 터미널 창을 쓰고 싶지 않다면 데스크톱 앱을 쓰세요. 더블클릭하면 게임 창이 열리고, 창을 닫으면 종료됩니다.
  · Windows: EmulatorJS-Setup-버전.exe는 설치판(설치 위치 선택 가능, 시작 메뉴와 바탕 화면 아이콘 생성),
    EmulatorJS-버전-win.zip은 설치 없이 원하는 폴더에 압축을 풀고 안의 EmulatorJS.exe를 더블클릭하면 됩니다.
    처음에 ‘Windows의 PC 보호’가 나오면 ‘추가 정보’ → ‘실행’.
    네트워크 접근을 물으면 ‘개인 네트워크’에 체크하고 ‘허용’(LAN 플레이에 필요).
  · Mac: M1 / M2 / M3 / M4 칩은 …-mac-apple-silicon.dmg, Intel 칩은 …-mac-intel.dmg.
    dmg를 열고 EmulatorJS를 ‘응용 프로그램’으로 드래그합니다.
    처음에 개발자를 확인할 수 없다고 나오면 ‘시스템 설정 → 개인정보 보호 및 보안’에서 ‘그래도 열기’.
    로컬 네트워크의 기기 찾기나 마이크 사용을 물으면 ‘허용’(LAN 플레이와 음성 채팅에 필요).
  · 게임 폴더: ‘문서 / EmulatorJS’의 roms, thumbnails, system과 RetroArch 기본 위치를 자동으로 찾습니다.
    ‘⚙ 폴더 설정’에서 고를 수도 있습니다. 처음 실행할 때 기존 EmulatorJS 폴더의 설정을 이어받습니다.
  · 설정은 앱 전용 데이터 폴더에 저장됩니다. 기존 EmulatorJS.command / EmulatorJS-Windows.bat도 그대로 쓸 수 있고,
    두 방식이 함께 플레이할 수 있습니다.
  · 설정 파일 config.json(폴더 설정, 인터넷 플레이 서버 주소와 방 비밀번호) 위치:
    Windows: %APPDATA%\EmulatorJS\config.json (파일 탐색기 주소 표시줄에 %APPDATA%\EmulatorJS 를 입력하고 Enter)
    Mac: ~/Library/Application Support/EmulatorJS/config.json (Finder에서 Shift+Command+G 를 누르고 이 경로 붙여넣기)

[안드로이드 휴대폰 / 태블릿 / 안드로이드 TV (APK)]
  · 휴대폰, 태블릿, TV, TV 박스: EmulatorJS-버전-android.apk
    PC의 안드로이드 에뮬레이터(MuMu 등): EmulatorJS-버전-android-x86_64.apk
    Android 7.0 이상이 필요합니다. TV의 ‘Android System WebView’가 너무 오래되면 업데이트하라는 안내가 나옵니다.
  · 설치: apk를 휴대폰 / TV로 옮긴 뒤(USB 케이블, USB 메모리, 메신저 등) 파일 관리자에서 누르세요.
    ‘출처를 알 수 없는 앱’ 설치가 막혀 있다고 나오면, 그 파일 관리자에 허용해 주고 apk를 다시 누르세요.
    TV: apk를 USB 메모리에 복사해 TV에 꽂고, TV의 파일 관리자로 apk를 여세요.
  · 처음 실행할 때 사진 및 파일(저장공간) 접근을 물으면 ‘허용’을 고르세요. 허용하지 않으면 게임을 읽을 수 없습니다.
    그러면 ‘내부 저장소 / EmulatorJS’ 폴더가 만들어지고, 안에 roms, thumbnails, system 폴더가 생깁니다.
  · 게임 넣기: 휴대폰을 케이블로 컴퓨터에 연결하고(휴대폰에서 ‘파일 전송’ 선택) 게임을 EmulatorJS / roms에 복사하세요.
    넣는 방법은 컴퓨터와 같습니다(3장 참고). 표지 그림은 thumbnails, BIOS는 system에. 다 넣으면 ‘↻ 다시 읽기’를 누르세요.
    다른 곳에 두고 ‘⚙ 폴더 설정’에서 고를 수도 있습니다. 폴더를 고르는 창 위쪽에 ‘내부 저장소’, ‘다운로드’ 같은
    바로가기 버튼이 있습니다.
  · TV에서 USB 메모리 읽기: USB 메모리 맨 위에 EmulatorJS 또는 RetroArch 폴더(안에 roms 등)가 있으면 자동으로 찾습니다.
    ‘⚙ 폴더 설정’에서 ‘USB / 메모리 카드’를 눌러 고를 수도 있습니다. 내용을 바꿨으면 ‘↻ 다시 읽기’를 누르세요.
    안드로이드에서는 앱이 USB 메모리에 쓸 수 없어서, 온라인 플레이 중 다른 사람 컴퓨터에서 받은 게임은
    ‘EmulatorJS / downloads’에 저장되고 USB 메모리의 게임과 함께 표시됩니다.
  · 조작:
    휴대폰: 화면의 가상 버튼, 또는 블루투스 / USB 게임패드.
    TV: 리모컨으로 게임을 고르고(방향키로 이동, 확인 / OK로 열기, 뒤로 키로 돌아가기) 게임패드로 플레이합니다.
    게임 중 리모컨이나 휴대폰의 뒤로 키(또는 게임패드에서 Select + Start 길게 누르기)로 게임 메뉴가 열립니다:
    계속, 상태 저장, 상태 불러오기, 리셋, 전체 화면, 게임 종료. 게임 목록에서 뒤로 키를 두 번 누르면 앱이 종료됩니다.
  · 온라인 플레이, 로비, 계정은 컴퓨터판과 같고 컴퓨터와 함께 플레이할 수 있습니다(LAN은 같은 Wi-Fi에 연결).
    음성 채팅을 처음 쓸 때 마이크 사용을 물으면 ‘허용’을 고르세요.
  · 저렴한 TV 박스는 성능이 낮습니다: 패미컴, 슈퍼 패미컴, GBA, 메가 드라이브는 매끄럽고 N64, PSP, NDS, 새턴은 끊길 수 있습니다.

[Mac]
  1. EmulatorJS.command를 더블클릭합니다.
     처음에 ‘확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다’가 나오면
     마우스 오른쪽 클릭 → ‘열기’ → 다시 ‘열기’. 다음부터는 더블클릭만 하면 됩니다.
  2. 터미널 창이 열리고 브라우저에서 게임 페이지가 자동으로 열립니다.
     ‘명령어 라인 개발자 도구’를 설치하라고 하면 ‘설치’를 누르고, 끝나면 다시 더블클릭하세요.
  3. 플레이하는 동안 터미널 창을 닫지 마세요. 다 하면 닫으면 됩니다.
  실행 파일에는 게임패드 아이콘이 자동으로 붙습니다. 복사하다가 아이콘이 없어져도
  한 번 실행하면 다시 생깁니다.

[Windows]
  1. EmulatorJS-Windows.bat을 더블클릭합니다.
     파란색 ‘Windows의 PC 보호’가 나오면 ‘추가 정보’ → ‘실행’을 누르세요.
  2. 검은 명령 창이 열리고 브라우저에서 게임 페이지가 자동으로 열립니다.
  3. 플레이하는 동안 이 창을 닫지 마세요. 다 하면 닫으면 됩니다.
  Windows에서는 .bat 파일에 아이콘을 붙일 수 없어서, 처음 실행한 뒤 폴더에 아이콘이 있는
  ‘EmulatorJS’ 바로가기가 만들어집니다. 다음부터는 그것을 더블클릭하세요. 바탕 화면으로 옮겨도 됩니다.
  폴더를 옮기면 바로가기가 작동하지 않으니, .bat을 한 번 더블클릭하면 다시 만들어집니다.

이 창은 왜 열어 둬야 하나요?
  창 안에서는 이 컴퓨터에서만 접속할 수 있는 작은 웹 서버가 돌아갑니다. 브라우저는 보안 때문에
  더블클릭으로 연 페이지가 에뮬레이터 파일을 읽지 못하게 하므로, 이 서버를 거쳐서 엽니다.
  창을 닫으면 서버도 멈춥니다.

【새 버전으로 업데이트】
  · 프로그램을 열 때(그 뒤로 6시간마다) 새 버전이 있는지 확인하고, 있으면 업데이트 내용을 알려 줍니다.
    왼쪽 버전 번호 옆에도 ‘🆕 새 버전’이 표시됩니다. 버전 번호를 누르면 언제든 직접 확인할 수 있습니다.
    게임 중에는 뜨지 않습니다.
  · Windows 설치판(EmulatorJS-Setup-버전.exe로 설치한 것): ‘자동 업데이트’를 누르면 새 설치 파일을 받아 손상 여부를
    확인합니다. 다 받으면 ‘지금 설치’: 프로그램이 닫히고 새 버전을 설치한 뒤 스스로 다시 열립니다(약 30초).
    게임, 설정, 저장 데이터는 그대로 남습니다. 다운로드가 아주 느리거나(5분 이상 예상) 실패하면 바이두 클라우드를 안내합니다.
  · Mac, Windows zip판, 폴더판, 안드로이드: ‘새 버전 다운로드’(중국 내에서는 바이두 클라우드)를 누르고 안내대로
    이전 버전을 바꿉니다(Mac: 새 EmulatorJS를 ‘응용 프로그램’으로 끌어 ‘대치’, 폴더판: 새 파일을 원래 폴더에 덮어쓰기).
  · 다운로드: https://github.com/supwang/emulatorjs-releases/releases
    바이두 클라우드: https://pan.baidu.com/s/13atBCqmTib1rGp_30279mQ?pwd=6akk (추출 코드 6akk)
  · 원하지 않는 버전은 ‘이 버전 건너뛰기’. 확인할 때는 다운로드 사이트의 버전 정보만 읽고 아무것도 보내지 않습니다.


3. 게임 폴더 (한 번만 설정)
---------------------------
페이지를 열면 다음 세 폴더를 자동으로 읽습니다. 매번 고를 필요가 없습니다.

  ROM 폴더          게임을 모아 둔 폴더 (필수)
  미리보기 폴더     RetroArch의 thumbnails 폴더 (선택, 게임 표지 표시용)
  BIOS 폴더         BIOS가 있는 폴더 (선택, 일부 플랫폼만 필요, 9장 참고)

[자동 찾기] 설정하지 않은 폴더는 다음 순서로 찾고, 찾으면 바로 씁니다:
  1. EmulatorJS 폴더 안(EmulatorJS.command, EmulatorJS-Windows.bat과 같은 곳)의
     roms, thumbnails, system 폴더 (BIOS 폴더는 bios라는 이름도 됩니다)
  2. RetroArch 기본 위치
     Mac: ~/Library/Application Support/RetroArch/ 아래의 roms, thumbnails, system
     Windows: %APPDATA%\RetroArch, 또는 C:/D:/E:/F: 드라이브의 RetroArch-Win64, RetroArch,
              Games\RetroArch-Win64 등의 폴더 안의 roms, thumbnails, system
  그래서 RetroArch를 기본 위치에서 쓰고 있다면 처음부터 바로 플레이할 수 있습니다.
  다른 사람에게 줄 때 roms, thumbnails, system 세 폴더를 EmulatorJS 폴더에 바로 넣어 두면,
  받은 사람은 압축을 풀고 열기만 하면 됩니다.

[직접 설정] 왼쪽 위 ‘⚙ 폴더 설정’을 누릅니다:
  1. 항목마다 ‘찾아보기…’를 누르고 폴더를 차례로 들어간 뒤 ‘이 폴더 선택’을 누릅니다.
     위쪽에 ‘홈’, ‘바탕 화면’, ‘RetroArch’ 같은 바로가기 버튼이 있습니다. 폴더 경로를 붙여 넣어도 됩니다.
  2. ‘저장하고 게임 불러오기’를 누릅니다. 설정은 config.json에 저장되어 다음부터 자동으로 쓰입니다.
  - ‘지우기’를 하고 저장하면 다시 자동 찾기로 돌아갑니다.
  - 설정한 폴더를 찾을 수 없게 되면(다른 컴퓨터로 옮겼을 때 등) 자동 찾기로 돌아가고,
    설정 화면에 알림이 표시됩니다.

【이미지 자동 다운로드】
  커버가 없는 게임은 libretro 커뮤니티의 이미지 모음(libretro-thumbnails, RetroArch와 같은 것)에서 커버, 타이틀 화면,
  게임 화면을 자동으로 받아 이미지 폴더에 저장할 수 있습니다(설정하지 않았으면 ROM 폴더 옆에 thumbnails 폴더를 만듭니다).
  · 커버 없는 게임을 처음 읽을 때 받을지 묻습니다. 동의하면 나중에 추가한 게임도 자동으로 받습니다.
  · ‘⚙ 폴더 설정’ → ‘이미지 자동 다운로드’에서 켜고 끌 수 있고, ‘⬇ 없는 이미지 지금 다운로드’도 있습니다.
  · 게임 이름으로 이미지를 찾습니다(아케이드는 FBNeo 정식 이름). No-Intro 같은 표준 파일 이름이 좋으며,
    한글 이름이나 직접 바꾼 이름은 못 찾을 수 있습니다.
  · GitHub에 연결되어야 합니다. 왼쪽 위에 진행 상황이 나오고 언제든 ‘중지’할 수 있습니다. 이미지는 커뮤니티가 모은 것이며 저작권은 각 게임 회사에 있습니다.

[새 게임을 넣은 뒤] 왼쪽 위 ‘↻ 다시 읽기’를 누르세요. 페이지를 다시 열 필요가 없습니다.

[새 게임의 플랫폼 자동 분류]
  각 게임의 플랫폼은 다음 순서로 판단하며, 먼저 알아낸 것을 씁니다:
  1. RetroArch 재생 목록에 기록된 플랫폼 (이 도구에는 게임 목록이 들어 있습니다)
  2. 전에 직접 고른 플랫폼 (‘플랫폼 직접 선택 필요’에서 한 번 고르면 기억합니다)
  3. 파일 확장자: .nes .sfc .smc .md .gen .gba .gb .n64 .nds 등
  4. 파일 내용:
     - 압축 파일(.zip): 안에 든 파일을 봅니다. 예를 들어 .sfc가 있으면 SNES, .md가 있으면 메가드라이브
     - 디스크 / 카트리지 이미지(.bin .iso .cue): 파일 앞부분의 표시를 읽어 메가드라이브, 세가 CD,
       새턴, PS1 등을 알아냅니다
  5. 들어 있는 폴더 이름: snes, md, fbneo, ‘Nintendo - Super Nintendo Entertainment System’ 등
  6. 압축 파일 안에 알려진 카트리지 형식이 없으면 → 아케이드 게임으로 봅니다
  7. 그래도 모르는 것(.7z, .chd 등)은 ‘플랫폼 직접 선택 필요’에 들어갑니다. 한 번 고르면 기억합니다
  아케이드 게임은 FBNeo 공식 게임 목록(8000개 이상)과도 대조하며, 목록에 없는 파일 이름(NAOMI의 cvs2.zip 등)은
  FBNeo로 실행할 수 없으므로 ‘웹 버전 미지원’에 들어갑니다.
  그래서 여러 게임이 한 폴더에 섞여 있어도 대부분 올바른 플랫폼으로 분류됩니다.
  파일 앞부분과 목차 일부만 읽어서 빠르고, 결과를 기억하므로 다음에는 다시 판단하지 않습니다.

팁:
  - ROM 폴더는 플랫폼별 하위 폴더(snes, md, nes, fbneo 등, 또는 RetroArch에서 흔히 쓰는
    ‘Nintendo - Super Nintendo Entertainment System’ 같은 이름)로 나누는 것이 좋습니다.
    그러면 플랫폼을 자동으로 알아냅니다.
  - 왼쪽 위에 ‘⚙ 폴더 설정’ 대신 ‘ROM 폴더 선택’ 등 버튼 세 개가 보이면, 여는 방법이 잘못됐거나
    예전 실행 창을 쓰는 것입니다. 터미널 / 명령 창을 모두 닫고 실행 파일로 다시 여세요.


4. 플레이하기
-------------
  1. 왼쪽은 플랫폼 목록이며, 플랫폼마다 본체 그림이 있습니다. 네오지오 게임은 ‘Neo Geo’로 따로
     나오고, 다른 아케이드 게임은 ‘아케이드 (FBNeo)’에 있습니다.
     플랫폼을 누르면 오른쪽에 그 플랫폼의 모든 게임 표지가 나옵니다.
     맨 위의 ‘🕘 최근 플레이’에는 이 컴퓨터에서 최근에 한 게임 10개가 있고, 누르면 바로 다시 할 수 있습니다.
     기록을 지우려면: 표지에 마우스를 올리고 오른쪽 위 ✕를 누르세요(게임패드는 선택 후 X, 키보드는 Delete).
     ‘기록 지우기’를 누르면 모두 지워집니다.
     게임 위에 마우스를 올리면 표지 → 타이틀 화면 → 스크린샷으로 그림이 바뀝니다. 표지 아래 점은
     모두 몇 장이고 지금 몇 번째인지 알려 줍니다. 마우스를 떼면 그 그림에서 멈춥니다.
     (없는 그림은 건너뛰고, 그림이 한 장뿐인 게임은 바뀌지 않습니다.)
     표지 크기: 표지 목록 오른쪽 위에서 ‘작게 / 보통 / 크게 / 아주 크게’를 고를 수 있으며, 플랫폼마다 따로 기억됩니다.
  2. 표지를 누르면 게임이 시작됩니다.
  3. 오른쪽 위 ‘게임 종료’를 누르면 표지 목록으로 돌아갑니다.
  4. 검색 상자로 이름을 입력해 게임을 찾을 수 있습니다.
  5. 왼쪽 맨 아래 ‘⌨ 단축키 안내’에 코인, 시작, 리셋, 일시정지, 연사, 저장 / 불러오기, 아케이드
     서비스 메뉴 등의 키보드와 게임패드 버튼이 정리되어 있습니다. 제목을 누르면 접기 / 펼치기가 되며 기억됩니다.
  6. 화면 색상: 왼쪽 위 ‘EmulatorJS’ 옆의 🎨를 누르면 7가지 중에서 고를 수 있습니다
     (어린 시절〔기본: 해 질 녘 오락실, 배경 이미지 포함〕, 나이트 아케이드〔어두운 색〕, 세가 블루〔선명한 파랑〕, 게임보이 그린, 슈퍼패미컴 회색·보라〔밝은 색〕,
       크림 카트리지〔밝은 색〕, 캔디 핑크〔밝은 색〕).
     배경, 글자, 버튼이 함께 바뀌며 고른 것을 기억합니다.
     같은 패널에서 ‘배경 이미지’도 설정할 수 있습니다: 컴퓨터의 이미지를 고르면 오른쪽 게임 목록 뒤에 표시됩니다
     (스크롤해도 움직이지 않음). 공통 이미지 한 장과, 기종마다 따로 이미지를 설정할 수 있습니다(따로 설정하지 않은
     기종은 공통 이미지). ‘어둡게’ 슬라이더로 이미지를 어둡게 하면 글자가 잘 보입니다. 이미지는 이 기기의 이
     브라우저에만 저장됩니다.
     게임 중에는 화면 양옆의 빈 곳에도 이 이미지가 (어둡고 흐리게) 보여서, 세로 화면 게임도 양옆이 새까맣지 않습니다.
     같은 패널에서 끌 수 있습니다.
  7. 언어: 왼쪽 위 국기 버튼을 누르세요 (8장 [화면 언어] 참고).

  - ‘플랫폼 직접 선택 필요’: 플랫폼을 알아내지 못한 게임입니다. 플랫폼을 고르면 그 그룹으로 옮겨집니다.
  - ‘웹 버전 미지원’: 브라우저 버전에서 돌아가지 않는 게임(세가 NAOMI 등). RetroArch로 플레이하세요.
    이 목록을 보고 싶지 않으면: 목록을 열고 오른쪽 위 ‘이 목록 숨기기’를 누르거나, ‘⚙ 폴더 설정’에서 체크를 끄세요.

게임 버튼, 저장, 상태 저장, 전체 화면 등은 게임 화면 아래 메뉴 막대에 있습니다.
‘Control Settings(조작 설정)’에서 키보드 키를 보고 바꿀 수 있으며, 게임패드도 지원합니다.
저장은 브라우저 안에 되므로, 브라우저를 바꾸거나 브라우저 데이터를 지우면 사라집니다.
백업하려면 메뉴의 ‘Export Save File(저장 파일 내보내기)’을 쓰세요.

치트: 메뉴 막대의 ‘치트’(Cheats) → ‘치트 추가하기’(Add Cheat)에서 코드와 설명을 넣고 제출한 뒤 체크하면 켜지고,
다시 누르면 꺼집니다. 코드 형식은 기종마다 다릅니다(패미컴은 Game Genie, GBA는 Action Replay / GameShark 등).
인터넷에서 ‘게임 이름 + 치트’로 찾을 수 있습니다. 어떤 치트는 끈 뒤 게임을 다시 시작해야 완전히 돌아옵니다.
다른 플레이어와 온라인 플레이 중에는 치트가 자동으로 꺼지고 치트 버튼도 숨겨지며, 혼자 남으면 다시 켜집니다.

치트 라이브러리: ‘치트’(Cheats) 메뉴 맨 위의 ‘📚 치트 라이브러리에서 고르기(libretro)’를 누르면 게임 이름으로 이 게임의 치트를
찾습니다(libretro 커뮤니티 데이터베이스 libretro-database. 패미컴, 슈퍼패미컴, 메가드라이브, GBA 등은 많고 아케이드는 거의 없음).
체크하고 ‘선택한 치트 추가’를 누른 뒤 ‘치트’에서 체크하면 켜집니다. 온라인 플레이 중에는 쓸 수 없습니다. GitHub에 연결되어야 합니다.


5. 키보드와 게임패드
--------------------
[키보드 기본 배치] (플레이어 1)

  방향                W 위   S 아래   A 왼쪽   D 오른쪽
  시작(Start)         Enter
  셀렉트 / 코인       V

  패미컴(NES)         J = A    K = B
  슈퍼 패미컴(SNES)   J = A    K = B    I = X    L = Y    U = L 버튼    O = R 버튼
  메가드라이브 / CD   아래 줄 J K L = A B C        윗줄 U I O = X Y Z
  아케이드 네오지오 (KOF, 메탈 슬러그, 사무라이 스피리츠 등)
                      J = A    K = B    I = C    L = D
                      U = A+B 동시   O = C+D 동시   (A+B+C, B+C+D는 기본으로 키가 없습니다)
  아케이드 (그 밖)    J K I L = 버튼 1 2 3 4    U O = 버튼 5 6
  아케이드 (스트리트 파이터, 뱀파이어, 마블 계열 같은 6버튼 격투)
                      약펀치 J   중펀치 K   강펀치 L
                      약킥 U     중킥 I     강킥 O
                      (펀치 3개 동시, 킥 3개 동시는 기본으로 키가 없습니다)

  일시정지 / 계속     오른쪽 Shift
  연사 켜기/끄기      T
  게임 리셋           V + Enter + U + O 동시에 (합팩은 게임 선택 화면으로 돌아갑니다)
  상태 저장 1         상태 불러오기 2         슬롯 바꾸기 3
  (빨리 감기, 느리게, 되감기는 기본으로 키가 없습니다. ‘Control Settings’에서 직접 정하세요)

  - 아케이드 게임은 ROM 파일 이름에 따라 배치를 자동으로 고릅니다. 지금 6버튼 배치를 쓰는 게임:
      스트리트 파이터 (sf), 스트리트 파이터 II' 챔피언 에디션 (sf2ce), 스트리트 파이터 ZERO 3 (sfa3),
      스트리트 파이터 III 3rd STRIKE (sfiii3), 스트리트 파이터 EX2 PLUS (sfex2p),
      뱀파이어 (dstlk), 뱀파이어 헌터 (nwarr), 뱀파이어 세이비어 2 (vsav2)
    나머지 아케이드 게임(KOF, 메탈 슬러그 같은 네오지오 게임 포함)은 J K I L 배치를 씁니다.
    나중에 넣는 스트리트 파이터, 뱀파이어, 마블(X-MEN 등) 계열 게임도 6버튼 배치로 자동 인식됩니다.
  - 키 배치는 게임 화면 아래 메뉴 막대의 ‘Control Settings’에서 바꿀 수 있습니다.

[‘Control Settings’에 보이는 버튼]
  버튼 이름은 각 플랫폼의 원래 컨트롤러 이름으로 보이며, 순서는 다음과 같습니다:
    코인 / 셀렉트 → 시작 → 상하좌우 → 버튼 → 동시 누르기 → 상태 저장, 빨리 감기 같은 기능 키

  패미컴(NES)         셀렉트, 시작, 방향, A, B
  슈퍼 패미컴(SNES)   셀렉트, 시작, 방향, A, B, X, Y, L, R
  메가드라이브 / CD   MODE, 시작, 방향, A, B, C, X, Y, Z
  아케이드 네오지오   코인, 시작, 방향, A, B, C, D
                      동시 누르기: A+B, C+D, A+B+C, B+C+D
  아케이드 격투       코인, 시작, 방향, 약·중·강펀치, 약·중·강킥
                      동시 누르기: 펀치 3개 동시, 킥 3개 동시
  아케이드 그 밖      코인, 시작, 방향, 버튼 1~6

  - 동시 누르기: 키 하나로 여러 버튼을 한꺼번에 누른 것과 같습니다. 원래 네오지오에는 A B C D 네 버튼만
    있고, 동시 누르기는 에뮬레이터가 따로 제공하는 것입니다. 필살기나 회피를 쓰기 쉬워집니다
    (예: KOF의 A+B 회피, C+D 날려 버리기).
  - 아케이드 게임이 네오지오인지 6버튼 격투인지는 ROM 파일 이름과 게임 전체 이름으로 자동 판단합니다.
  - 설정은 게임마다 따로 저장됩니다. 어떤 게임에서 바꾼 키 배치나 필터는 그 게임에만 적용되고,
    다음에 그 게임을 열 때 그대로 쓰입니다. 다른 게임은 위의 기본 배치를 그대로 씁니다.
  - 게임 저장(상태 저장 포함)은 이 설정들과 따로 저장되어 서로 영향을 주지 않습니다.
  - 게임패드 버튼은 위의 키보드 설정과 상관없습니다. 아래 [게임패드]를 보세요.

[게임패드]
Xbox, PS4 / PS5, Switch Pro 컨트롤러와 대부분의 USB / 블루투스 게임패드를 쓸 수 있습니다.

  1. USB나 블루투스로 게임패드를 컴퓨터에 연결합니다.
  2. 게임에 들어간 뒤 먼저 게임패드의 아무 버튼이나 한 번 누르세요. 그래야 브라우저가 게임패드를
     인식합니다(브라우저의 개인 정보 보호 규칙).
  3. 기본 배치는 RetroArch와 같습니다 (Xbox 컨트롤러 기준, 왼쪽이 게임의 버튼):
       패미컴 / 슈퍼 패미컴   B → A(아래)   A → B(오른쪽)   Y → X(왼쪽)   X → Y(위)
       메가드라이브           A → X(왼쪽)   B → A(아래)     C → B(오른쪽)
       네오지오               A → A(아래)   B → B(오른쪽)   C → X(왼쪽)   D → Y(위)
       격투                   약펀치 → X(왼쪽)  중펀치 → Y(위)  약킥 → A(아래)  중킥 → B(오른쪽)
                              강펀치 → LB   강킥 → RB
     (EmulatorJS 원래 기본값은 게임패드의 A와 B가 바뀌어 있는데, 이 도구는 RetroArch에 맞췄습니다.)
     배치가 맞지 않으면 게임 화면 아래 메뉴 막대의 ‘Control Settings’에서 버튼마다 다시 지정할 수 있습니다.
     최대 4명까지 각자 다른 게임패드를 설정할 수 있습니다. 설정은 브라우저에 저장됩니다.

  - 게임패드 지원은 Chrome이나 Edge가 가장 좋습니다.
  - 아케이드 게임의 코인과 시작은 보통 게임패드의 Select / 보기 버튼과 Start / 메뉴 버튼입니다.
  - 게임 리셋: Select + Start + LB + RB를 동시에 (PlayStation 패드는 Share + Options + L1 + R1).
    패미컴 합팩에서 게임 선택 화면으로 돌아갈 때 씁니다. 모든 플랫폼에서 됩니다.
  - 왼쪽 스틱도 십자 키처럼 방향을 조작합니다 (절반 넘게 밀면 누른 것으로, 대각선도 됩니다). 둘을 섞어 써도 됩니다.
  - 연사 켜기/끄기: 오른쪽 스틱을 눌러 넣습니다(R3).
  - 마우스 없이 게임 고르기(게임패드, 키보드, TV 리모컨):
      십자키 / 왼쪽 스틱 / 방향키: 표지와 버튼 사이를 이동. A / Enter: 확인(게임 시작, 버튼 누르기).
      B / Esc / 리모컨 뒤로: 뒤로 가기, 열린 패널 닫기. LB / RB: 이전 / 다음 기종. Start: 로비 열기 / 닫기.
  - 게임 메뉴: 플레이 중 Select + Start를 0.5초 동시에 누르고 있으면(TV 리모컨은 뒤로 키) 계속하기, 상태 저장,
    상태 불러오기, 리셋, 전체 화면, 게임 종료를 할 수 있습니다. 혼자 할 때는 메뉴가 열려 있는 동안 일시정지되고,
    온라인에서는 멈추지 않으며 참가한 사람에게는 저장·불러오기·리셋이 나오지 않습니다.

[연사]
  1. 게임 중에 위쪽 ‘연사 설정’을 누르고 이 게임에서 연사할 버튼에 체크합니다.
     예를 들어 슈팅 게임: 사격 버튼은 체크하고 모으기 버튼은 체크하지 않습니다. 그러면 사격 버튼을
     누르고 있으면 연사되고, 모으기 버튼은 그대로 모을 수 있습니다.
  2. 연사 켜기: ‘연사 설정’에서 ‘연사 켜기’를 누르거나, 게임 중에 키보드 T / 오른쪽 스틱(R3)을 누릅니다.
     켜지면 화면 왼쪽 위에 ‘연사 ON’이 보이고 버튼도 ‘연사 설정 · 켜짐’으로 바뀝니다.
  3. ‘이 게임을 시작하면 연사 자동 켜기’에 체크하면 다음부터 그 게임에서 처음부터 켜져 있습니다.

  - 설정은 게임마다 저장되므로 게임마다 한 번만 하면 됩니다. 기본으로 모든 버튼이 체크되어 있고,
    자동으로 켜지지는 않습니다.
  - 연사 속도는 1초에 약 15번입니다. 방향, 시작, 코인은 해당되지 않습니다.
  - 모든 플랫폼에서 키보드와 게임패드 모두 쓸 수 있습니다.
  - ‘연사 설정’ 창을 닫은 뒤 키가 반응하지 않으면 게임 화면을 한 번 클릭하세요.


6. 아케이드 설정: 서비스 메뉴, 난이도, 목숨 수, 네오지오 모드
-------------------------------------------------------------
아래 설정은 모두 게임 화면 아래 메뉴 막대의 ‘Settings(설정, 톱니바퀴)’ → ‘Backend Core Options(코어 옵션)’에 있습니다.
바꾼 뒤 메뉴 막대의 ‘Restart(다시 시작)’를 눌러야 적용됩니다. 설정은 게임마다 저장됩니다.

[아케이드 서비스 메뉴(테스트 모드) 들어가기]
  게임 중에 시작(Enter)을 약 2초 동안 누르고 있으면 아케이드 기판 원래의 서비스 메뉴가 열리며,
  난이도, 목숨 수, 시간, 이어하기 허용 여부 등을 바꿀 수 있습니다(항목은 게임마다 다릅니다).
  들어가는 방법은 코어 옵션의 ‘diagnostic input’에서 바꿀 수 있습니다(예: 셀렉트 길게 누르기).

[난이도, 목숨 수 (딥 스위치)]
  많은 아케이드 게임은 난이도와 목숨 수를 기판의 딥 스위치(DIP 스위치)로 정합니다.
  코어 옵션에서 이름에 ‘Dipswitch’가 들어간 항목을 찾으세요. 예:
    Difficulty(난이도)  Lives(목숨 수)  Bonus Life(보너스 목숨)
  스위치는 게임마다 다르고, 없는 게임도 있습니다.

[다인원 모드 (3명·4명)]
  - 캡틴 코만도: 기판은 출고 시 2인 모드지만, 이 도구는 기본으로 4인 모드로 바꿉니다
    (코어 옵션의 ‘Dipswitch Play Mode’에서 되돌릴 수 있습니다).
  - 나이츠 오브 더 라운드, 더 킹 오브 드래곤즈, 머시스: 출고 시부터 3인 모드라 바꿀 필요 없습니다.
  - 천지를 먹다 2, 캐딜락 & 다이노소어 같은 Q사운드 CPS1 게임: 인원은 딥 스위치가 아니라 게임 서비스 메뉴의
    설정입니다. 세 번째 사람이 참가하지 못하면 서비스 메뉴(시작 버튼 약 2초 누르기)의 CONFIGURATION을 확인하세요.
  - 온라인 플레이에서는 같은 게임의 이 설정이 모두 같아야 합니다(다르면 ‘화면이 어긋났다’고 나옵니다).
    되도록 모두 최신 버전을 쓰세요.

[네오지오 아케이드 / 가정용 모드]
  이 도구는 기본으로 네오지오 게임(KOF, 메탈 슬러그, 사무라이 스피리츠 등)을 ‘아케이드 모드’
  (MVS 유럽·아시아판)로 실행합니다:
    - 오락실과 똑같이 V로 코인을 넣고 Enter로 시작합니다
    - 한 명이 플레이하는 중에도 다른 사람이 언제든 코인을 넣고 시작을 누르면 참가할 수 있습니다(온라인 참가도 같음)
    - 난이도, 목숨 수 등은 아케이드 서비스 메뉴에서 정합니다(위의 ‘서비스 메뉴 들어가기’)
  가정용 모드로 바꾸려면 코어 옵션에서 ‘mode’(Neo-Geo mode)를 찾으세요:
    MVS_EUR / MVS_USA / MVS_JAP  아케이드판(유럽·아시아 / 미국 / 일본), 코인 필요   ← 기본값 MVS_EUR
    AES_EUR / AES_JAP            가정용판(유럽 영어 / 일본어), 코인 불필요. 타이틀 화면 Option에서 난이도와 목숨 수 설정
    DIPSWITCH                    게임 원래 기본값(보통 아케이드판)
    UNIBIOS                      팬이 만든 확장 BIOS(치트, 지역 전환 등)
  게임마다 기억합니다. 어떤 게임을 가정용 모드로 바꾸면 다음에도 그 게임은 가정용 모드입니다.
  함께 플레이할 때는 그 게임의 모드를 모두 같게 해야 합니다. 다르면 ‘화면이 어긋남’ 알림이 뜹니다.
  주의: neogeo.zip에 해당 BIOS 파일이 들어 있어야 합니다(FBNeo용 완전한 neogeo.zip에는 보통 들어 있습니다).
  없으면 게임의 기본 모드로 돌아갑니다.


7. 필터 (화면 효과)
-------------------
게임 중에 화면 아래 메뉴 막대의 ‘Settings’ → ‘Graphics Settings’ → ‘Shaders’에서 하나를 고르면
바로 효과를 볼 수 있습니다:

  CRT easymode       옛날 브라운관 TV 느낌, 주사선 있음, 부드러운 화면. 먼저 이것을 추천
  CRT geom           브라운관의 곡면과 모서리 어두움까지 재현. 옛날 TV와 가장 비슷
  CRT aperture       애퍼처 그릴을 재현, 선명한 화면
  CRT mattias        TV 신호의 약한 번짐과 색 번짐을 재현
  2xScaleHQ          픽셀 가장자리를 둥글고 매끄럽게
  4xScaleHQ          위와 같으며 더 강하게 매끄럽게
  Disabled           필터 끄기, 원래 픽셀 그대로

  - 필터는 게임마다 저장됩니다. 어떤 게임에 고르면 다음에도 그 필터이고, 다른 게임은 따로 정합니다.
  - CRT 계열 필터는 전체 화면에서 가장 보기 좋습니다. 창이 작으면 주사선이 너무 촘촘해 보입니다.
  - 오래된 컴퓨터에서는 CRT geom이 끊길 수 있습니다. CRT easymode가 더 부드럽습니다.


8. 함께 플레이하기
------------------
[LAN 플레이 (같은 Wi-Fi / 공유기에 있는 컴퓨터)]
주소를 서로 보낼 필요가 없습니다. 각자 EmulatorJS.command(Mac)나 EmulatorJS-Windows.bat(Windows)을
더블클릭하면, 같은 네트워크에 있는 한 왼쪽 ‘🕹 지금 플레이 중’에 다른 컴퓨터에서 누가 무엇을 하는지
자동으로 나옵니다. ‘참가’를 누르면 함께 플레이합니다.

  · LAN 플레이는 기본으로 켜져 있습니다. 보이고 싶지 않으면 ‘⚙ 폴더 설정’에서 ‘LAN 플레이’ 체크를 끄세요.
  · Mac: 처음에 ‘Python이 들어오는 네트워크 연결을 허용하도록 하겠습니까?’가 나오면 ‘허용’.
  · Windows: 처음에 ‘이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?’가 나오면 ‘예’(한 번만 묻습니다).
    그때 ‘아니요’를 눌렀다면 나중에 폴더 안의 ‘Enable-LAN-Windows.bat’을 더블클릭한 뒤 EmulatorJS를 다시 여세요.
  · ‘참가’를 눌러도 플레이는 내 페이지에서 하며, 내 컴퓨터에 있는 같은 게임 파일을 씁니다.
    나에게 그 게임이 없거나 파일이 다르면, 상대 화면을 보면서 플레이하는 방식으로 자동으로 바뀝니다.
  · ‘다른 컴퓨터’라고 적힌 것은 다른 컴퓨터에서 시작한 게임이고, 적혀 있지 않은 것은 이 컴퓨터의
    라이브러리에서 시작한 게임입니다.
  · 가정용 게임기 게임도 같습니다. 목록에 같은 게임이 보이면 ‘참가’를 눌러 함께 할 수 있습니다.
  · ‘내 이름: …’을 누르면 이름을 바꿀 수 있고, 다른 사람 목록에 그 이름이 보입니다.
    욕설이나 모욕 같은 부적절한 단어는 쓸 수 없고, 플레이 중인 사람과 같은 이름도 안 됩니다
    (대소문자, 공백, 기호는 구분하지 않습니다). 부적절한 단어가 있는 이름은 자동으로 ‘플레이어’+번호로 바뀝니다.
    금지어는 data/badwords.json에 있으며 텍스트 편집기로 추가·삭제할 수 있습니다(한 단어에 한 항목).
    인터넷 플레이 서버에서는 /opt/emulatorjs-cloud/data/badwords.json이며, 바꾸면 바로 적용되고 재시작이 필요 없습니다.

EmulatorJS가 없는 기기 (태블릿, 다른 사람의 컴퓨터):
  브라우저 주소창에 EmulatorJS를 켠 컴퓨터의 주소(왼쪽에 표시됨, 예: http://192.168.1.23:8765)를 입력하면
  그 컴퓨터의 게임을 모두 보고 참가할 수 있습니다. ROM은 필요 없습니다. 이런 기기에서는 그 컴퓨터의
  폴더 설정을 보거나 바꿀 수 없습니다.
  주의: 이렇게 연 페이지에서는 브라우저가 마이크를 허용하지 않아 음성 채팅으로 말할 수 없습니다(듣기는 됩니다).

연결 방식 (자동으로 고릅니다. 설정할 것 없음):
  · 입력 동기화(실험 기능, 우선 사용): 참가하는 사람의 컴퓨터에서도 같은 게임을 실행하고, 네트워크로는
    매 프레임 누른 버튼만 보냅니다. RetroArch 넷플레이와 같은 원리입니다. 화면은 각자 컴퓨터가 그려서
    선명하고, 데이터도 거의 쓰지 않습니다. ‘다른 컴퓨터’에 참가할 때는 내 컴퓨터의 같은 게임 파일을 쓰고,
    브라우저에 LAN 주소를 입력해 연 경우에는 게임 파일을 호스트 컴퓨터에서 자동으로 읽으므로 ROM이 없어도 됩니다.
    버튼이 네트워크로 도착할 시간을 주기 위해 모든 사람의 버튼은 몇 프레임 늦게 반영됩니다
    (LAN에서는 2~3프레임 정도라 거의 느끼지 못합니다).
    2초마다 게임 상태를 맞춰 보고, 어긋나면 호스트가 상태 저장을 모두에게 보내 다시 맞춥니다.
    이때 화면이 잠깐 깜빡이거나 튈 수 있는데 정상입니다.
  · 화면 전송: 호스트 컴퓨터가 화면과 소리를 실시간으로 보내고, 참가한 사람의 버튼을 되돌려 받습니다.
    참가하는 사람에게 같은 게임 파일이 없을 때 자동으로 이 방식이 쓰입니다.
  호스트가 1P, 참가한 사람이 차례로 2P, 3P, 4P이며 최대 4명입니다(게임이 지원하는 경우).
  함께할 수 있는 인원은 기종에 따라 다릅니다: 패미컴, PS1, 네오지오 등은 2명, 슈퍼 패미컴, 메가 드라이브, N64, 기타 아케이드,
  PC 엔진은 4명, 휴대용 기기(GB / GBA / NDS / PSP 등)는 1명. 인원이 차도 관전은 할 수 있습니다. ‘지금 플레이 중’의
  ‘2/2명 · 👀 1’은 지금 플레이어 2명 / 최대 2명, 그리고 1명이 관전 중이라는 뜻입니다.
  참가한 사람은 자기 키보드나 게임패드를 혼자 할 때와 같은 배치로 씁니다.
  LAN에서는 지연이 아주 적지만 Wi-Fi 신호가 약하면 끊깁니다. 호스트 컴퓨터는 유선이 좋습니다.

입력 동기화 때 주의할 점:
  · 호스트가 오른쪽 Shift로 일시정지하면 모두 함께 멈춥니다. 참가한 사람은 일시정지할 수 없습니다.
  · 게임 리셋(Select+Start+L1+R1)과 불러오기는 호스트만 할 수 있으며, 그 뒤에는 모두에게 자동으로 동기화됩니다.
  · 각 플레이어 이름 옆에 호스트까지의 지연이 표시됩니다(초록 = 빠름, 노랑 = 보통, 빨강 = 느림, 서버를 거치면 ‘중계’).
    호스트와 참가자 모두 볼 수 있습니다. 계속 빨간 사람 때문에 모두 느려지면 호스트가 ‘👥 방’에서 내보낼 수 있습니다.
  · 위쪽의 📶 는 연결 상태입니다: 직접 연결/중계, 왕복 시간(ms), 버튼 지연 프레임 수(자동 조정).
    숫자가 계속 크면 유선 랜을 쓰거나 큰 다운로드를 멈추세요. 모두 최신 버전을 쓰는 것이 좋습니다.
  · 모두가 게임 페이지에 머물러 있어야 합니다. 한 사람이라도 다른 창으로 가거나 최소화하면 모두 멈춥니다.
  · 누군가의 네트워크가 느려지면 모두 함께 느려지고, 화면 위에 ‘X 님의 네트워크를 기다리는 중…’이 나옵니다.
  · ‘화면이 어긋남’ 알림이 계속 나오면, 보통 서로 그 게임의 설정(코어 옵션. 네오지오 가정용 / 아케이드
    모드, 난이도 등)이 다른 것입니다. 같게 맞추세요.
  · 패미컴과 메가드라이브로 테스트했습니다. 다른 기종도 이론상 되지만 하나하나 확인하지는 않았습니다.
    문제가 생기면 자동으로 다시 맞춥니다.

두 가지 온라인 방식: 딜레이 / 롤백 (버튼 동기화일 때만, 방장이 정합니다)
  ‘⚙ 폴더 설정’ → ‘온라인 방식’에서 고르고, 플레이 중에는 ‘👥 방’에서도 바꿀 수 있습니다.
  · 딜레이 모드 (기본, 안정): 위에서 설명한 방식입니다. 모두의 버튼이 몇 프레임 늦게 반영되며,
    화면이 항상 같고 네트워크가 나빠도 되감기지 않습니다.
  · 롤백 모드 (빠른 반응, 실험 기능): 내 입력은 거의 바로 반영됩니다(2프레임만 늦춤).
    상대 입력이 아직 도착하지 않았으면 ‘직전과 같은 버튼을 계속 누르고 있다’고 보고 진행하고,
    실제 입력이 도착했는데 예상이 틀렸으면 몇 프레임 전의 상태 저장을 불러와 올바른 입력으로 순식간에
    다시 실행합니다. 그래서 가끔 상대 캐릭터가 올바른 위치로 ‘휙’ 이동하는 것이 보일 수 있습니다.
    온라인 대전 격투 게임 대부분이 이 방식을 씁니다.
    · 네트워크 왕복이 100ms 이내일 때 알맞습니다. 그보다 느리면 상대 움직임이 자주 튀므로 딜레이 모드가 낫습니다.
    · 매 프레임 상태 저장을 한 번 더 하므로 컴퓨터가 충분히 빨라야 합니다. 따라가지 못하는 컴퓨터가 있으면
      그 판은 자동으로 딜레이 모드로 돌아가고 알려 줍니다.
    · 모두 새 버전이어야 합니다. 옛 버전을 쓰는 사람이 있으면 그 판은 딜레이 모드입니다.
    · 롤백 모드에서 화면이 계속 어긋나는 게임(1분에 3번)도 그 판은 자동으로 딜레이 모드로 돌아갑니다.
    · 롤백 모드에서는 일시정지할 수 없으며, 위쪽 📶에 ‘롤백’이 표시됩니다. 다시 실행할 때 가끔 소리가 살짝 튈 수 있습니다.

휴대폰과 컴퓨터가 함께 (느린 기기):
  입력 동기화에서는 모두가 한 프레임씩 함께 진행하므로, 속도는 가장 느린 기기를 따릅니다.
  휴대폰은 아케이드 게임(네오지오 등)을 컴퓨터보다 느리게 돌리므로, 다음처럼 자동으로 처리합니다:
  · 휴대폰이 컴퓨터의 게임에 참가: 휴대폰은 자동으로 ‘화면을 보며 플레이’ 방식이 됩니다. 게임은
    컴퓨터에서 돌아가므로 속도는 컴퓨터와 같습니다. 화면에 십자 키와 버튼이 나타납니다.
  · 컴퓨터가 휴대폰의 게임에 참가: 먼저 화면을 맞춘 뒤 게임을 컴퓨터로 넘기고, 휴대폰은 화면을 보며
    계속 플레이합니다. 중간에 1~2초 멈춥니다. 플레이어 번호는 그대로입니다(휴대폰은 계속 1P, 컴퓨터는 계속 2P).
  · 휴대폰·태블릿의 아케이드, PS, N64 등의 게임은 항상 ‘느림’으로 봅니다. 다른 게임은 실제로 잰 속도로
    판단하며, 아주 오래되고 느린 컴퓨터도 마찬가지입니다.
  · 휴대폰에서 아케이드 게임을 혼자 할 때는 자동 프레임 건너뛰기와 낮은 오디오 샘플링 레이트를 기본으로
    켜서 더 빠르게 돌립니다(가끔 한 프레임을 그리지 않을 뿐, 게임 속도는 그대로입니다).

다른 사람이 참가하지 못하게 하려면:
  게임 중 화면 위에 ‘참가 허용: 켜짐’ 버튼이 있습니다. 누르면 ‘꺼짐’이 되어 다른 사람이 들어올 수 없고,
  목록에는 ‘참가 불가’가 표시됩니다(이미 들어온 사람은 영향 없음).
  기본값은 마지막으로 고른 것을 따릅니다.
  다른 사람이 내 게임을 누르면 참가할 수 없다는 알림이 뜨고, 혼자 플레이를 고를 수 있습니다.

방 관리 (👥 방):
  게임 중 위쪽의 ‘👥 방’을 누르면 방에 있는 플레이어와 관전자를 볼 수 있습니다:
  · 관전 허용: 켜기 / 끄기. 한 게임에 관전은 최대 8명, 그중 화면 관전은 최대 2명입니다
    (화면 관전은 내 컴퓨터가 한 명씩 따로 영상을 압축해 보내므로, 많으면 게임이 느려집니다).
  · 등록 플레이어 전용: 켜면 로그인하지 않은 사람은 참가하거나 관전할 수 없습니다
    (LAN에서도 같으며, 인터넷 플레이 서버가 설정되어 있어야 합니다).
  · 내보내기: 두 번 누릅니다(두 번째가 확인). 내보낸 사람은 30분 동안 내 방에 들어올 수 없습니다.
    계정, 기기 번호, 네트워크 주소로 구분합니다(같은 네트워크의 다른 사람도 30분 동안 못 들어올 수 있습니다).
  · ♡: 다른 플레이어에게 좋아요를 누릅니다(상대에게 계정이 있어야 합니다).

주의:
  · 호스트 컴퓨터는 게임 페이지에 계속 머물러 있어야 합니다. 다른 창으로 가거나 최소화하면 화면이 멈출 수 있습니다.
  · 호스트가 게임을 끝내면 그 게임은 끝나고, 참가한 사람에게 알림이 갑니다.
  · 저장은 호스트 컴퓨터에 됩니다. 연사는 입력 동기화 때는 내 컴퓨터의 설정을, 화면 전송 때는 호스트 컴퓨터의 설정을 씁니다.
  · LAN 플레이는 같은 네트워크 안에서만 됩니다. 멀리 있는 친구와는 아래 방법을 보세요.

[음성 채팅]
  함께 플레이할 때 화면 위에 ‘🎤 음성: 꺼짐’ 버튼이 있습니다. 누르면 켜져서 함께 하는 사람과 이야기할 수
  있습니다(모두가 서로의 말을 들을 수 있습니다).
  · 처음에는 브라우저가 마이크 사용을 물어보니 ‘허용’을 고르세요. 한 번 켜면 다음 함께 플레이 때부터 자동으로 켜집니다.
  · 음성을 꺼도 다른 사람에게 내 목소리가 안 들릴 뿐, 다른 사람 목소리는 들립니다.
  · 누가 말하면 위쪽 그 사람 이름 주위가 빛납니다.
  · 이어폰을 꼭 쓰세요. 쓰지 않으면 마이크가 게임 소리와 다른 사람의 목소리를 다시 보내 울림이 생깁니다.
  · 마이크는 내 컴퓨터에서 EmulatorJS를 열었을 때(주소가 127.0.0.1)만 쓸 수 있습니다.
    태블릿 등에서 LAN 주소로 바로 연 페이지는 브라우저가 마이크를 허용하지 않습니다.

[멀리 있는 친구와 플레이 (인터넷 플레이 서버)]
다른 네트워크에 있는 친구와 플레이하려면 모두가 접속할 수 있는 ‘플레이 서버’(클라우드 서버 등)가 필요합니다.
쓰는 방법은 LAN과 같습니다. ‘지금 플레이 중’에 멀리 있는 친구의 게임이 (‘인터넷’ 표시와 함께) 나오고,
‘참가’를 누르면 됩니다. 음성 채팅도 됩니다.

컴퓨터마다 설정 (한 번만):
  ‘⚙ 폴더 설정’ → ‘인터넷 플레이 서버’에 서버 주소(예: http://1.2.3.4:8765)와 방 비밀번호를 넣고
  ‘저장하고 테스트’를 눌러 ‘연결됨’이 나오면 끝입니다.
  이 설정은 EmulatorJS 폴더의 config.json에 저장됩니다. 설정한 뒤 폴더째로 친구에게 보내면
  친구는 다시 입력하지 않아도 됩니다.
  주의: config.json 에는 방 비밀번호가 들어 있어서, 이 폴더를 받은 사람은 누구나 당신의 서버에 들어올 수 있습니다.
  믿을 수 있는 사람에게만 보내세요. 바로 접속하게 하고 싶지 않다면 config.json 을 지운 뒤 보내고,
  서버 주소와 방 비밀번호는 상대가 직접 입력하게 하세요.

서버는 여러 개 저장할 수 있습니다: 다른 주소와 방 비밀번호를 넣고 ‘추가하고 바꾸기’를 누르세요.
서버 하나가 로비 하나이며, 왼쪽 ‘지금 플레이 중’ 아래의 ‘🌐 로비: …’에서 바꿉니다. 로비마다 서버가 있는
나라·지역의 국기, 방 수, 접속자 수가 표시됩니다. 계정·친구·전적은 서버마다 따로이므로, 다른 로비에서는
그곳에서 다시 가입하거나 로그인하세요.

주의:
  · 인터넷 판 옆에는 호스트 네트워크가 있는 나라·지역의 국기가 표시됩니다(IP로 대략 판단). 지연을
    가늠하는 데 참고하세요.
  · 게임이 없는 사람은 ‘참가’할 때 호스트에게 다운로드를 요청할 수 있습니다. 호스트에게 ‘허락 / 허락 안 함 /
    앞으로 항상 허락’이 뜨고, 허락하면 게임 파일, 미리보기 그림 3장, 없는 BIOS가 호스트 컴퓨터에서 바로(서버를 거치지 않고) 전송되어
    내 ROM 폴더의 같은 기종 폴더에 저장된 뒤 자동으로 참가합니다.
  · 연결이 안 되거나 끊길 때: 참가 후 20초 안에 연결되지 않으면 안내와 함께 자동으로 나갑니다. 게임 중
    15초 동안 끊기면 참가한 사람은 자동으로 나가고, 호스트는 계속 플레이합니다. 한쪽이 VPN을 켜 두면
    연결이 안 되거나 지연이 매우 커지는 일이 많습니다.
  · 인터넷으로 참가할 때도 내 컴퓨터의 같은 게임 파일을 쓰므로(입력 동기화) 모두의 ROM이 같아야 합니다
    (같은 EmulatorJS 패키지를 쓰면 문제없습니다). 그 게임이 없는 사람은 화면 전송 방식이 되어 서버 데이터를 더 씁니다.
  · 거리가 멀수록 버튼이 늦게 반영되는 프레임 수가 늘어납니다(네트워크 속도를 재서 자동으로 조절). 격투
    게임은 조금 무겁게 느껴질 수 있습니다.
  · 비밀번호를 아는 사람은 서버의 모든 게임을 볼 수 있습니다. 참가를 막으려면 참가 허용을 끄세요.

플레이 서버 만들기 (한 번만, 클라우드 서버가 있는 사람이 합니다):
  Ubuntu 22.04 / 24.04 클라우드 서버가 필요합니다(가장 싼 작은 서버로 충분).
  1. 클라우드 콘솔의 ‘방화벽’에서 TCP 8765, TCP 80, TCP 3478, UDP 3478, UDP 49160-49250을 엽니다.
     (TCP 80은 무료 https 인증서를 받는 데 써서 비밀번호 등을 암호화해 보냅니다. 인증서는 3일마다 자동으로 갱신됩니다)
  2. 콘솔의 ‘로그인’으로 웹 터미널을 열고, 폴더 안의 ‘cloud-server/ejs-cloud-setup.sh’를 서버에 올립니다.
  3. 터미널에서 실행: sudo bash ejs-cloud-setup.sh
     비밀번호를 직접 정하려면: sudo bash ejs-cloud-setup.sh 비밀번호 (영문자와 숫자만)
     도메인이 있다면 (먼저 DNS A 레코드로 서버 IP를 가리키게 설정): sudo bash ejs-cloud-setup.sh 도메인
     예: sudo bash ejs-cloud-setup.sh example.site. 이후 주소는 https://도메인:8765 입니다.
     기존 IP 주소도 그대로 쓸 수 있고, 각 컴퓨터는 접속하면 자동으로 도메인 주소로 바뀝니다
     (나중에 서버 IP가 바뀌어도 도메인의 A 레코드만 고치면 됩니다).
  4. 끝나면 서버 주소(https://로 시작)와 방 비밀번호가 나오니 위 설정에 입력하세요.
     전에 넣은 http 주소는 바꾸지 않아도 됩니다. EmulatorJS가 자동으로 https로 바꾸고, 설정에 ‘🔒 암호화 연결’이 보입니다.
  서버는 재부팅해도 자동으로 실행됩니다.
  서버 업데이트: EmulatorJS를 업데이트한 뒤 새 ‘cloud-server/ejs-cloud-setup.sh’를 다시 올리고(덮어쓰기)
  sudo bash ejs-cloud-setup.sh를 실행하면 됩니다. 비밀번호는 그대로이고, 플레이 중인 사람은 잠깐 끊기니 다시 참가하면 됩니다.
  (주의: 서버의 금지어 파일이 새 것으로 덮어써집니다. 서버에서 직접 추가한 단어는 다시 넣어야 합니다.)
  계정 관리: 서버 터미널에서 sudo ejs-admin 을 실행하고 영어 메뉴에서 번호를 고릅니다:
    사용자 목록 / 검색, 비밀번호 재설정, 이름 변경, 이용 정지 / 해제, 계정 삭제, 대전 결과 목록 / 삭제.
    메뉴 10 ‘Server limits’에서 서버 상한(동시 접속 인원, 방 개수, 중계 속도)을 설정할 수 있습니다.
    메뉴 11 ‘Developer (admin) account’에서 관리자 전용 계정 ‘开发者’ 또는 ‘Developer’를 만듭니다. 이 단어가
    들어간 이름은 플레이어가 가입하거나 사칭할 수 없고, 이 계정으로 로그인하면 로비·방·순위에서 이름이
    색깔과 🛠로 눈에 띄게 표시됩니다.
  (이용 정지된 사용자는 로그인할 수 없고 바로 로그아웃됩니다. 계정을 삭제하면 친구와 대전 결과도 함께 지워지며
   되돌릴 수 없습니다.)

[로비]
  왼쪽 ‘지금 플레이 중’ 옆의 ‘⤢ 로비’(휴대폰은 오른쪽 위 🕹)를 누르면 전체 화면 로비가 열립니다:
  · ‘지금 플레이 중’: LAN과 인터넷에서 플레이 중인 모든 게임. 게임 이름이나 플레이어 이름으로 검색하고,
    ‘참가 가능 / 도전 모드 / 격투 / 친구 / LAN / 인터넷’으로 거를 수 있습니다. 모든 게임에서 ‘참가’나
    ‘👀 관전’을 할 수 있습니다(관전하는 사람은 보기만 하고 조작할 수 없습니다).
  · ‘친구’, ‘순위’, ‘내 전적’: 먼저 계정으로 로그인해야 합니다(아래 참고).

[계정, 친구, 전적] (인터넷 플레이 서버 필요)
  가입하지 않아도 플레이하고 함께 플레이할 수 있습니다. 계정을 만들면 전적과 친구 기능이 생깁니다.
  · 가입: 로비 오른쪽 위 ‘가입’을 누르고 이름(2~16자, 부적절한 단어 불가)과 비밀번호(6자 이상)를 넣고
    지역을 고릅니다. 계정은 인터넷 플레이 서버에 저장되어 다른 컴퓨터에서도 로그인할 수 있습니다.
    로그인하면 함께 플레이할 때 계정 이름과 지역(국기로 표시)이 쓰입니다.
  · 친구: ‘친구’에서 상대의 계정 이름을 입력해 요청을 보내고, 상대가 수락하면 친구가 됩니다.
    친구가 온라인인지, 무엇을 하는지 보이고, 친구가 하는 게임에 한 번에 참가하거나 관전할 수 있습니다.
  · 전적: 플레이한 게임, 플레이 시간, 함께 플레이한 횟수, 함께 한 사람을 자동으로 기록합니다.
  · 승패: 함께 한 판이 끝나면 화면 위 ‘🏆 승패 기록’에서 승자를 고릅니다. 다른 사람에게 확인 알림이 가고,
    모두 ‘맞아요, 확인’을 눌러야 기록됩니다. 누군가 ‘틀려요’를 누르면 그 기록은 취소됩니다.
  · 챔피언: 한 게임에서 10승 이상, 승률 60% 이상이면 그 게임의 챔피언이 되고, 로비에서 이름이 금색과 👑로 보입니다.
  · 좋아요: 로비, 친구 목록, 플레이어 기록, 게임 중 ‘👥 방’에서 ♡를 누르면 좋아요를 보내고, 다시 누르면 취소됩니다.
    순위의 ‘♥ 인기 순위’는 받은 좋아요 수로 정렬됩니다.
  · 도전 모드: 격투 게임에서 호스트는 화면 위 ‘🥊 도전 모드’를 누를 수 있습니다. 로비 맨 위에 ‘도전 환영’과
    함께 표시되어 누구나 도전하러 올 수 있습니다.
  · 휴대폰·태블릿에서 LAN 주소로 연 페이지도 로그인하고 인터넷 게임을 볼 수 있습니다. 요청은 호스트
    컴퓨터가 대신 전달합니다(그 컴퓨터에 인터넷 플레이 서버 설정이 필요합니다).

[화면 언어]
  왼쪽 위 국기 버튼으로 화면 언어를 바꿀 수 있습니다: 简体中文, 繁體中文, English, 日本語, 한국어, Español,
  Français, Deutsch, Português, Русский. 기본값은 컴퓨터 시스템 언어와 같습니다.
  게임 이름은 영어 제목이 표시되며, 고른 언어로 된 제목이 있으면 함께 표시됩니다.
  번역은 data/i18n 폴더에 있고(data/names.json은 게임 이름 번역) 직접 고칠 수 있습니다.

다른 방법:
  · Parsec(https://parsec.app) 원격 플레이: 친구가 내 컴퓨터에 접속해 내 화면을 보고, 친구의 게임패드가
    내 컴퓨터의 두 번째 게임패드가 됩니다. 친구는 ROM도 EmulatorJS도 필요 없습니다.
  · 둘 다 RetroArch가 있다면 RetroArch 자체의 넷플레이도 쓸 수 있습니다.


9. BIOS
-------
  패미컴, 슈퍼 패미컴, 메가드라이브   필요 없음
  세가 메가 CD                       필수: bios_CD_U.bin(북미판), bios_CD_J.bin(일본판), bios_CD_E.bin(유럽판)
  아케이드 (FBNeo)                   대부분 필요 없음. 네오지오 게임(KOF, 메탈 슬러그 등)은 neogeo.zip,
                                     PGM 게임은 pgm.zip이 필요

  BIOS가 없으면 세가 CD 게임을 누를 때 ‘BIOS가 없어 실행할 수 없습니다’가 나옵니다.
  BIOS 폴더를 정하면 왼쪽 위에 ‘BIOS 찾음: 세가 메가 CD (U/J)’ 같은 표시가 나옵니다.
  알파벳은 어느 지역의 BIOS가 있는지를 뜻합니다.


10. 자주 묻는 질문
------------------
  게임을 눌러도 계속 검은 화면이에요
    → 실행 파일로 열었는지 확인하세요(주소창에 http://127.0.0.1 또는 http://localhost).
      index.html을 직접 더블클릭해서 연 경우(주소창에 file://)는 작동하지 않습니다.

  EmulatorJS.command를 더블클릭해도 아무 반응이 없어요 (Mac)
    → 복사하다가 ‘실행 가능’ 권한이 없어졌을 수 있습니다. ‘터미널’을 열고
         chmod +x
      를 입력한 뒤(끝에 공백이 있습니다), EmulatorJS.command를 터미널 창으로 끌어다 놓고 Enter를 누른 다음
      다시 더블클릭해 보세요.

  Mac에서 EmulatorJS.command에 게임패드 아이콘이 안 보여요
    → 한 번 더블클릭해서 실행하면 자동으로 붙습니다. 그래도 그대로면 Finder 창을 닫았다가 다시 여세요
      (Finder는 바로 새로 고쳐지지 않을 때가 있습니다). 아이콘 파일은 data/icon.png이니 지우지 마세요.

  Windows에서 ‘EmulatorJS’ 바로가기가 안 생겨요
    → 먼저 EmulatorJS-Windows.bat을 한 번 더블클릭하세요. 같은 폴더에 바로가기가 생깁니다.
      data 폴더에 icon.ico가 있는지, start-windows.ps1이 .bat과 같은 곳에 있는지 확인하세요.

  일부 게임이 실행되지 않아요
    → BIOS가 필요한 게임이 있습니다(9장). 또 원래 다른 에뮬레이터용인 아케이드 게임은 웹 버전 FBNeo에서
      돌아가지 않으니 RetroArch로 플레이하세요.

  설정, 계정, 저장 파일은 어디에 저장되나요?
    → 계정(이름, 친구, 전적): 인터넷 플레이 서버에 저장되므로 다른 컴퓨터나 휴대폰에서도 로그인할 수 있습니다.
      비밀번호는 암호화된 형태로만 저장됩니다.
      설정(폴더, 인터넷 플레이 서버 주소와 방 비밀번호): 각 기기의 config.json 에 저장 ——
        폴더판(.command / .bat): EmulatorJS 폴더의 config.json
        Windows 데스크톱 앱: %APPDATA%\EmulatorJS\config.json
        Mac 데스크톱 앱: ~/Library/Application Support/EmulatorJS/config.json
        안드로이드 앱: 앱 전용 데이터 안(앱을 삭제하거나 데이터를 지우면 함께 지워짐)
      로그인 상태, 플레이어 이름, 화면 언어, 색 테마, 배경 이미지, 최근 플레이, 게임 저장과 상태 저장: 브라우저에 저장
      (데스크톱 앱과 안드로이드 앱은 앱 전용 데이터 안). 기기마다 따로 저장되며 서버로 올라가지 않습니다.
      브라우저를 바꾸거나 브라우저 데이터를 지우거나 앱을 삭제하면 사라지니, 저장은 게임 아래 메뉴 막대의
      ‘Export Save File(저장 파일 내보내기)’로 백업하세요.
