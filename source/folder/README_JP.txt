EmulatorJS 使い方ガイド
================================

EmulatorJS は、ブラウザでレトロゲームを遊べるツールです。RetroArch のインストールも、
インターネット接続も必要ありません。
ファミコン、スーパーファミコン、ゲームボーイ / GBA、N64、NDS、メガドライブ / メガCD / 32X / サターン、
PS1、PSP、PC エンジン、アーケード（FBNeo / MAME 2003）など 20 以上の機種に対応しています。


1. フォルダの中身
-----------------
  index.html              ゲームのページ（直接ダブルクリックで開かないでください）
  data/                   エミュレーターとコア。変更しないでください
  EmulatorJS.command      Mac 用の起動ファイル
  EmulatorJS-Windows.bat  Windows 用の起動ファイル
  start-windows.ps1       Windows の起動ファイルが使うスクリプト。.bat と同じ場所に置いてください
  Enable-LAN-Windows.bat  Windows の LAN 対戦の許可（初回に自動で表示されます。そのとき「いいえ」を
                          選んだ場合だけ、手動でダブルクリックしてください）
  cloud-server/           インターネット対戦サーバーを作るためのスクリプト（クラウドサーバーでだけ使用、第 8 章）
  server.py               Mac の起動ファイルが使う小さなローカルサーバー
  config.json             フォルダ設定を初めて保存したときに作られ、選んだフォルダを記録します
  EmulatorJS.lnk          Windows の初回起動時に作られるショートカット（コントローラーのアイコン付き）
  LICENSE                 EmulatorJS のオープンソースライセンス（GPL-3.0）
  README_JP.txt など      このガイド。言語ごとに 1 つ：CN 简体中文、HK 繁體中文、US English、JP 日本語、
                          KR 한국어、ES Español、FR Français、DE Deutsch、BR Português、RU Русский


2. 開き方
---------
【デスクトップ版（おすすめ）】
  ブラウザやターミナルウィンドウを使いたくない場合はデスクトップ版を使えます。ダブルクリックでゲーム画面が開き、
  ウィンドウを閉じると終了します。
  · Windows：EmulatorJS-Setup-バージョン.exe はインストール版（インストール先を選べます。スタートメニューとデスクトップにアイコンを作成）、
    EmulatorJS-バージョン-win.zip はインストール不要：好きなフォルダーに展開して、中の EmulatorJS.exe をダブルクリックするだけで遊べます。
    初回に「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
    ネットワークへのアクセスを聞かれたら「プライベート ネットワーク」にチェックして「許可」（LAN 対戦に必要）。
  · Mac：M1 / M2 / M3 / M4 チップは …-mac-apple-silicon.dmg、Intel チップは …-mac-intel.dmg。
    dmg を開いて EmulatorJS を「アプリケーション」にドラッグします。
    初回は開発元を確認できないと表示されます：「システム設定 → プライバシーとセキュリティ」で「このまま開く」。
    ローカルネットワークのデバイス検索やマイクの使用を聞かれたら「許可」（LAN 対戦・ボイスチャットに必要）。
  · ゲームのフォルダ：「書類 / EmulatorJS」の roms・thumbnails・system と RetroArch の標準の場所を自動で探します。
    「⚙ フォルダ設定」で選ぶこともできます。初回起動時は元の EmulatorJS フォルダの設定を引き継ぎます。
  · 設定はアプリ専用のデータフォルダに保存されます。元の EmulatorJS.command / EmulatorJS-Windows.bat も
    そのまま使え、両方で一緒に対戦できます。
  · 設定ファイル config.json（フォルダ設定、インターネット対戦サーバーのアドレスとルームパスワード）の場所：
    Windows：%APPDATA%\EmulatorJS\config.json（エクスプローラーのアドレス欄に %APPDATA%\EmulatorJS と入れて Enter）
    Mac：~/Library/Application Support/EmulatorJS/config.json（Finder で Shift+Command+G を押してこのパスを貼り付け）

【Android スマホ / タブレット / Android TV（APK）】
  · スマホ、タブレット、テレビ、TV ボックス：EmulatorJS-バージョン-android.apk
    パソコン上の Android エミュレーター（MuMu など）：EmulatorJS-バージョン-android-x86_64.apk
    Android 7.0 以降が必要です。テレビの「Android System WebView」が古すぎる場合は更新を促す表示が出ます。
  · インストール：apk をスマホ / テレビに送り（USB ケーブル、USB メモリ、チャットアプリなど）、ファイル管理アプリで開きます。
    「提供元不明のアプリはインストールできません」と出たら、そのファイル管理アプリに許可して、もう一度 apk を開きます。
    テレビ：apk を USB メモリにコピーしてテレビに挿し、テレビのファイル管理アプリで開きます。
  · 初回起動時に写真とファイル（ストレージ）へのアクセスを聞かれたら「許可」を選んでください。許可しないとゲームを読めません。
    その後「本体ストレージ / EmulatorJS」フォルダが作られ、中に roms、thumbnails、system の 3 つのフォルダがあります。
  · ゲームの入れ方：スマホをケーブルでパソコンにつなぎ（スマホ側で「ファイル転送」を選ぶ）、EmulatorJS / roms にコピーします。
    入れ方はパソコンと同じです（第 3 章）。表紙画像は thumbnails、BIOS は system へ。入れたら「↻ 再読み込み」を押します。
    別の場所に置いて「⚙ フォルダ設定」で選ぶこともできます。フォルダ選択画面には「本体ストレージ」「ダウンロード」などの
    ショートカットボタンがあります。
  · テレビで USB メモリを読む：USB メモリの一番上に EmulatorJS か RetroArch フォルダ（中に roms など）があれば自動で見つけます。
    「⚙ フォルダ設定」の「USB メモリ / SD カード」から選ぶこともできます。中身を変えたら「↻ 再読み込み」を押します。
    Android ではアプリが USB メモリに書き込めないため、通信プレイ中にほかの人のパソコンからダウンロードしたゲームは
    「EmulatorJS / downloads」に保存され、USB メモリのゲームと一緒に表示されます。
  · 操作：
    スマホ：画面上の仮想ボタン、または Bluetooth / USB コントローラー。
    テレビ：リモコンでゲームを選び（十字キーで移動、決定 / OK で開く、戻るで戻る）、コントローラーで遊びます。
    ゲーム中にリモコンやスマホの戻るキー（またはコントローラーで Select + Start を長押し）でゲームメニューが開きます：
    再開、ステートセーブ、ステートロード、リセット、全画面、ゲーム終了。ゲーム一覧で戻るキーを 2 回押すとアプリを終了します。
  · 通信プレイ、ロビー、アカウントはパソコン版と同じで、パソコンとも一緒に遊べます（LAN では同じ Wi-Fi につなぐ）。
    ボイスチャットを初めて使うときはマイクの使用を聞かれるので「許可」を選んでください。
  · 安い TV ボックスは性能が低めです：ファミコン、スーファミ、GBA、メガドライブは快適、N64、PSP、NDS、セガサターンは重いことがあります。

【Mac】
  1. EmulatorJS.command をダブルクリックします。
     初回に「開発元が未確認のため開けません」と出たら、
     右クリック →「開く」→ もう一度「開く」。次からはダブルクリックで開けます。
  2. ターミナルのウィンドウが開き、ブラウザでゲームのページが自動で開きます。
     「コマンドライン・デベロッパ・ツール」のインストールを求められたら「インストール」を押し、
     終わったらもう一度ダブルクリックしてください。
  3. 遊んでいる間はターミナルのウィンドウを閉じないでください。遊び終わったら閉じます。
  起動ファイルには自動でコントローラーのアイコンが付きます。コピーでアイコンが消えても、
  一度起動すれば元に戻ります。

【Windows】
  1. EmulatorJS-Windows.bat をダブルクリックします。
     青い「Windows によって PC が保護されました」が出たら：「詳細情報」→「実行」。
  2. 黒いコマンドウィンドウが開き、ブラウザでゲームのページが自動で開きます。
  3. 遊んでいる間はこのウィンドウを閉じないでください。遊び終わったら閉じます。
  Windows では .bat にアイコンを付けられないため、初回起動後にアイコン付きの「EmulatorJS」
  ショートカットがフォルダに作られます。次からはそれをダブルクリックしてください。デスクトップにも置けます。
  フォルダを移動するとショートカットが使えなくなるので、.bat をもう一度ダブルクリックすると作り直されます。

なぜこのウィンドウを開いておくの？
  ウィンドウの中では、この PC からだけアクセスできる小さな Web サーバーが動いています。
  ブラウザはセキュリティ上、ダブルクリックで開いたページからエミュレーターのファイルを読めないため、
  このサーバー経由で開いています。ウィンドウを閉じるとサーバーも止まります。

【新しいバージョンへの更新】
  · 起動時（その後は 6 時間ごと）に新しいバージョンがあるか確認し、あれば更新内容を表示します。
    左のバージョン番号の横にも「🆕 新しいバージョン」と出ます。バージョン番号を押すといつでも手動で確認できます。
    ゲーム中に表示されることはありません。
  · Windows のインストール版（EmulatorJS-Setup-バージョン.exe で入れたもの）：「自動で更新」を押すと新しいインストーラーを
    ダウンロードして欠けがないか確認します。終わったら「今すぐインストール」：アプリが閉じ、新しいバージョンを入れて
    自動で開き直します（約 30 秒）。ゲーム・設定・セーブは残ります。
    ダウンロードがとても遅い（5 分以上かかりそう）か失敗したときは、Baidu ネットディスクからのダウンロードを案内します。
  · Mac・Windows の zip 版・フォルダ版・Android：「新しいバージョンをダウンロード」（中国国内なら Baidu ネットディスク）を押し、
    案内に沿って古いバージョンと置き換えます（Mac：新しい EmulatorJS を「アプリケーション」にドラッグして「置き換える」、
    フォルダ版：新しいファイルを元のフォルダに上書きコピー）。
  · ダウンロード：https://github.com/supwang/emulatorjs-releases/releases
    Baidu ネットディスク：https://pan.baidu.com/s/13atBCqmTib1rGp_30279mQ?pwd=6akk（抽出コード 6akk）
  · 入れたくないバージョンは「このバージョンをスキップ」。確認はダウンロードサイトのバージョン情報を読むだけで、何も送信しません。


3. ゲームのフォルダ（設定は 1 回だけ）
-------------------------------------
ページを開くと、次の 3 つのフォルダを自動で読み込みます。毎回選ぶ必要はありません。

  ROM フォルダ           ゲームをまとめたフォルダ（必須）
  サムネイルフォルダ     RetroArch の thumbnails フォルダ（任意。ゲームのカバーを表示）
  BIOS フォルダ          BIOS を入れたフォルダ（任意。一部の機種だけ必要、第 9 章）

【自動検索】設定していないフォルダは次の順に探し、見つかればそのまま使います：
  1. EmulatorJS フォルダの中（EmulatorJS.command・EmulatorJS-Windows.bat と同じ場所）の
     roms、thumbnails、system フォルダ（BIOS フォルダは bios という名前でも可）
  2. RetroArch の標準の場所
     Mac：~/Library/Application Support/RetroArch/ の roms、thumbnails、system
     Windows：%APPDATA%\RetroArch、または C:/D:/E:/F: ドライブの RetroArch-Win64、RetroArch、
              Games\RetroArch-Win64 などの中の roms、thumbnails、system
  RetroArch を標準の場所で使っていれば、初回からすぐに遊べます。
  人に渡すときは、roms、thumbnails、system の 3 つを EmulatorJS フォルダに直接入れておけば、
  相手は解凍して開くだけで遊べます。

【手動で設定】左上の「⚙ フォルダ設定」を押します：
  1. 各項目の「参照…」を押し、フォルダを順にたどって「このフォルダを選ぶ」を押します。
     上に「ホーム」「デスクトップ」「RetroArch」などのショートカットがあります。パスを貼り付けても構いません。
  2. 「保存してゲームを読み込む」を押します。設定は config.json に保存され、次回から自動で使われます。
  - 「クリア」して保存すると、自動検索に戻ります。
  - 設定したフォルダが見つからなくなった場合（別の PC に移したときなど）は自動検索に戻り、
    設定画面にその旨が表示されます。

【画像の自動ダウンロード】
  カバーのないゲームは、libretro コミュニティの画像集（libretro-thumbnails。RetroArch と同じもの）から、カバー・タイトル画面・
  ゲーム画面を自動でダウンロードして画像フォルダに保存できます（未設定なら ROM フォルダの隣に thumbnails フォルダを作ります）。
  · カバーのないゲームを初めて読み込んだときに確認が出ます。同意すると、あとで追加したゲームも自動でダウンロードします。
  ·「⚙ フォルダ設定」→「画像を自動でダウンロード」でオン・オフでき、「⬇ 足りない画像を今すぐダウンロード」もあります。
  · ゲーム名で画像を探します（アーケードは FBNeo の正式名）。No-Intro などの標準的なファイル名がおすすめで、
    日本語名や自分で変えた名前は見つからないことがあります。
  · GitHub につながる必要があります。左上に進み具合が出て、いつでも「停止」できます。画像はコミュニティが集めたもので、著作権は各ゲーム会社にあります。

【新しいゲームを入れたら】左上の「↻ 再読み込み」を押します。ページを開き直す必要はありません。

【新しいゲームの機種の判定】
  各ゲームの機種は次の順で判定し、先に分かったものが使われます：
  1. RetroArch のプレイリストに記録された機種（このツールにはゲームリストが付属しています）
  2. 以前に手動で選んだ機種（「機種を手動で選択」で一度選べば記憶されます）
  3. 拡張子：.nes .sfc .smc .md .gen .gba .gb .n64 .nds など
  4. ファイルの中身：
     - 圧縮ファイル（.zip）：中身を見て判定（たとえば .sfc ならスーファミ、.md ならメガドライブ）
     - ディスク / カートリッジのイメージ（.bin .iso .cue）：先頭の目印を読み、メガドライブ、メガCD、
       サターン、PS1 などを判別
  5. 入っているフォルダの名前：snes、md、fbneo、「Nintendo - Super Nintendo Entertainment System」など
  6. 圧縮ファイルの中に既知のカートリッジ形式がない → アーケードのゲームとみなします
  7. それでも分からないもの（.7z、.chd など）は「機種を手動で選択」に入ります。一度選べば記憶されます
  アーケードゲームは FBNeo 公式のゲーム一覧（8000 本以上）とも照合し、一覧にないファイル名のもの
  （NAOMI の cvs2.zip など）は FBNeo で動かないため「Web 版は非対応」に入ります。
  そのため、いろいろなゲームが 1 つのフォルダに混ざっていても、たいていは正しい機種に分類されます。
  読むのはファイルの先頭と目次の一部だけなので高速です。判定結果は記憶され、次回は判定し直しません。

ヒント：
  - ROM フォルダは機種ごとにサブフォルダ（snes、md、nes、fbneo など、または RetroArch でよく使う
    「Nintendo - Super Nintendo Entertainment System」のような名前）に分けるのがおすすめです。
    機種を自動で判別できます。
  - 左上に「⚙ フォルダ設定」ではなく「ROM フォルダを選ぶ」など 3 つのボタンが出ている場合は、
    開き方が違うか古い起動ウィンドウを使っています。ターミナル / コマンドウィンドウをすべて閉じて、
    起動ファイルから開き直してください。


4. 遊ぶ
-------
  1. 左は機種の一覧で、それぞれ本体の画像が付いています。ネオジオのゲームは「Neo Geo」として
     別に表示され、それ以外のアーケードゲームは「アーケード (FBNeo)」に入ります。
     機種を押すと、右にその機種のゲームのカバーが並びます。
     一番上の「🕘 最近遊んだゲーム」には、この PC で最近遊んだ 10 本が並び、押せばすぐ遊べます。
     記録を消すには：表紙にマウスを乗せて右上の ✕ を押します（コントローラーは選んで X、キーボードは Delete）。
     「履歴を消去」で全部消せます。
     ゲームにマウスを乗せると、カバー → タイトル画面 → スクリーンショットと画像が切り替わります。
     カバーの下の点は全部で何枚あり今何枚目かを示します。マウスを離すとその画像のまま止まります。
     （ない画像は飛ばし、画像が 1 枚だけのゲームは切り替わりません。）
     カバーの大きさ：カバー一覧の右上で「小 / 中 / 大 / 特大」を選べます。機種ごとに別々に記憶されます。
  2. カバーを押すとゲームが始まります。
  3. 右上の「ゲームを終了」でカバー一覧に戻ります。
  4. 検索ボックスで名前からゲームを探せます。
  5. 左の一番下の「⌨ ショートカット」に、コイン、スタート、リセット、一時停止、連射、セーブ / ロード、
     アーケードのサービスメニューなどのキーボードとコントローラーの操作がまとめてあります。
     見出しを押すと折りたたみ / 展開でき、選択は記憶されます。
  6. 配色：左上の「EmulatorJS」の横の 🎨 を押すと、7 種類から選べます
     （子どもの頃〔標準：夕暮れのゲームセンター、背景画像つき〕、ナイトアーケード〔ダーク〕、セガブルー〔鮮やか〕、ゲームボーイグリーン、スーファミ グレー＆パープル〔ライト〕、
       クリームカートリッジ〔ライト〕、キャンディピンク〔ライト〕）。
     背景・文字・ボタンがまとめて変わり、選択は記憶されます。
     同じパネルで「背景画像」も設定できます：パソコンの画像を選ぶと、右のゲーム一覧の後ろに表示されます
     （スクロールしても動きません）。共通の 1 枚のほか、機種ごとに別の画像も設定できます（個別に設定していない
     機種は共通の画像）。「暗さ」スライダーで画像を暗くすると文字が読みやすくなります。画像はこの端末のこの
     ブラウザーにだけ保存されます。
     プレイ中はゲーム画面の左右の余白にもこの画像が（暗く・ぼかして）表示されるので、縦画面のゲームでも両側が真っ黒になりません。
     同じパネルでオフにできます。
  7. 言語：左上の国旗のボタンを押します（第 8 章【表示言語】）。

  - 「機種を手動で選択」：機種を判別できなかったゲームです。機種を選ぶとそのグループに移ります。
  - 「Web 版は非対応」：ブラウザ版では動かないゲーム（セガ NAOMI など）。RetroArch で遊んでください。
    この一覧を見たくないとき：開いて右上の「この一覧を表示しない」を押すか、「⚙ フォルダ設定」でチェックを外します。

ゲーム中のボタン設定、セーブ、ステートセーブ、全画面などは、ゲーム画面の下のメニューバーにあります。
「Control Settings（操作設定）」でキーボードのキーを確認・変更でき、コントローラーにも対応しています。
セーブはブラウザ内に保存されるため、ブラウザを変えたりブラウザのデータを消したりすると失われます。
バックアップするには、メニューの「Export Save File（セーブファイルを書き出す）」を使ってください。

チート：メニューバーの「チート」(Cheats) →「チートの追加」(Add Cheat) でコードと説明を入れて「適用」し、チェックを入れると有効、
もう一度押すと無効になります。コードの形式は機種によります（ファミコンは Game Genie、GBA は Action Replay / GameShark など）。
ネットで「ゲーム名 チート」と検索すると見つかります。チートによっては、オフにしてもゲームをやり直すまで元に戻らないものがあります。
ほかのプレイヤーと通信プレイ中はチートが自動でオフになり、チートボタンも隠れます。1 人に戻ると元に戻ります。

チートライブラリ：「チート」(Cheats) メニューのいちばん上の「📚 チートライブラリから選ぶ（libretro）」を押すと、ゲーム名でこのゲームの
チートを探します（libretro コミュニティのデータベース libretro-database。ファミコン・スーファミ・メガドライブ・GBA などは充実、
アーケードはほぼなし）。チェックして「選んだチートを追加」を押し、「チート」でチェックすると有効になります。
通信プレイ中は使えません。GitHub につながる必要があります。


5. キーボードとコントローラー
-----------------------------
【キーボードの標準配置】（プレイヤー 1）

  方向                W 上   S 下   A 左   D 右
  スタート            Enter
  セレクト / コイン   V

  ファミコン          J = A    K = B
  スーファミ          J = A    K = B    I = X    L = Y    U = L ボタン    O = R ボタン
  メガドライブ / CD   下段 J K L = A B C        上段 U I O = X Y Z
  アーケード ネオジオ（KOF、メタルスラッグ、サムライスピリッツなど）
                      J = A    K = B    I = C    L = D
                      U = A+B 同時   O = C+D 同時   （A+B+C、B+C+D は標準ではキーなし）
  アーケード（その他）J K I L = ボタン 1 2 3 4    U O = ボタン 5 6
  アーケード（6 ボタン格闘：ストリートファイター、ヴァンパイア、マーヴル系など）
                      弱パンチ J   中パンチ K   強パンチ L
                      弱キック U   中キック I   強キック O
                      （パンチ 3 つ同時・キック 3 つ同時は標準ではキーなし）

  一時停止 / 再開     右 Shift
  連射 オン / オフ    T
  リセット            V + Enter + U + O を同時押し（多数入りカートリッジはゲーム選択画面に戻ります）
  ステートセーブ 1    ステートロード 2    スロット切り替え 3
  （早送り・スロー・巻き戻しは標準ではキーなし。「Control Settings」で設定できます）

  - アーケードゲームは ROM のファイル名から配置を自動で選びます。現在 6 ボタン配置になるゲーム：
      ストリートファイター (sf)、ストリートファイター II' (sf2ce)、ストリートファイター ZERO3 (sfa3)、
      ストリートファイター III 3rd STRIKE (sfiii3)、ストリートファイター EX2 PLUS (sfex2p)、
      ヴァンパイア (dstlk)、ヴァンパイアハンター (nwarr)、ヴァンパイアセイヴァー 2 (vsav2)
    それ以外のアーケードゲーム（KOF やメタルスラッグなどのネオジオを含む）は J K I L 配置です。
    今後追加するストリートファイター、ヴァンパイア、マーヴル（X-MEN など）系も 6 ボタン配置と判定されます。
  - キー配置はゲーム画面の下のメニューバーの「Control Settings」で変更できます。

【「Control Settings」に表示されるボタン】
  ボタン名は各機種の本来のコントローラーの名前で、順番は次のとおりです：
    コイン / セレクト → スタート → 上下左右 → ボタン → 同時押し → ステートセーブや早送りなどの機能キー

  ファミコン          セレクト、スタート、方向、A、B
  スーファミ          セレクト、スタート、方向、A、B、X、Y、L、R
  メガドライブ / CD   MODE、スタート、方向、A、B、C、X、Y、Z
  アーケード ネオジオ コイン、スタート、方向、A、B、C、D
                      同時押し：A+B、C+D、A+B+C、B+C+D
  アーケード 格闘     コイン、スタート、方向、弱・中・強パンチ、弱・中・強キック
                      同時押し：パンチ 3 つ同時、キック 3 つ同時
  アーケード その他   コイン、スタート、方向、ボタン 1～6

  - 同時押しキー：1 つのキーで複数のボタンを同時に押したことになります。ネオジオ本来のボタンは
    A B C D の 4 つだけで、同時押しはエミュレーターの追加機能です。必殺技や回避が出しやすくなります
    （たとえば KOF の A+B 回避、C+D ふっとばし）。
  - アーケードゲームがネオジオか 6 ボタン格闘かは、ROM のファイル名とゲームの正式名から自動で判定します。
  - 設定はゲームごとに保存されます。あるゲームで変えたキー配置やフィルターはそのゲームにだけ適用され、
    次回もそのまま使われます。ほかのゲームは上の標準配置のままです。
  - セーブ（ステートセーブを含む）はこれらの設定とは別に保存され、互いに影響しません。
  - コントローラーのボタンは上のキーボード設定の影響を受けません。下の【コントローラー】を見てください。

【コントローラー】
Xbox、PS4 / PS5、Switch Pro コントローラーのほか、たいていの USB / Bluetooth コントローラーが使えます。

  1. USB か Bluetooth でコントローラーを PC につなぎます。
  2. ゲームに入ったら、まずコントローラーのボタンをどれか押してください。ブラウザはそれで初めて
     コントローラーを認識します（ブラウザのプライバシー上の決まり）。
  3. 標準では RetroArch と同じ割り当てです（Xbox コントローラーの場合。左がゲームのボタン）：
       ファミコン / スーファミ   B → A（下）   A → B（右）   Y → X（左）   X → Y（上）
       メガドライブ              A → X（左）   B → A（下）   C → B（右）
       ネオジオ                  A → A（下）   B → B（右）   C → X（左）   D → Y（上）
       格闘                      弱パンチ → X（左）  中パンチ → Y（上）  弱キック → A（下）  中キック → B（右）
                                 強パンチ → LB   強キック → RB
     （EmulatorJS 本来の標準ではコントローラーの A と B が逆ですが、このツールは RetroArch に合わせています。）
     割り当てが合わないときは、ゲーム画面の下のメニューバーの「Control Settings」で付け直せます。
     最大 4 人まで、それぞれ別のコントローラーを設定できます。設定はブラウザに保存されます。

  - コントローラーの対応が一番良いのは Chrome か Edge です。
  - アーケードゲームのコインとスタートは、たいていコントローラーの Select / ビュー と Start / メニュー です。
  - リセット：Select + Start + LB + RB を同時押し（PlayStation は Share + Options + L1 + R1）。
    ファミコンの多数入りカートリッジでゲーム選択画面に戻るときに使います。すべての機種で使えます。
  - 左スティックも十字キーと同じく方向に使えます（半分以上倒すと押した扱い、斜めも可）。両方を混ぜて使えます。
  - 連射のオン / オフ：右スティックを押し込みます（R3）。
  - マウスなしでゲームを選ぶ（コントローラー、キーボード、テレビのリモコン）：
      十字キー / 左スティック / 方向キー：カバーやボタンの間を移動。A / Enter：決定（ゲーム開始、ボタンを押す）。
      B / Esc / リモコンの戻る：戻る、開いているパネルを閉じる。LB / RB：前 / 次の機種。Start：ロビーを開く / 閉じる。
  - ゲームメニュー：プレイ中に Select + Start を同時に 0.5 秒押し続けると（テレビのリモコンは戻るキー）、
    再開・ステートセーブ・ステートロード・リセット・全画面・終了ができます。一人で遊んでいるときはメニュー中は
    一時停止します。オンラインでは止まらず、乱入した人にはセーブ・ロード・リセットは出ません。

【連射】
  1. ゲーム中に上の「連射設定」を押し、このゲームで連射したいボタンにチェックを入れます。
     たとえばシューティング：ショットにチェックを入れ、溜め撃ちのボタンには入れません。
     こうするとショットは押しっぱなしで連射、溜めボタンは普通に溜められます。
  2. 連射をオンにする：「連射設定」で「連射をオン」を押すか、ゲーム中にキーボードの T / 右スティック（R3）。
     オンのときは画面左上に「連射 ON」と出て、ボタンも「連射設定・オン」に変わります。
  3. 「このゲームの開始時に連射を自動でオン」にチェックすると、次回からはそのゲームで最初からオンになります。

  - 設定はゲームごとに保存されるので、各ゲームで 1 回設定すれば OK です。標準ではすべてのボタンに
    チェックが入っていて、自動でオンにはなりません。
  - 連射の速さは 1 秒に約 15 回です。方向、スタート、コインは対象外です。
  - すべての機種で、キーボードでもコントローラーでも使えます。
  - 「連射設定」を閉じたあとキーが効かないときは、ゲーム画面を一度クリックしてください。


6. アーケードの設定：サービスメニュー、難易度、残機、ネオジオのモード
--------------------------------------------------------------------
以下はゲーム画面の下のメニューバーの「Settings（設定、歯車アイコン）」→「Backend Core Options（コアオプション）」にあります。
変更後はメニューバーの「Restart（リスタート）」で反映されます。設定はゲームごとに保存されます。

【サービスメニュー（テストモード）に入る】
  ゲーム中にスタート（Enter）を約 2 秒押し続けると、アーケード基板本来のサービスメニューに入り、
  難易度、残機、時間、コンティニューの可否などを変えられます（項目はゲームによって違います）。
  入り方はコアオプションの「diagnostic input」で変えられます（たとえばセレクト長押しに）。

【難易度・残機（DIP スイッチ）】
  多くのアーケードゲームは、難易度や残機を基板の DIP スイッチで設定します。
  コアオプションで「Dipswitch」が付いた項目を探してください。たとえば：
    Difficulty（難易度）  Lives（残機）  Bonus Life（エクステンド）
  スイッチはゲームごとに違い、ないゲームもあります。

【多人数モード（3 人・4 人）】
  - キャプテンコマンドー：基板は工場出荷時 2 人モードですが、このツールでは 4 人モードを既定にしています
    （コアオプションの「Dipswitch Play Mode」で戻せます）。
  - ナイツ・オブ・ザ・ラウンド、ザ・キング・オブ・ドラゴンズ、戦場の狼 II：出荷時から 3 人モードなので変更不要です。
  - 天地を喰らう II、キャディラックス 恐竜新世紀など Q サウンドの CPS1 ゲーム：人数はディップスイッチではなく
    ゲームのサービスメニューの設定です。3 人目が参加できないときは、サービスメニュー（スタートを約 2 秒長押し）の
    CONFIGURATION を確認してください。
  - 通信プレイでは、同じゲームのこれらの設定が全員同じである必要があります（違うと「画面がずれた」と表示されます）。
    なるべく全員最新版を使ってください。

【ネオジオ アーケード / 家庭用モード】
  このツールは標準でネオジオのゲーム（KOF、メタルスラッグ、サムライスピリッツなど）を
  「アーケードモード」（MVS 欧州・アジア版）で動かします：
    - ゲームセンターと同じく、V でコインを入れて Enter でスタート
    - 1 人で遊んでいる間でも、もう 1 人がいつでもコインを入れてスタートを押せば参加できます（オンライン乱入も同じ）
    - 難易度や残機はサービスメニューで設定します（上の「サービスメニューに入る」）
  家庭用モードにするには、コアオプションで「mode」（Neo-Geo mode）を探します：
    MVS_EUR / MVS_USA / MVS_JAP  アーケード版（欧州・アジア / 北米 / 日本）、コインが必要   ← 標準は MVS_EUR
    AES_EUR / AES_JAP            家庭用版（欧州英語 / 日本語）、コイン不要。タイトル画面の Option で難易度と残機を設定
    DIPSWITCH                    ゲーム本来の標準（たいていアーケード版）
    UNIBIOS                      有志による拡張 BIOS（チートや地域の切り替えなど）
  ゲームごとに記憶されます。あるゲームを家庭用モードにすると、次回もそのゲームは家庭用モードです。
  オンラインで遊ぶときは、そのゲームのモードを全員そろえてください。違うと「画面のずれ」が出ます。
  注意：neogeo.zip に対応する BIOS が入っている必要があります（FBNeo 用の完全な neogeo.zip ならたいてい入っています）。
  ない場合は、そのゲームの標準のモードに戻ります。


7. フィルター（画面効果）
------------------------
ゲーム中に画面下のメニューバーの「Settings」→「Graphics Settings」→「Shaders」を開き、
1 つ選ぶとすぐに効果が分かります：

  CRT easymode       昔のブラウン管テレビ風、走査線あり、柔らかい見た目。まずはこれがおすすめ
  CRT geom           ブラウン管の丸みと四隅の暗さまで再現。昔のテレビに一番近い
  CRT aperture       アパーチャーグリルを再現、くっきりした画面
  CRT mattias        テレビ信号の軽いにじみと色ずれを再現
  2xScaleHQ          ドットの縁を丸めて滑らかに
  4xScaleHQ          同上、より強く滑らかに
  Disabled           フィルターなし、元のドットのまま

  - フィルターはゲームごとに保存されます。あるゲームで選べば次回もそのフィルターで、
    ほかのゲームは個別に設定します。
  - CRT 系は全画面で一番きれいに見えます。ウィンドウが小さいと走査線が細かすぎて見えます。
  - 古い PC では CRT geom が重いことがあります。CRT easymode なら軽快です。


8. みんなで遊ぶ
---------------
【LAN 対戦（同じ Wi-Fi / ルーターにある PC）】
アドレスを送り合う必要はありません。それぞれが EmulatorJS.command（Mac）か
EmulatorJS-Windows.bat（Windows）をダブルクリックすれば、同じ LAN にいるかぎり、
左の「🕹 プレイ中」に、ほかの PC で誰が何を遊んでいるかが自動で並びます。「乱入」を押せば参加できます。

  · LAN 対戦は最初からオンです。見られたくない場合は「⚙ フォルダ設定」で「LAN 対戦」のチェックを外します。
  · Mac：初回に「Python が受信ネットワーク接続を受け入れることを許可しますか」と出たら「許可」。
  · Windows：初回に「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」（1 回だけ）。
    そこで「いいえ」を選んだ場合は、あとでフォルダ内の「Enable-LAN-Windows.bat」をダブルクリックしてから、
    EmulatorJS を開き直してください。
  · 「乱入」しても、遊ぶのは自分のページで、自分の PC にある同じゲームファイルを使います。
    自分のほうにそのゲームがない（またはファイルが違う）ときは、相手の画面を見ながら遊ぶ方式に自動で切り替わります。
  · 「別の PC」と書かれているものは別の PC で始めたゲームで、書かれていないものはこの PC のライブラリから始めたゲームです。
  · 家庭用ゲーム機のゲームも同じで、一覧に同じゲームがあれば「乱入」で一緒に遊べます。
  · 「名前：…」を押すと名前を変えられます。ほかの人の一覧にはこの名前が表示されます。
    悪口や侮辱などの不適切な言葉は使えません。プレイ中の人と同じ名前も使えません（大文字・小文字・空白・記号は区別しません）。
    不適切な言葉を含む名前は、自動で「プレイヤー」＋番号に変わります。
    禁止語は data/badwords.json にあり、テキストエディタで追加・削除できます（1 語 1 項目）。
    インターネット対戦サーバーでは /opt/emulatorjs-cloud/data/badwords.json で、変更はすぐ反映され再起動は不要です。

EmulatorJS を入れていない機器（タブレットや他の人の PC）：
  ブラウザのアドレス欄に、EmulatorJS を開いている PC のアドレス（左に表示されます。例：http://192.168.1.23:8765）を
  入力すると、その PC のゲームをすべて見て乱入できます。ROM は不要です。これらの機器からは、その PC の
  フォルダ設定は見られず、変更もできません。
  注意：この方法で開いたページでは、ブラウザがマイクを許可しないため、ボイスチャットで話すことはできません（聞くことはできます）。

つながり方（自動で選ばれます。設定は不要）：
  · 入力同期（実験的機能、優先して使われます）：乱入する人の PC でも同じゲームを動かし、ネットでは
    毎フレーム押したボタンだけを送ります。RetroArch のネットプレイと同じ仕組みです。画面は各 PC で
    描くのでくっきりしていて、通信量もほとんどかかりません。「別の PC」に乱入するときは自分の PC にある
    同じゲームファイルを使います。LAN のアドレスでブラウザから開いた場合は、ゲームファイルをホストの PC から
    自動で読み込むので、自分で ROM を持っていなくても大丈夫です。
    ボタンがネット越しに届くのを待つため、全員のボタンは数フレーム遅れて反映されます
    （LAN では 2～3 フレームほどで、ほとんど気になりません）。
    2 秒ごとにゲームの状態を照合し、ずれたらホストがステートセーブを全員に送って合わせ直します。
    そのとき画面が一瞬ちらついたり飛んだりしますが、正常です。
  · 映像配信：ホストの PC が映像と音声をリアルタイムで送り、乱入した人のボタンを送り返します。
    乱入する人が同じゲームファイルを持っていないときに自動で使われます。
  ホストが 1P、乱入した人が順に 2P、3P、4P で、最大 4 人です（ゲームが対応している場合）。
  一緒に遊べる人数は機種によります：ファミコン、PS1、ネオジオなどは 2 人、スーファミ、メガドライブ、N64、その他のアーケード、
  PC エンジンは 4 人、携帯機（GB / GBA / NDS / PSP など）は 1 人。満員でも観戦はできます。「プレイ中」の
  「2/2 人 · 👀 1」は、いまのプレイヤー 2 人 / 最大 2 人、ほかに 1 人が観戦中という意味です。
  乱入した人は自分のキーボードやコントローラーを、1 人プレイと同じ配置で使えます。
  LAN では遅延はとても少ないですが、Wi-Fi の電波が弱いとカクつきます。ホストの PC は有線がおすすめです。

入力同期のときの注意：
  · ホストが右 Shift で一時停止すると全員が止まります。乱入した人は一時停止できません。
  · リセット（Select+Start+L1+R1）とロードができるのはホストだけです。ホストがロードやリセットをすると、
    全員に自動で同期されます。
  · 各プレイヤーの名前の横に、ホストまでの遅延が表示されます（緑＝速い、黄＝ふつう、赤＝遅い。サーバー経由なら「中継」）。
    ホストも乱入した人も見られます。ずっと赤い人がいて全員が重くなるときは、ホストが「👥 ルーム」で退室させられます。
  · 上部の 📶 は接続状況です：直接か中継か、往復の時間（ミリ秒）、ボタンの遅延フレーム数（自動調整）。
    数字がずっと大きいときは、有線 LAN にするか、大きなダウンロードを止めてください。全員が最新版を使ってください。
  · 全員がゲームのページを開いたままにしてください。誰か 1 人でも別のウィンドウに切り替えたり最小化したりすると、
    全員が止まります。
  · 誰かの通信が重くなると全員が遅くなり、画面上に「X の通信を待っています…」と出ます。
  · 「画面のずれ」が何度も出る場合は、たいていそのゲームの設定（コアオプション。ネオジオの家庭用 / アーケードの
    モードや難易度など）が違います。同じにしてください。
  · ファミコンとメガドライブでテスト済みです。ほかの機種も理論上は動きますが、すべては確認していません。
    問題があっても自動で合わせ直します。

2 つの通信方式：ディレイ / ロールバック（入力同期のときだけ。ホストが決めます）
  「⚙ フォルダ設定」→「通信方式」で選びます。プレイ中は「👥 ルーム」でも切り替えられます。
  · ディレイモード（標準・安定）：上で説明した方式です。全員のボタン入力が数フレーム遅れて反映され、
    画面は常に一致し、回線が悪くても巻き戻りません。
  · ロールバックモード（反応が速い・実験的）：自分の入力はほぼすぐ反映されます（2 フレームだけ遅らせます）。
    相手の入力がまだ届いていない間は「前と同じボタンを押し続けている」とみなして進め、本当の入力が届いて
    予想が外れていたら、数フレーム前のステートセーブを読み込み、正しい入力で一瞬でやり直します。
    そのため、ときどき相手のキャラが正しい位置に「パッ」と移ることがあります。
    オンライン対戦の格闘ゲームの多くはこの方式です。
    · ネットワークの往復が 100 ミリ秒以内のときに向いています。それより遅いと相手の動きがよく飛ぶので、
      ディレイモードに戻してください。
    · 毎フレーム余分にステートセーブするので、十分速いパソコンが必要です。追いつかない PC があると、
      その対戦は自動でディレイモードに戻り、お知らせします。
    · 全員が新しいバージョンである必要があります。古いバージョンの人がいると、その対戦はディレイモードです。
    · ロールバックモードで画面がずれ続けるゲーム（1 分間に 3 回）も、その対戦は自動でディレイモードに戻ります。
    · ロールバックモードでは一時停止できません。上の 📶 に「ロールバック」と表示されます。
      やり直しのとき、まれに音が少し乱れることがあります。

スマホと PC で一緒に遊ぶ（遅い機器）：
  入力同期では全員が 1 フレームずつそろって進むため、速さは一番遅い機器に合わせられます。
  スマホでアーケードゲーム（ネオジオなど）を動かすと PC より遅いので、自動で次のようにします：
  · スマホが PC のゲームに乱入：スマホは自動で「画面を見ながら遊ぶ」方式になります。ゲームは PC で動くので、
    速さは PC と同じです。画面に十字キーとボタンが出ます。
  · PC がスマホのゲームに乱入：まず画面を合わせ、そのあとゲームを PC に引き継ぎ、スマホは画面を見ながら
    続けて遊びます。途中で 1～2 秒止まります。プレイヤー番号は変わりません（スマホは 1P のまま、PC は 2P のまま）。
  · スマホやタブレットでのアーケード、PS、N64 などのゲームは常に「遅い」として扱います。ほかのゲームは
    実際に測った速さで判断します。とても古くて遅い PC でも同じです。
  · スマホでアーケードゲームを 1 人で遊ぶときは、自動フレームスキップと音声サンプリングレートの低下を標準でオンにして、
    速く動くようにしています（たまに 1 フレーム描かないことがありますが、ゲームの速さは変わりません）。

乱入されたくないとき：
  ゲーム中、画面の上に「乱入：可」ボタンがあります。押すと「乱入：不可」になり、ほかの人は入れなくなります。
  一覧には「乱入不可」と表示されます（すでに入っている人には影響しません）。
  標準のオン / オフは、最後に選んだほうになります。
  ほかの人があなたのゲームを押すと「乱入不可」と表示され、一人で遊ぶこともできます。

ルームの管理（👥 ルーム）：
  ゲーム中に上の「👥 ルーム」を押すと、ルームのプレイヤーと観戦者が見られます：
  · 観戦を許可：オン / オフ。観戦は 1 ゲーム最大 8 人、そのうち映像で観戦できるのは最大 2 人です
    （映像観戦はあなたの PC が 1 人ずつ映像を圧縮して送るので、多いとゲームが重くなります）。
  · 登録プレイヤー限定：オンにすると、ログインしていない人は乱入も観戦もできません
    （LAN でも同じ。インターネット対戦サーバーの設定が必要です）。
  · 退出させる：2 回押します（2 回目が確認）。退出させた人は 30 分間あなたのルームに入れません。
    アカウント・端末の番号・ネットワークアドレスで判別します（同じネットワークのほかの人も 30 分間入れないことがあります）。
  · ♡：ほかのプレイヤーにいいねを送ります（相手にアカウントが必要です）。

注意：
  · ホストの PC はゲームのページを開いたままにしてください。別のウィンドウや最小化で画面が止まることがあります。
  · ホストがゲームを終了するとそのゲームは終わり、乱入していた人にお知らせが出ます。
  · セーブはホストの PC に保存されます。連射は、入力同期では自分の PC の設定、映像配信ではホストの PC の設定が使われます。
  · LAN 対戦は同じ LAN の中だけで使えます。遠くの友だちとは下の方法で。

【ボイスチャット】
  一緒に遊んでいるとき、画面の上に「🎤 ボイス：オフ」ボタンがあります。押してオンにすると、
  一緒に遊んでいる人と話せます（全員の声が全員に聞こえます）。
  · 初回はブラウザがマイクの使用を確認するので「許可」を選んでください。一度オンにすれば、次の対戦から自動でオンになります。
  · オフにしても、相手に自分の声が届かなくなるだけで、相手の声は聞こえます。
  · 誰かが話していると、上のその人の名前の周りが光ります。
  · イヤホンを強くおすすめします。ないと、マイクがゲームの音やほかの人の声を拾って送り返し、エコーになります。
  · マイクが使えるのは、自分の PC で EmulatorJS を開いたとき（アドレスが 127.0.0.1）だけです。
    タブレットなどで LAN のアドレスから直接開いたページでは、ブラウザがマイクを許可しません。

【遠くの友だちと遊ぶ（インターネット対戦サーバー）】
別のネットワークにいる友だちと遊ぶには、みんながアクセスできる「対戦サーバー」（クラウドサーバーなど）が必要です。
使い方は LAN と同じで、「プレイ中」に遠くの友だちのゲームが（「インターネット」と表示されて）並び、「乱入」で参加できます。ボイスチャットも使えます。

各 PC の設定（1 回だけ）：
  「⚙ フォルダ設定」→「インターネット対戦サーバー」に、サーバーのアドレス（例：http://1.2.3.4:8765）と
  ルームパスワードを入れて「保存してテスト」を押し、「接続中」と出れば完了です。
  この設定は EmulatorJS フォルダの config.json に保存されます。設定してからフォルダごと友だちに渡せば、
  友だちは入力しなくて済みます。
  注意：config.json にはルームパスワードが入っているので、このフォルダを受け取った人は誰でもあなたのサーバーに入れます。
  信頼できる人にだけ渡してください。すぐにはつながせたくない場合は、config.json を消してから渡し、
  サーバーのアドレスとルームパスワードは相手に自分で入れてもらいます。

サーバーは複数保存できます：別のアドレスとルームパスワードを入れて「追加して切り替え」を押します。
1 台のサーバーが 1 つのロビーで、左の「プレイ中」の下の「🌐 ロビー：…」で切り替えます。各ロビーには
サーバーのある国・地域の国旗、ルーム数、オンライン人数が表示されます。アカウント・フレンド・戦績は
サーバーごとに別なので、別のロビーではそこで登録またはログインしてください。

注意：
  · インターネットのゲームには、ホストのネットワークがある国・地域の国旗が表示されます（IP からの
    大まかな判定）。遅延の目安にしてください。
  · ゲームを持っていない人は「乱入」のときにホストへダウンロードを頼めます。ホストには「許可 / 許可しない /
    今後いつも許可」が表示され、許可されるとゲーム・プレビュー画像 3 枚・足りない BIOS がホストの PC から直接（サーバーを通らずに）届き、
    自分の ROM フォルダーの同じ機種フォルダーに保存されて、そのまま乱入します。
  · つながらない・切れたとき：乱入して 20 秒つながらなければ自動で抜けて知らせます。プレイ中に 15 秒
    切れたままなら乱入した人は自動で抜け、ホストはそのまま遊び続けます。どちらかが VPN を使っていると、
    つながらなかったり遅延が大きくなったりしがちです。
  · インターネット越しの乱入でも自分の PC にある同じゲームファイルを使う（入力同期）ため、全員の ROM が
    同じである必要があります（同じ EmulatorJS のパッケージを使えば問題ありません）。そのゲームがない人は
    映像を見る方式になり、サーバーの通信量が多くなります。
  · 離れているほど、ボタンが遅れて反映されるフレーム数が増えます（通信速度を測って自動で調整します）。
    格闘ゲームでは少しもっさり感じることがあります。
  · パスワードを知っている人はサーバー上のすべてのゲームを見られます。入られたくないときは乱入をオフにしてください。

対戦サーバーの作り方（1 回だけ。クラウドサーバーを持っている人がやります）：
  Ubuntu 22.04 / 24.04 のクラウドサーバーが必要です（一番安い小さなプランで十分）。
  1. クラウドのコンソールの「ファイアウォール」で TCP 8765、TCP 80、TCP 3478、UDP 3478、UDP 49160-49250 を開けます。
     （TCP 80 は無料の https 証明書の取得に使い、パスワードなどを暗号化して送れるようにします。証明書は 3 日ごとに自動更新されます）
  2. コンソールの「ログイン」から Web ターミナルを開き、フォルダ内の「cloud-server/ejs-cloud-setup.sh」をサーバーにアップロードします。
  3. ターミナルで実行：sudo bash ejs-cloud-setup.sh
     パスワードを自分で決める場合：sudo bash ejs-cloud-setup.sh パスワード（英字と数字のみ）
     ドメインがある場合（先に DNS の A レコードでサーバーの IP を指定）：sudo bash ejs-cloud-setup.sh ドメイン名
     例：sudo bash ejs-cloud-setup.sh example.site。以後のアドレスは https://ドメイン名:8765 になります。
     元の IP アドレスもそのまま使え、各パソコンは接続すると自動でドメインのアドレスに切り替わります
     （サーバーの IP が変わっても、ドメインの A レコードを変えるだけで済みます）。
  4. 終わるとサーバーのアドレス（https:// で始まる）とルームパスワードが表示されるので、上の設定に入力します。
     以前入力した http のアドレスは変えなくて大丈夫です。EmulatorJS が自動で https に切り替え、設定画面に「🔒 暗号化接続」と表示されます。
  サーバーは再起動後も自動で動きます。
  サーバーの更新：EmulatorJS を更新したら、新しい「cloud-server/ejs-cloud-setup.sh」をもう一度アップロードして（上書き）、
  sudo bash ejs-cloud-setup.sh を実行するだけです。パスワードは変わりません。遊んでいる人は一度切れるので、乱入し直してください。
  （注意：サーバー上の禁止語ファイルは新しいもので上書きされます。サーバーで追加した言葉は追加し直してください。）
  アカウント管理：サーバーのターミナルで sudo ejs-admin を実行し、英語のメニューから番号を選びます：
    ユーザーの一覧 / 検索、パスワードの再設定、名前の変更、利用停止 / 解除、アカウント削除、対戦結果の一覧 / 削除。
    メニュー 10「Server limits」でサーバーの上限（同時接続人数、ルーム数、中継の速度）を設定できます。
    メニュー 11「Developer (admin) account」で管理者専用アカウント「开发者」または「Developer」を作れます。
    この語を含む名前はプレイヤーが登録も成りすましもできません。このアカウントでログインすると、ロビー・
    ルーム・ランキングで名前がカラー + 🛠 で目立つように表示されます。
  （利用停止するとログインできず、ログイン中でもすぐにログアウトされます。アカウント削除はフレンドと対戦結果も
    一緒に消え、元に戻せません。）

【ロビー】
  左の「プレイ中」の横の「⤢ ロビー」（スマホでは右上の 🕹）を押すと、全画面のロビーが開きます：
  · 「プレイ中」：LAN とインターネットで遊ばれているすべてのゲーム。ゲーム名やプレイヤー名で検索でき、
    「乱入できる / 挑戦受付 / 格闘 / フレンド / LAN / インターネット」で絞り込めます。どのゲームにも
    「乱入」か「👀 観戦」ができます（観戦する人は見るだけで操作はできません）。
  ·「🌐 オンラインのプレイヤー」：インターネット対戦サーバーにいま接続している全員（EmulatorJS を開いてこのサーバーを
    設定している人）。国旗・名前・登録プレイヤーかどうか、何をプレイ中か（ロビーにいるか）が出て、そのまま「乱入」や
    「👀 観戦」もできます。「🌐 ロビー」ボタンの横には「オンライン 37/200 人」（いまの人数 / サーバーの上限）が出ます。
    古いサーバーでは表示されません。サーバー管理者がセットアップスクリプトをもう一度実行すると更新されます。
  · 「フレンド」「ランキング」「自分の戦績」：先にアカウントでログインしてください（下を参照）。

【アカウント・フレンド・戦績】（インターネット対戦サーバーが必要）
  登録しなくても遊べますし対戦もできます。アカウントを作ると戦績とフレンドが使えます。
  · 新規登録：ロビー右上の「新規登録」を押し、名前（2～16 文字、不適切な言葉は不可）とパスワード（6 文字以上）を
    入れて地域を選びます。アカウントはインターネット対戦サーバーに保存されるので、別の PC でもログインできます。
    ログイン中は、対戦でアカウントの名前と地域（国旗で表示）が使われます。
  · フレンド：「フレンド」で相手のアカウント名を入れて申請し、相手が承認するとフレンドになります。
    フレンドがオンラインか、何を遊んでいるかが見え、フレンドのゲームにワンクリックで乱入・観戦できます。
  · 戦績：遊んだゲーム、プレイ時間、対戦回数、一緒に遊んだ人を自動で記録します。
  · 勝敗：対戦が終わったら画面上の「🏆 勝敗を記録」で勝者を選びます。ほかの人に確認のお知らせが届き、
    全員が「はい、確認」を押して初めて記録されます。誰かが「違います」を押すと、その記録は取り消されます。
  · チャンピオン：1 つのゲームで 10 勝以上・勝率 60% 以上になると、そのゲームのチャンピオンです。
    ロビーで名前が金色になり 👑 が付きます。
  · いいね：ロビー、フレンド一覧、プレイヤーの戦績、ゲーム中の「👥 ルーム」で ♡ を押すといいねを送れます。
    もう一度押すと取り消せます。ランキングの「♥ 人気ランキング」はもらったいいねの数で並びます。
  · 挑戦受付：格闘ゲームでは、ホストが画面上の「🥊 挑戦受付」を押せます。ロビーの一番上に「挑戦者募集中」と
    表示され、誰でも挑戦しに来られます。
  · スマホやタブレットで LAN のアドレスから開いたページでも、ログインやインターネットのゲームの表示ができます。
    通信はホストの PC が中継します（その PC にインターネット対戦サーバーの設定が必要です）。

【表示言語】
  左上の国旗のボタンで表示言語を切り替えられます：简体中文、繁體中文、English、日本語、한국어、Español、Français、
  Deutsch、Português、Русский。標準はパソコンのシステムの言語と同じです。
  ゲーム名は英語名と、訳名がある場合は選んだ言語の名前も表示します（日本語は一部のゲームのみ）。
  翻訳は data/i18n フォルダにあり（data/names.json はゲームの訳名）、自分で修正できます。

そのほかの方法：
  · Parsec（https://parsec.app）でのリモートプレイ：友だちがあなたの PC に接続して画面を見て、
    友だちのコントローラーがあなたの PC の 2 台目のコントローラーになります。友だちは ROM も EmulatorJS も不要です。
  · お互いに RetroArch を持っていれば、RetroArch 本体のネットプレイも使えます。


9. BIOS
-------
  ファミコン、スーファミ、メガドライブ   不要
  メガCD                               必須：bios_CD_U.bin（北米版）、bios_CD_J.bin（日本版）、bios_CD_E.bin（欧州版）
  アーケード (FBNeo)                   ほとんど不要。ネオジオのゲーム（KOF、メタルスラッグなど）は neogeo.zip、
                                       PGM のゲームは pgm.zip が必要

  BIOS がないと、メガCD のゲームを押したときに「BIOS がないため起動できません」と表示されます。
  BIOS フォルダを設定すると、左上に「BIOS あり：セガ メガCD (U/J)」のように表示されます。
  アルファベットはどの地域の BIOS があるかを表します。


10. よくある質問
----------------
  ゲームを押しても真っ黒のまま
    → 起動ファイルから開いているか確認してください（アドレス欄が http://127.0.0.1 か http://localhost）。
      index.html を直接ダブルクリックした場合（アドレス欄が file://）は動きません。

  EmulatorJS.command をダブルクリックしても何も起きない（Mac）
    → コピーの途中で「実行可能」の権限が消えた可能性があります。「ターミナル」を開いて
         chmod +x
      と入力し（最後にスペースがあります）、EmulatorJS.command をターミナルのウィンドウにドラッグして
      Enter を押してから、もう一度ダブルクリックしてください。

  Mac で EmulatorJS.command にコントローラーのアイコンが付かない
    → 一度ダブルクリックで起動すれば自動で付きます。変わらない場合は Finder のウィンドウを開き直してください
      （Finder はすぐに更新されないことがあります）。アイコンのファイルは data/icon.png なので消さないでください。

  Windows で「EmulatorJS」ショートカットが作られない
    → まず EmulatorJS-Windows.bat を一度ダブルクリックしてください。同じフォルダにショートカットが作られます。
      data フォルダに icon.ico があること、start-windows.ps1 が .bat と同じ場所にあることを確認してください。

  一部のゲームが起動しない
    → BIOS が必要なゲームがあります（第 9 章）。また、もともと別のエミュレーター用のアーケードゲームは
      Web 版の FBNeo では動かないので、RetroArch で遊んでください。

  設定・アカウント・セーブはどこに保存されますか？
    → アカウント（名前・フレンド・戦績）：インターネット対戦サーバーに保存。別の PC やスマホからもログインできます。
      パスワードは暗号化した形でしか保存しません。
      設定（フォルダ、インターネット対戦サーバーのアドレスとルームパスワード）：各機器の config.json に保存——
        フォルダ版（.command / .bat）：EmulatorJS フォルダの config.json
        Windows デスクトップ版：%APPDATA%\EmulatorJS\config.json
        Mac デスクトップ版：~/Library/Application Support/EmulatorJS/config.json
        Android アプリ：アプリ専用のデータ内（アンインストールやデータ消去で一緒に消えます）
      ログイン状態・プレイヤー名・表示言語・配色・背景画像・最近遊んだゲーム・セーブとステートセーブ：ブラウザに保存
      （デスクトップ版と Android アプリはアプリ専用のデータ内）。機器ごとに別々で、サーバーには送られません。
      ブラウザを変えたり、閲覧データを消したり、アプリを削除すると消えます。セーブはゲーム画面下のメニューバーの
      「Export Save File」でバックアップしてください。
