EmulatorJS 使用说明
================================

EmulatorJS 是一个在浏览器里玩老游戏的工具，不需要安装 RetroArch，也不需要联网。
支持 FC/NES、超任 SNES、Game Boy / GBA、N64、NDS、世嘉 MD / Mega-CD / 32X / Saturn、PS1、PSP、
PC Engine、街机 (FBNeo / MAME 2003) 等二十多个平台。


一、文件夹里有什么
------------------
  index.html              游戏页面（不要直接双击打开它）
  data/                   模拟器和模拟核心，不要改动
  EmulatorJS.command      Mac 启动文件
  EmulatorJS-Windows.bat  Windows 启动文件
  start-windows.ps1       Windows 启动文件要用到的脚本，和 .bat 放在一起
  Enable-LAN-Windows.bat  Windows 联机许可（第一次运行会自动弹出，选了「否」时再手动双击它）
  cloud-server/           搭建外网联机服务器用的安装脚本（只在云服务器上用，见第八节）
  server.py               Mac 启动文件要用到的本地服务器程序
  config.json             第一次保存文件夹设置后自动生成，记录你选的文件夹
  EmulatorJS.lnk          Windows 第一次运行后自动生成的快捷方式（带游戏手柄图标）
  LICENSE                 EmulatorJS 的开源许可证（GPL-3.0）
  README_CN.txt 等        这份说明，每种语言一份：CN 简体中文、HK 繁體中文、US English、JP 日本語、
                          KR 한국어、ES Español、FR Français、DE Deutsch、BR Português、RU Русский


二、怎么打开
------------
【桌面版程序（推荐）】
  不想用浏览器、也不想一直开着终端窗口，可以用桌面版：双击图标就打开游戏窗口，关掉窗口就退出。
  · Windows：EmulatorJS-Setup-版本号.exe 是安装版（可以自己选安装位置，会建开始菜单和桌面图标）；
    EmulatorJS-版本号-win.zip 是免安装版：解压到任意文件夹，双击里面的 EmulatorJS.exe 就能玩。
    第一次打开如果出现「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
    Windows 问是否允许网络访问时，勾选「专用网络」再点「允许」（局域网联机要用）。
  · Mac：M1 / M2 / M3 / M4 芯片用 …-mac-apple-silicon.dmg，Intel 芯片用 …-mac-intel.dmg。
    打开 dmg，把 EmulatorJS 拖进「应用程序」文件夹。
    第一次打开会提示无法验证开发者：到「系统设置 → 隐私与安全性」，点「仍要打开」。
    之后问能否查找本地网络上的设备、能否使用麦克风时，都选「允许」（局域网联机、语音聊天要用）。
  · 游戏文件夹：自动找「文稿 / EmulatorJS」里的 roms、thumbnails、system，以及 RetroArch 的默认位置；
    也可以在「⚙ 文件夹设置」里选。第一次打开时会自动沿用原来 EmulatorJS 文件夹的设置。
  · 设置保存在程序自己的数据文件夹里。原来的 EmulatorJS.command / EmulatorJS-Windows.bat 也照样能用，
    两种方式可以一起联机。
  · 设置文件 config.json（文件夹设置、外网联机服务器地址和房间密码）在：
    Windows：%APPDATA%\EmulatorJS\config.json（在资源管理器的地址栏输入 %APPDATA%\EmulatorJS 回车就能打开）
    Mac：~/Library/Application Support/EmulatorJS/config.json（访达里按 Shift+Command+G，粘贴这个路径）

【安卓手机 / 平板 / 安卓电视（APK）】
  · 手机、平板、电视、电视盒子用 EmulatorJS-版本号-android.apk；
    电脑上的安卓模拟器（MuMu 等）用 EmulatorJS-版本号-android-x86_64.apk。
    需要 Android 7.0 以上。电视上的「Android System WebView」太旧时会提示更新。
  · 安装：把 apk 传到手机 / 电视上（数据线、U 盘、微信 / QQ 传文件都行），用文件管理器点开它。
    提示「禁止安装未知来源应用」时，按提示允许这个文件管理器安装应用，再点一次 apk。
    电视：把 apk 拷到 U 盘，插到电视上，用电视自带的「文件管理」打开 U 盘里的 apk。
  · 第一次打开会问能否访问照片和文件（存储权限），选「允许」，不然读不到游戏。
    之后会自动建好「手机存储 / EmulatorJS」文件夹，里面有 roms、thumbnails、system 三个文件夹。
  · 放游戏：手机用数据线连电脑（手机上选「传输文件」），把游戏拷进 EmulatorJS / roms，
    放法和电脑上一样（见第三节），封面图放 thumbnails，BIOS 放 system。放好后点「↻ 重新读取」。
    也可以放在别的地方，在「⚙ 文件夹设置」里选；选文件夹时上面有「手机存储」「下载」等快捷按钮。
  · 电视读 U 盘：U 盘根目录下有 EmulatorJS 或 RetroArch 文件夹（里面是 roms 等）时会自动找到；
    也可以在「⚙ 文件夹设置」里点「U 盘 / 存储卡」选文件夹。U 盘换了内容，点「↻ 重新读取」。
    安卓不允许应用往 U 盘里写东西：联机时从别人电脑下载的游戏会存到「EmulatorJS / downloads」，
    和 U 盘里的游戏显示在一起。
  · 操作：
    手机：屏幕上有虚拟按键，也可以连蓝牙 / USB 手柄。
    电视：用遥控器选游戏（方向键移动，确认键 / OK 打开，返回键返回），连上手柄玩。
    游戏里按遥控器或手机的返回键（或者手柄同时按住 Select + Start）打开游戏菜单：
    继续、即时存档、读取存档、重置、全屏、退出游戏。在游戏列表里连按两次返回键退出程序。
  · 联机、大厅、账号和电脑版一样，可以和电脑一起联机（局域网要连同一个 Wi-Fi）。
    语音聊天第一次用时会问能否使用麦克风，选「允许」。
  · 便宜的电视盒子性能有限：FC、超任、GBA、MD 这些都很流畅，N64、PSP、NDS、Saturn 可能会卡。

【Mac】
  1. 双击 EmulatorJS.command。
     第一次打开如果提示「无法打开，因为来自身份不明的开发者」：
     右键点它 → 选「打开」→ 再点「打开」。以后直接双击就行。
  2. 会弹出一个终端窗口，浏览器会自动打开游戏页面。
     如果系统提示安装「命令行开发者工具」，点「安装」，装好后再双击一次。
  3. 玩的时候不要关终端窗口，玩完再关。
  启动文件会自动换成游戏手柄图标。如果图标在传输中丢了，双击运行一次就会恢复。

【Windows】
  1. 双击 EmulatorJS-Windows.bat。
     如果出现蓝色的「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
  2. 会弹出一个黑色命令行窗口，浏览器会自动打开游戏页面。
  3. 玩的时候不要关这个窗口，玩完再关。
  Windows 不能给 .bat 文件设图标，所以第一次运行后，文件夹里会自动生成一个带图标的
  「EmulatorJS」快捷方式，以后双击它就行。快捷方式可以拖到桌面。
  如果把文件夹挪了位置，快捷方式会失效，再双击一次 .bat 就会重新生成。

为什么要开着这个窗口？
  窗口里运行的是一个只有本机能访问的小网页服务器。浏览器出于安全限制，
  不允许直接双击打开的网页读取模拟器文件，所以要通过它来打开。
  关掉窗口，服务器就停了。

【更新到新版本】
  · 程序打开后会自己检查有没有新版本（之后每 6 小时看一次），有的话会弹出提示，列出这次更新了什么；
    左边栏的版本号旁边也会显示「🆕 有新版本」。点版本号随时可以手动检查。正在玩游戏时不会弹出来打扰。
  · Windows 安装版（用 EmulatorJS-Setup-版本号.exe 装的）：点「自动更新」，程序自己下载新的安装包并检查是否完整，
    下载好后点「立即安装」：程序会关闭，装好新版本后自己重新打开（大约半分钟），游戏、设置、存档都会保留。
    下载太慢（预计要 5 分钟以上）或者下载失败时，会提示改用百度网盘下载。
  · Mac、Windows 免安装版、文件夹版、安卓：点「下载新版本」打开下载地址，或者点「去百度网盘下载」（国内推荐），
    下载后按提示替换旧版本（Mac：把新的 EmulatorJS 拖进「应用程序」选「替换」；文件夹版：把新文件复制到原来的文件夹里覆盖）。
  · 下载地址：https://github.com/supwang/emulatorjs-releases/releases
    百度网盘：https://pan.baidu.com/s/13atBCqmTib1rGp_30279mQ?pwd=6akk （提取码 6akk）
  · 不想装某个版本，点「跳过这个版本，不再提醒」。检查更新只是读取下载网站上的版本信息，不会上传任何东西。


三、游戏文件夹（只需设置一次）
------------------------------
打开页面后会自动读取三个文件夹，不用每次选择：

  ROM 文件夹       放游戏的总文件夹（必需）
  预览图文件夹     RetroArch 的 thumbnails 文件夹（可选，用来显示游戏封面）
  BIOS 文件夹      放 BIOS 的文件夹（可选，只有部分平台需要，见第九节）

【自动查找】没设置过的文件夹会按下面的顺序自动查找，找到就直接用：
  1. EmulatorJS 文件夹里（和 EmulatorJS.command、EmulatorJS-Windows.bat 放在一起）的
     roms、thumbnails、system 文件夹（BIOS 文件夹叫 bios 也可以）
  2. RetroArch 的默认位置
     Mac：~/Library/Application Support/RetroArch/ 下的 roms、thumbnails、system
     Windows：%APPDATA%\RetroArch，或 C:/D:/E:/F: 盘的 RetroArch-Win64、RetroArch、
              Games\RetroArch-Win64 等文件夹下的 roms、thumbnails、system
  所以如果你的 RetroArch 用的是默认位置，第一次打开就能直接玩。
  分享给别人时，也可以把 roms、thumbnails、system 三个文件夹直接放进 EmulatorJS 文件夹里，
  对方解压后打开就能玩。

【手动设置】点左上角「⚙ 文件夹设置」：
  1. 点每一项后面的「浏览…」，一层层点进文件夹，再点「选这个文件夹」。
     上方有「个人文件夹」「桌面」「RetroArch」等快捷按钮。也可以直接粘贴文件夹路径。
  2. 点「保存并读取游戏」。设置会保存在 config.json 里，以后打开会自动使用。
  - 「清除」后保存，就会改回自动查找。
  - 之前设置的文件夹找不到了（比如换了电脑），会自动改回自动查找，设置页里会提示。

【自动下载预览图】
  没有封面的游戏，可以从 libretro 社区的封面库（libretro-thumbnails，RetroArch 用的也是它）自动下载
  封面、标题画面和游戏截图，存进你的预览图文件夹（没设置的话，会在 ROM 文件夹旁边建一个 thumbnails 文件夹）。
  · 第一次读取到没有封面的游戏时会问你要不要自动下载；同意后，以后加了新游戏也会自动下载。
  · 也可以在「⚙ 文件夹设置」→「自动下载预览图」里打开 / 关闭，或者点「⬇ 现在下载缺少的预览图」。
  · 按游戏名找对应的图（街机按 FBNeo 的游戏全名），文件名最好保持 No-Intro 这类标准名字，中文名或自己改过的名字可能找不到。
  · 需要能连上 GitHub。下载时左上角会显示进度，可以随时「停止」。这个封面库是社区整理的，图片版权归各游戏公司。

【加了新游戏后】点左上角「↻ 重新读取」，不用重新打开页面。

【新游戏怎么自动归类到平台】
  每个游戏按下面的顺序判断平台，前面的认出来了就不再往下看：
  1. RetroArch 播放列表里记录的平台（本工具自带了一份游戏清单）
  2. 以前手动选过的平台（在「需要手动选平台」里选过一次，以后自动记住）
  3. 文件扩展名：.nes .sfc .smc .md .gen .gba .gb .n64 .nds 等
  4. 读文件内容：
     - 压缩包（.zip）：看里面装的是什么文件，比如里面是 .sfc 就是超任，是 .md 就是世嘉 MD
     - 光盘 / 卡带镜像（.bin .iso .cue）：读文件开头的标记，能认出世嘉 MD、世嘉 CD、
       世嘉土星、PS1 等
  5. 所在文件夹的名字：snes、md、fbneo、「Nintendo - Super Nintendo Entertainment System」等
  6. 压缩包里都不是已知的卡带格式 → 当作街机游戏
  7. 还是认不出来的（比如 .7z、.chd），放进「需要手动选平台」，选一次就会记住
  街机游戏还会对照 FBNeo 官方的游戏清单（8000 多个）：文件名不在清单里的（比如 NAOMI 的 cvs2.zip），
  FBNeo 跑不了，放进「网页版不支持」。
  所以别人就算把各种游戏都放在同一个文件夹里，大部分也能自动归到正确的平台。
  只读取文件开头和目录的一小部分，不会把整个文件读一遍，速度很快；识别结果会记住，
  下次打开不用重新识别。

小提示：
  - ROM 文件夹里最好按平台分子文件夹，比如 snes、md、nes、fbneo，
    或者 RetroArch 常用的「Nintendo - Super Nintendo Entertainment System」这类名字，
    这样能自动识别平台。
  - 如果左上角显示的是「选择 ROM 文件夹」等三个按钮，而不是「⚙ 文件夹设置」，
    说明打开方式不对或用的是旧的启动窗口：关掉所有终端/命令行窗口，
    再双击启动文件重新打开。


四、开始玩
----------
  1. 左边是平台列表，每个平台都有主机图片。Neo Geo 游戏单独列为「Neo Geo」，
     其他街机游戏在「街机 (FBNeo)」里。
     点一个平台，右边会显示这个平台所有游戏的封面。
     最上面的「🕘 最近玩过」列出这台电脑上最近玩的 10 个游戏，点封面就能直接再玩。
     不想保留某个记录：鼠标移到封面上，点右上角的 ✕（手柄选中后按 X，键盘按 Delete）；「清空记录」一次全部删掉。
     鼠标停在某个游戏上，会自动轮播它的预览图：封面 → 标题画面 → 游戏截图，
     封面下方的小圆点表示一共几张、现在是第几张；鼠标移开就停在当前这张。
     （没有的图会跳过，只有一张图的游戏不轮播。）
     封面大小：封面墙右上角可以选「小 / 中 / 大 / 特大」，每个平台分别记住自己的大小。
  2. 点封面就开始游戏。
  3. 点右上角「退出游戏」回到封面墙。
  4. 搜索框可以按名字找游戏。
  5. 左侧栏最下面有「⌨ 快捷键提醒」，列出投币、开始、重置游戏、暂停、连发、存档读档、
     街机后台等功能键的键盘和手柄按法。点标题可以收起 / 展开，会记住你的选择。
  6. 页面配色：点左上角「EmulatorJS」旁边的 🎨，可以在 7 套配色里选
     （童年〔默认：黄昏的游戏厅，带背景图〕、夜色街机〔深色〕、世嘉蓝〔鲜艳蓝〕、Game Boy 绿、超任灰紫〔浅色〕、
       奶油卡带〔浅色〕、糖果粉〔浅色〕），
     背景、文字、按钮会一起换，选好后会记住。
     同一个面板里还能设置「背景图片」：从电脑里选一张图片，显示在右边游戏列表的后面（滚动时不动）。
     可以设一张通用的，也可以给每个机种单独设一张（没单独设置的机种用通用的那张）；
     「调暗」滑块可以让图片暗一点，文字看得更清楚。图片只保存在这台设备的这个浏览器里。
     玩游戏时，画面两边的空白也会显示这张背景图（调暗、模糊），竖版游戏两边就不是一片黑；不喜欢可以在同一个面板里关掉。
  7. 界面语言：点左上角的国旗按钮（见第八节【界面语言】）。

  - 「需要手动选平台」：网页认不出平台的游戏，选一下平台就会归到对应分组。
  - 「网页版不支持」：浏览器版跑不了的游戏（比如世嘉 NAOMI），请用 RetroArch 玩。
    不想看到这个列表：打开它点右上角的「不显示这个列表」，或在「⚙ 文件夹设置」里取消勾选；想看时再勾上。

游戏里的按键、存档、即时存档、全屏等，都在游戏画面下方的菜单栏里。
「控制设置」可以查看和修改键盘按键，也支持手柄。
存档保存在浏览器里，换浏览器或清除浏览器数据后会丢失。
需要备份的话，可以用菜单里的「导出存档文件」。

金手指：菜单栏里的「秘籍」（英文界面叫 Cheats）→「添加作弊」（Add Cheat），填上代码（Code）和说明（Description），
提交后勾选就生效，再点一次取消。代码格式看平台：FC 用 Game Genie，GBA 用 Action Replay / GameShark 等，
网上搜「游戏名 + 金手指」能找到。有些金手指关掉后要重新开始游戏才会完全恢复。
联机时（有别的玩家一起玩）金手指会自动关闭，秘籍按钮也会藏起来；只剩你一个人时自动恢复。

金手指库：在「秘籍」（Cheats）菜单最上面点「📚 从金手指库选（libretro）」，会按游戏名找到这个游戏的金手指
（来自 libretro 社区的数据库 libretro-database，FC、超任、MD、GBA 等家用机比较全，街机基本没有），勾选后点「添加选中的金手指」，
再回到「秘籍」里勾选才会开启。联机时同样不能用。需要能连上 GitHub。


五、键盘和手柄
--------------
【键盘默认键位】（玩家 1）

  方向                W 上   S 下   A 左   D 右
  开始 (Start)        回车
  选择 (Select)/投币  V

  FC / NES            J = A    K = B
  超任 SNES           J = A    K = B    I = X    L = Y    U = L 肩键    O = R 肩键
  世嘉 MD / Mega-CD   下排 J K L = A B C        上排 U I O = X Y Z
  街机 Neo Geo（拳皇、合金弹头、侍魂等）
                      J = A    K = B    I = C    L = D
                      U = A+B 组合   O = C+D 组合   （A+B+C、B+C+D 组合默认没有分配按键）
  街机（其他游戏）    J K I L = 按键 1 2 3 4    U O = 按键 5 6
  街机（街霸类 6 键格斗：街霸系列、恶魔战士、漫画英雄等）
                      轻拳 J   中拳 K   重拳 L
                      轻脚 U   中脚 I   重脚 O
                      （三拳、三脚组合默认没有分配按键）

  暂停 / 继续   右 Shift
  连发 开/关    T
  重置游戏      V + 回车 + U + O 同时按（多合一卡带会回到选游戏画面）
  即时存档 1    读取即时存档 2    切换存档位 3
  （快进、慢放、倒带默认没有分配按键，可以在「控制设置」里自己设）

  - 街机游戏会按 ROM 文件名自动选择布局。目前用「街霸类 6 键」布局的游戏有：
      街霸 1 (sf)、街霸 2 冠军版 (sf2ce)、街霸 Zero 3 (sfa3)、街霸 3 三度冲击 (sfiii3)、
      街霸 EX2 Plus (sfex2p)、恶魔战士 (dstlk)、恶魔战士 2 (nwarr)、吸血鬼救世主 2 (vsav2)
    其余街机游戏（包括拳皇、合金弹头等 Neo Geo 游戏）都用 J K I L 布局。
    以后新加的街霸、恶魔战士、漫画英雄 (X-Men、Marvel) 系列游戏也会自动识别成 6 键布局。
  - 键位可以在游戏画面下方菜单栏的「控制设置」里修改。

【「控制设置」里显示的按键】
  按键名称按各平台原始手柄显示，顺序统一为：
    投币 / 选择 → 开始 → 上下左右 → 按键 → 组合键 → 即时存档、快进等功能键

  FC / NES            选择、开始、方向、A、B
  超任 SNES           选择、开始、方向、A、B、X、Y、L、R
  世嘉 MD / Mega-CD   MODE、开始、方向、A、B、C、X、Y、Z
  街机 Neo Geo        投币、开始、方向、A、B、C、D
                      组合键：A+B、C+D、A+B+C、B+C+D
  街机 街霸类格斗     投币、开始、方向、轻拳、中拳、重拳、轻脚、中脚、重脚
                      组合键：三拳（三个拳同时按）、三脚（三个脚同时按）
  街机 其他游戏       投币、开始、方向、按键 1～6

  - 组合键：按一个键，等于同时按下几个键。Neo Geo 原机只有 A B C D 四个键，
    组合键是模拟器额外提供的，方便放必杀技、闪避（比如拳皇的 A+B 闪避、C+D 吹飞）。
  - 街机游戏是不是 Neo Geo / 街霸类，是按 ROM 文件名和游戏全名自动判断的。
  - 设置是按游戏分别保存的：在某个游戏里改过的键位、滤镜等，只对这个游戏生效，
    下次打开这个游戏会自动沿用；其他游戏仍然使用上面的默认键位。
  - 游戏存档（包括即时存档）和这些设置是分开保存的，互不影响。
  - 手柄的键位不受上面键盘设置影响，见下面的【手柄】。

【手柄】
支持常见手柄：Xbox、PS4 / PS5、Switch Pro，以及大部分 USB / 蓝牙通用手柄。

  1. 先用 USB 或蓝牙把手柄连上电脑。
  2. 进入游戏后，先按一下手柄上的任意键，浏览器才会识别手柄（浏览器的隐私规定）。
  3. 默认按 RetroArch 的习惯对应手柄按键（以 Xbox 手柄为例，左边是游戏里的键）：
       FC / 超任   B → 手柄 A（下）   A → 手柄 B（右）   Y → 手柄 X（左）   X → 手柄 Y（上）
       世嘉 MD     A → 手柄 X（左）   B → 手柄 A（下）   C → 手柄 B（右）
       Neo Geo     A → 手柄 A（下）   B → 手柄 B（右）   C → 手柄 X（左）   D → 手柄 Y（上）
       街霸类      轻拳 → 手柄 X（左）  中拳 → 手柄 Y（上）  轻脚 → 手柄 A（下）  中脚 → 手柄 B（右）
                   重拳 → LB   重脚 → RB
     （EmulatorJS 原本的默认设置把手柄的 A、B 对调了，本工具已改成和 RetroArch 一致。）
     键位不对的话，点游戏画面下方菜单栏的「控制设置」，可以给每个按键重新指定。
     最多支持 4 个玩家，可以分别设置不同的手柄。设置会保存在浏览器里。

  - 推荐用 Chrome 或 Edge，对手柄支持最好。
  - 街机游戏的投币和开始，一般是手柄上的 Select / 视图键 和 Start / 菜单键。
  - 重置游戏：手柄同时按 Select + Start + LB + RB（PS 手柄是 Share + Options + L1 + R1）。
    玩 FC 多合一卡带时，用它回到选游戏的画面。所有平台都可以用。
  - 左摇杆和十字键作用一样，可以控制方向（推过一半就算按下，斜推就是斜方向），
    两个可以混着用。
  - 连发开关：按一下右摇杆（R3，就是把右摇杆按下去）。
  - 不用鼠标也能选游戏（手柄、键盘、电视遥控器都可以）：
      十字键 / 左摇杆 / 方向键：在游戏封面和按钮之间移动；A / 回车：确认（开始游戏、点按钮）；
      B / Esc / 遥控器返回键：返回、关掉打开的面板；LB / RB：换上一个 / 下一个机种；Start：打开或关上大厅。
  - 游戏菜单：玩的时候同时按住 Select + Start 半秒（电视遥控器按返回键），可以继续、即时存档、读档、
    重置、全屏、退出游戏。单人玩时打开菜单会暂停；联机时游戏不会暂停，乱入的人看不到存档、读档和重置。

【连发】
  1. 进游戏后，点画面上方的「连发设置」，勾选这个游戏里哪些键要连发。
     比如射击游戏：勾选射击键，不勾蓄力键。这样按住射击键会连发，按住蓄力键就是正常蓄力。
  2. 打开连发：在「连发设置」里点「开启连发」，或者游戏中按 键盘 T / 手柄右摇杆（R3）。
     打开后画面左上角显示「连发 ON」，「连发设置」按钮也会变成「连发设置 · 开」。
  3. 勾选「进入这个游戏时自动开启连发」，以后进这个游戏就自动开着，不用再按 T / R3。

  - 设置按游戏分别保存，每个游戏设一次就行。默认是全部按键都勾选、进游戏时不自动开启。
  - 连发速度大约每秒 15 次。方向键、开始、投币不受影响。
  - 所有平台都可以用，键盘和手柄都可以。
  - 关掉「连发设置」窗口后，如果按键没反应，用鼠标点一下游戏画面就好。


六、街机设置：后台、难度、命数、Neo Geo 模式
--------------------------------------------
以下设置都在游戏画面下方菜单栏的「设置」（齿轮图标）→「Backend Core Options（核心选项）」里。
改完后点菜单栏的「重新开始」才会生效。设置按游戏分别保存。

【进入街机后台（服务菜单 / Test Mode）】
  游戏里按住「开始」键（回车）约 2 秒，就会进入街机原本的后台菜单，
  可以调难度、命数、时间、是否允许接关等（具体有哪些选项由游戏决定）。
  进入方式可以在核心选项的「diagnostic input」里改，比如改成按住选择键。

【难度、命数（拨码开关）】
  很多街机游戏的难度、命数是用机板上的拨码开关（DIP 开关）设定的。
  在核心选项里找名字带「Dipswitch」的项，比如：
    Difficulty（难度）  Lives（命数）  Bonus Life（奖命）
  每个游戏的开关不一样，有的游戏没有。

【多人模式（3 人、4 人）】
  - 名将（Captain Commando）：机台出厂是 2 人模式，本工具默认改成 4 人模式
    （核心选项里的「Dipswitch Play Mode」，想改回去可以在那里改）。
  - 圆桌骑士、龙王战士、战场之狼 2：出厂就是 3 人模式，不用改。
  - 吞食天地 2、恐龙快打这类 Q-Sound 的 CPS1 游戏：人数不是拨码开关，而是游戏后台里的设置，
    第 3 个人加入不了的话，进街机后台（按住开始键约 2 秒）的 CONFIGURATION 里看看。
  - 联机时，大家同一个游戏的这些设置要一样，否则会提示“画面对不上”，所以最好都用最新版本。

【Neo Geo 街机 / 家用机模式】
  本工具默认让 Neo Geo 游戏（拳皇、合金弹头、侍魂等）以「街机模式」运行（MVS 欧亚版）：
    - 和街机厅一样：按 V 投币，再按回车开始；
    - 一个人在玩时，另一个人随时投币按开始就能加入（联机乱入也一样）；
    - 难度、命数等在街机后台设置里调（见上面的「进入后台」）。
  想换成家用机模式：核心选项里找「mode」（即 Neo-Geo mode），可选：
    MVS_EUR / MVS_USA / MVS_JAP  街机版（欧亚 / 美国 / 日本），需要投币   ← 默认 MVS_EUR
    AES_EUR / AES_JAP            家用机版（欧亚英文 / 日文），不用投币，标题画面 Option 里可调难度和命数
    DIPSWITCH                    按游戏自带的默认（一般是街机版）
    UNIBIOS                      玩家自制增强 BIOS（可开作弊、切地区等）
  按游戏分别记住：某个游戏改成家用机模式后，下次进这个游戏还是家用机模式。
  联机时，双方同一个游戏的模式要一样，否则会提示“画面对不上”。
  注意：需要 neogeo.zip 里有对应的 BIOS 文件（完整的 FBNeo 版 neogeo.zip 一般都有），
  缺少的话会自动退回游戏默认模式。


七、滤镜（画面效果）
--------------------
进游戏后，点画面下方菜单栏的「设置」→「图形设置（Graphics Settings）」→「Shaders」，
选一个就能马上看到效果：

  CRT easymode       模拟老式显像管电视，有扫描线，效果柔和，推荐先试这个
  CRT geom           显像管效果，带屏幕弧度和暗角，最像当年的大屁股电视
  CRT aperture       模拟荫罩网格，画面清晰
  CRT mattias        模拟电视信号的轻微模糊和色彩溢出
  2xScaleHQ          把像素边缘磨圆、变平滑
  4xScaleHQ          同上，平滑效果更强
  Disabled           关闭滤镜，保持原始像素

  - 滤镜是按游戏分别保存的：给某个游戏选好后，下次打开这个游戏还是这个滤镜，
    其他游戏需要分别设置。
  - CRT 类滤镜在全屏下效果最好，窗口太小时扫描线会显得太密。
  - 电脑配置比较老时，CRT geom 可能会卡，换成 CRT easymode 会流畅一些。


八、联机
--------
【局域网联机（同一个 Wi-Fi / 路由器下的电脑）】
不用互相发地址：大家各自双击 EmulatorJS.command（Mac）或 EmulatorJS-Windows.bat（Windows），
只要在同一个局域网里，左侧「🕹 正在游戏」就会自动列出别的电脑上谁在玩什么，点「乱入」就加入。

  · 局域网联机默认是打开的。不想被别人看到，点左下角「⚙ 文件夹设置」，去掉「局域网联机」的勾。
  · Mac：第一次可能弹出“是否允许 Python 接受传入网络连接”，选「允许」。
  · Windows：第一次打开时会弹出“是否允许此应用对你的设备进行更改”，选「是」（只问一次）。
    如果当时选了「否」，以后双击文件夹里的「Enable-LAN-Windows.bat」补一次，再重新打开 EmulatorJS。
  · 点「乱入」后，还是在自己的页面上玩，用的是自己电脑里的同一个游戏文件；
    自己这里没有这个游戏（或文件不一样）时，自动改成看对方的画面玩。
  · 列表里写着「另一台电脑」的，是别的电脑上开的局；没写的，是在你这台电脑的游戏库里开的局。
  · 家用机游戏也一样：看到同一个游戏在列表里，点「乱入」就能一起玩。
  · 点「我是：…」可以改自己的名字，别人在列表里看到的就是这个名字。
    名字不能含有辱骂、侮辱等不文明的词，也不能和正在玩的人重名（不分大小写、空格和符号）。
    含不文明词的名字会被自动改成「玩家」加编号。
    屏蔽词在 data/badwords.json 里，可以用文本编辑器增删（一个词一项）；
    外网联机服务器上的在 /opt/emulatorjs-cloud/data/badwords.json，改完马上生效，不用重启。

没装 EmulatorJS 的设备（平板、别人的电脑）：
  在浏览器地址栏输入开着 EmulatorJS 的那台电脑的地址（左侧栏会显示，例如 http://192.168.1.23:8765 ），
  就能看到那台电脑的全部游戏并乱入，不需要 ROM。这些设备看不到、也改不了那台电脑的文件夹设置。
  注意：这种方式打开的页面，浏览器不允许用麦克风，所以不能语音（只能听别人说话）。

怎么联机的（自动选择，不用设置）：
  · 按键同步（实验功能，默认优先用）：乱入的人自己的电脑上也运行同一个游戏，
    网上只传每一帧按了哪些键，和 RetroArch 的联机原理一样。画面是自己电脑算出来的，清楚不模糊，
    几乎不占网速。从「另一台电脑」乱入时用自己电脑里的同一个游戏文件；
    用浏览器输入局域网地址打开的，游戏文件会自动从开局的电脑读取，不用自己有 ROM。
    为了等按键在网上传过来，所有人的按键会延后几帧生效（局域网里大约 2～3 帧，感觉不太出来）。
    每隔 2 秒会自动核对一次游戏状态；万一对不上，主机会自动把即时存档发给大家重新对齐，
    这时画面会闪一下或跳一下，属于正常现象。
  · 画面串流：开局的电脑把画面和声音实时传给乱入的人，乱入的人按键再传回去。
    乱入的人找不到同一个游戏文件时，自动改用这种方式。
  开局的人是 1P，乱入的依次是 2P、3P、4P，最多 4 人（要游戏本身支持多人）。
  能一起玩的人数看平台：FC、PS1、Neo Geo 等 2 人，超任、MD、N64、其他街机、PC Engine 4 人，
  掌机（GB / GBA / NDS / PSP 等）1 人；人满了还可以观战。「正在游戏」里的「2/2 人 · 👀 1」
  意思是：现在 2 个玩家 / 最多 2 人，另外 1 人在观战。
  乱入的人用自己的键盘或手柄，键位和单人玩时一样。
  局域网里延迟很低，但 Wi-Fi 信号差时会卡，开局的电脑最好用网线。

按键同步时要注意：
  · 主机按右 Shift 暂停，所有人一起暂停；乱入的人不能暂停。
  · 只有主机能重置游戏（Select+Start+L1+R1）和读档；主机读档或重置后，会自动同步给大家。
  · 每个玩家名字旁边显示他到主机的延迟（绿色快、黄色一般、红色慢；经过服务器中转的标「中转」），
    房主和乱入的人都看得到。有人一直是红色、拖慢了大家，房主可以在「👥 房间」里把他请出去。
  · 顶部的 📶 显示连接情况：直连还是中转、网络来回一次多少毫秒、按键延后几帧（会根据网络自动调整）。
    数字一直很大时，可以改用网线，或暂停占网速的下载。联机的各方最好都用最新版本。
  · 所有人的电脑都要停在游戏页面上，有一个人切到别的窗口或最小化，大家都会一起卡住。
  · 某个人网络卡顿时，大家会一起慢下来，画面上方会提示“等待 某某 的网络…”。
  · 如果一直提示“画面对不上”，通常是双方这个游戏的设置（核心选项，比如 Neo Geo 的家用机/街机模式、
    难度）不一样，改成一样即可。
  · 已测试过 FC 和世嘉 MD，其他机种理论上也可以，但没有逐个验证；有问题时会自动重新对齐。

两种联机方式：延迟 / 回滚（按键同步时才有；由开局的人决定）
  在「⚙ 文件夹设置」→「联机方式」里选，玩的时候也可以在「👥 房间」里切换。
  · 延迟模式（默认，稳）：上面说的方式。所有人的按键延后几帧生效，画面永远一致，网络差时也不会回跳。
  · 回滚模式（跟手，实验功能）：自己的按键几乎马上生效（只延后 2 帧）。对方的按键还没传到时，
    先当作他还按着上一次的键接着跑；真正的按键到了、发现猜错了，就读回几帧前的即时存档，
    用正确的按键一瞬间重跑一遍，所以偶尔会看到对方的角色“闪”一下到正确的位置。
    格斗游戏的线上对战大多用这种方式。
    · 适合网络来回 100 毫秒以内；更慢时对方的动作会经常跳一下，可以改回延迟模式。
    · 每一帧都要多存一次即时存档，电脑要够快：哪台电脑跑不动，这局会自动改回延迟模式并提示。
    · 联机的所有人都要是新版本；有人是旧版本时，这局自动用延迟模式。
    · 某个游戏在回滚模式下老是对不上（1 分钟里 3 次），这局也会自动改回延迟模式。
    · 回滚模式下不能暂停；顶部的 📶 显示「回滚」。重跑那几帧时偶尔可能听到一点杂音。

手机和电脑一起玩（速度慢的设备）：
  按键同步时大家必须一帧一帧一起跑，速度跟着最慢的那台走。手机跑街机（Neo Geo 等）比电脑慢，所以会自动这样处理：
  · 手机乱入电脑的游戏：手机自动改成「看画面玩」，游戏在电脑上跑，速度和电脑一样。屏幕上会出现十字键和按键。
  · 电脑乱入手机的游戏：先对齐画面，然后游戏自动交给电脑运行，手机改成看画面接着玩，
    中间会停一两秒。两人的玩家号不变（手机还是 1P，电脑还是 2P）。
  · 手机、平板上的街机、PS、N64 等游戏一律按「慢」处理；其他游戏按实际测到的速度判断，电脑很老很慢时也一样。
  · 手机单独玩街机游戏时，默认打开自动跳帧、降低声音采样率，跑得更快（偶尔少画一帧，游戏速度不变）。

不想让别人乱入：
  玩游戏时，画面上方有「允许乱入：开」按钮，点一下变成「关」，别人就进不来了，
  列表里会显示“不允许乱入”（已经进来的人不受影响）。
  默认开还是关，以你最后一次的选择为准。
  别人点进你正在玩的游戏时，会提示“不允许乱入”，可以选择自己单独玩。

房间管理（👥 房间）：
  玩游戏时点上方的「👥 房间」，可以看到房间里的玩家和观战的人：
  · 允许观战：开 / 关。每局最多 8 人观战，其中看画面观战的最多 2 人
    （看画面观战要你的电脑给每个人单独压缩视频，人多了会拖慢你的游戏）。
  · 只允许注册玩家：开启后，没有登录账号的人不能乱入或观战（局域网里也一样，需要设置好外网联机服务器）。
  · 请出去：点两下（第二下是确认）。被请出去的人 30 分钟内不能再进你的房间，
    按账号、设备编号和网络地址认人（同一个网络里的其他人这 30 分钟内也可能进不来）。
  · ♡：给其他玩家点赞（对方要有账号）。

注意：
  · 开局的电脑要一直停在游戏页面上，切到别的窗口或最小化，画面可能会停住。
  · 开局的人退出游戏，这一局就结束了，乱入的人会收到提示。
  · 存档保存在开局那台电脑上。连发：按键同步时用自己电脑上的设置，画面串流时用开局那台电脑的设置。
  · 只在同一个局域网内有效；外地朋友请看下面的方法。

【语音聊天】
  联机时画面上方有「🎤 语音：关」按钮，点一下变成「开」，就能和一起玩的人说话（所有人都能互相听到）。
  · 第一次打开时，浏览器会问能否使用麦克风，选「允许」。以后会记住：开过语音的话，下次联机自动打开。
  · 关掉语音只是不让别人听到你，你仍然能听到别人。
  · 有人说话时，上方他的名字会亮一圈。
  · 强烈建议戴耳机：不戴的话，麦克风会把游戏声音和别人的声音又传回去，产生回声。
  · 必须是在自己电脑上打开 EmulatorJS（地址是 127.0.0.1）才能用麦克风；
    平板等用局域网地址直接打开的页面，浏览器不允许用麦克风。

【和外地朋友联机（外网联机服务器）】
和不在同一个网络的朋友联机，需要一台大家都能访问的「联机服务器」（比如一台云服务器）。
用法和局域网一样：「正在游戏」里会出现外地朋友开的局（标着「外网」），点「乱入」即可，语音也能用。

每台电脑的设置（只需一次）：
  「⚙ 文件夹设置」→「外网联机服务器」，填服务器地址（例如 http://1.2.3.4:8765 ）和房间密码，
  点「保存并测试」，显示“已连接”就好了。
  这个设置保存在 EmulatorJS 文件夹的 config.json 里：设置好以后再把整个文件夹打包发给朋友，
  朋友那边就不用再填了。
  注意：config.json 里有房间密码，拿到这个文件夹的人都能进你的服务器，只发给信任的人。
  不想让对方直接连上，就先删掉 config.json 再打包，让对方自己填服务器地址和房间密码。

可以保存多个服务器：再填一个地址和房间密码，点「添加并切换到这里」。一个服务器就是一个大厅，
在左边「正在游戏」下面点「🌐 大厅：…」就能切换；每个大厅旁边有服务器所在国家 / 地区的国旗、
房间数和在线人数。每台服务器的账号、好友、战绩是分开的，换到另一个大厅要在那边另外注册或登录。
填的地址连不上、或者房间密码不对时，会直接提示，不会加进列表。要改某个服务器的房间密码，
点它旁边的 🔑，填好新密码，再点「保存密码并切换到这里」。

注意：
  · 外网的局旁边有房主网络所在国家 / 地区的国旗（按 IP 大致判断），可以用来估计延迟。
  · 没有这个游戏的人点「乱入」时，可以向开局的人请求下载：对方会弹窗选「允许 / 不允许 / 以后都允许他」，
    同意后游戏文件、3 张预览图和缺少的 BIOS 直接从对方电脑传过来（不经过服务器），存进自己 ROM 文件夹里同名的平台文件夹，然后自动乱入。
  · 连不上或断线：乱入后 20 秒还连不上会自动退出并提示；玩到一半断线 15 秒，乱入的人自动退出，
    开局的人不再等他、接着玩。有一方开着 VPN 时，经常会连不上或延迟很高。
  · 外网乱入用的是自己电脑里的同一个游戏文件（按键同步），所以大家的 ROM 要一样
    （用同一个 EmulatorJS 包就没问题）。没有这个游戏的人会改成看画面，比较占服务器流量。
  · 两地越远，按键延后的帧数越多（程序会自动测网速调整），格斗类游戏会感觉稍微黏手。
  · 有密码的人都能看到服务器上的所有游戏局；不想被人加入，就关掉「允许乱入」。

搭建联机服务器（只需做一次，由有云服务器的人来做）：
  需要一台 Ubuntu 22.04 / 24.04 的云服务器（最便宜的轻量服务器就够）。
  1. 云服务器控制台 →「防火墙」放行：TCP 8765、TCP 80、TCP 3478、UDP 3478、UDP 49160-49250。
     （TCP 80 用来申请免费的 https 证书，让密码等信息加密传输；证书每 3 天自动续期）
  2. 用控制台的「登录」打开网页终端，把文件夹里「cloud-server/ejs-cloud-setup.sh」上传到服务器。
  3. 在终端里运行：sudo bash ejs-cloud-setup.sh
     想自己定密码：sudo bash ejs-cloud-setup.sh 你的密码（只能用英文字母和数字）
     有域名的话（先在域名解析里把它指向这台服务器的 IP）：sudo bash ejs-cloud-setup.sh 你的域名
     例如 sudo bash ejs-cloud-setup.sh example.site。之后地址就是 https://你的域名:8765，
     原来的 IP 地址照样能用，各台电脑连上后会自动换成域名地址（以后服务器换了 IP，只要改域名解析）。
  4. 运行完会显示服务器地址（https://开头）和房间密码，填到上面的设置里。
     以前填的 http 地址不用改，EmulatorJS 会自动换成 https，设置里显示「🔒 已加密连接」。
  服务器重启后会自动运行。
  更新服务器：EmulatorJS 更新后，把新的「cloud-server/ejs-cloud-setup.sh」再上传一次（覆盖旧的），
  运行 sudo bash ejs-cloud-setup.sh 即可，密码不变，正在玩的人会断开一下，重新乱入就好。
  （注意：这样会用新版的屏蔽词文件覆盖服务器上的，自己在服务器上加过的词要重新加。）
  管理账号：在服务器的终端里运行 sudo ejs-admin，出现英文菜单后按数字选择：
    查看 / 搜索用户、重置密码、改名字、封禁 / 解封、删除账号、查看 / 删除胜负记录。
    菜单 10「Server limits」可以设置服务器上限：最多同时在线人数、最多房间数、网络中转的速度上限。
    菜单 11「Developer (admin) account」建管理员专用账号「开发者」或「Developer」：名字里带这两个词的，
    玩家不能注册、也不能冒用；用这个账号登录后，你的名字在大厅、房间、排行榜里都会彩色 + 🛠 高亮显示。
  （封禁后不能登录，已登录的会马上退出；删除账号会连同好友和胜负记录一起删除，不能恢复。）

【大厅】
  左侧「正在游戏」旁边点「⤢ 大厅」（手机上点右上角的 🕹），打开全屏的大厅：
  · 「正在游戏」：所有局域网、外网正在玩的局，可以搜索游戏名或玩家名，按「可以乱入 / 擂台 / 格斗 /
    好友 / 局域网 / 外网」筛选。每一局都可以「乱入」或「👀 观战」（观战的人只能看，不能操作）。
    每一局都有标签：绿色「局域网」是同一个 Wi-Fi / 路由器里的，蓝色「🌐 外网」是联机服务器上的；
    同一局两边都看得到时，只显示局域网那条（更快、更稳）。
  · 「🌐 在线玩家」：外网联机服务器上现在所有在线的人（打开了程序、连着这个服务器的都算），显示国旗、名字、
    是不是注册玩家，以及在玩什么还是在大厅里；正在玩的可以直接「乱入」或「👀 观战」。左边的「🌐 大厅」按钮上
    会显示「在线 37/200 人」（现在人数 / 服务器的上限）。服务器是旧版本时看不到，请服务器管理员重新运行一次安装脚本更新。
  · 「好友」「排行榜」「我的战绩」：要先登录账号（见下面）。

【账号、好友、战绩】（需要外网联机服务器）
  不注册也能玩、能联机；注册账号后才有战绩和好友。
  · 注册：大厅右上角点「注册」，填名字（2～16 个字，不能有不文明的词）、密码（至少 6 位），选地区。
    账号保存在外网联机服务器上，换电脑登录也能用。登录后联机时就用账号的名字和地区（显示国旗）。
  · 好友：在「好友」里输入对方的账号名字发请求，对方同意后就是好友。
    能看到好友在不在线、在玩什么，好友正在玩的局可以一点就乱入或观战。
  · 战绩：自动记录玩了哪些游戏、玩了多久、联机了几次、和谁一起玩过。
  · 胜负：联机打完一局，画面上方点「🏆 记录胜负」选赢家，其他人会收到确认提示，
    所有人都点「对，确认」才算数；有人点「不对」，这条记录就作废。
  · 擂主：一个游戏赢 10 场以上、胜率 60% 以上，就是这个游戏的擂主，大厅里名字是金色的 👑。
  · 点赞：在大厅、好友列表、玩家资料或游戏里的「👥 房间」里点 ♡ 给别人点赞，再点一下取消。
    排行榜里的「♥ 最受欢迎」按收到的赞排名。
  · 擂台：玩格斗游戏时，开局的人可以点画面上方的「🥊 擂台」，大厅里会把这一局排在最前面，
    写着“欢迎挑战”，谁都可以来挑战。
  · 手机、平板用局域网地址打开的页面，也能登录、看外网的局：请求会经过开局的那台电脑转发
    （那台电脑要设置好外网联机服务器）。

【界面语言】
  左上角国旗按钮可以切换界面语言：简体中文、繁體中文、English、日本語、한국어、Español、Français、
  Deutsch、Português、Русский。默认和电脑系统的语言一样。
  游戏名会同时显示英文名和所选语言的译名（有译名时；街机游戏大多有中文名）。
  翻译在 data/i18n 文件夹里（data/names.json 是游戏译名），可以自己修改。

其他办法：
  · Parsec（https://parsec.app）远程同屏：朋友连进你的电脑，看到你的画面，他的手柄变成你电脑上的
    第二个手柄。朋友那边不需要 ROM，也不用装 EmulatorJS。
  · 如果双方都装了 RetroArch，也可以用 RetroArch 自带的联机功能。


九、BIOS
--------
  FC / NES、超任 SNES、世嘉 MD     不需要
  世嘉 Mega-CD                     必须要：bios_CD_U.bin（美版）、
                                   bios_CD_J.bin（日版）、bios_CD_E.bin（欧版）
  街机 (FBNeo)                     大部分不需要；Neo Geo 游戏（拳皇、合金弹头等）
                                   需要 neogeo.zip，PGM 游戏需要 pgm.zip

  缺少 BIOS 时，点世嘉 CD 游戏会提示「缺少 BIOS」。
  选好 BIOS 文件夹后，左上角会显示「已找到 BIOS：世嘉 Mega-CD（U/J）」这类提示，
  字母表示有哪些地区的 BIOS。


十、常见问题
------------
  点了游戏一直黑屏
    → 确认是双击启动文件打开的（地址栏显示 http://127.0.0.1 或 http://localhost），
      而不是直接双击 index.html（地址栏显示 file://）。

  双击 EmulatorJS.command 没反应（Mac）
    → 文件的「可执行」权限可能在传输时丢了。打开「终端」，输入
         chmod +x 
      （注意末尾有个空格），把 EmulatorJS.command 拖进终端窗口，按回车，再双击试试。

  Mac 上 EmulatorJS.command 没有显示游戏手柄图标
    → 双击运行一次就会自动设置。如果还是没变，关掉访达窗口再打开（访达有时不会马上刷新）。
      图标文件在 data/icon.png，不要删掉。

  Windows 上没有生成「EmulatorJS」快捷方式
    → 先双击 EmulatorJS-Windows.bat 运行一次，快捷方式会在同一个文件夹里生成。
      确认 data 文件夹里有 icon.ico，并且 start-windows.ps1 和 .bat 放在一起。

  个别游戏启动不了
    → 有些游戏需要 BIOS（见第九节）；有些街机游戏原本是给其他模拟器用的，
      网页版的 FBNeo 跑不了，这类请用 RetroArch 玩。

  我的设置、账号、存档保存在哪里？
    → 账号（名字、好友、战绩）：保存在外网联机服务器上，换电脑、换手机都能登录；密码只存加密后的结果。
      设置（文件夹、外网联机服务器地址和房间密码）：保存在每台设备自己的 config.json 里——
        文件夹版（.command / .bat）：EmulatorJS 文件夹里的 config.json
        Windows 桌面版：%APPDATA%\EmulatorJS\config.json
        Mac 桌面版：~/Library/Application Support/EmulatorJS/config.json
        安卓 App：App 自己的数据里（卸载 App 或清除 App 数据会一起删掉）
      登录状态、玩家名字、界面语言、配色、背景图片、最近玩过、游戏存档和即时存档：保存在浏览器里
      （桌面版、安卓 App 保存在程序自己的数据里），每台设备各存各的，不会上传到服务器。
      换浏览器、清除浏览器数据或卸载程序后会丢失；存档请用游戏下方菜单栏里的「导出存档文件」备份。
